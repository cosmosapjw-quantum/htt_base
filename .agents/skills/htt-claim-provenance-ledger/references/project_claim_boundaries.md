# Project claim boundaries for htt-claim-provenance-ledger

- MIO certificates are diagnostic reports, not posteriors or truth certificates.
- HTT owns model-dependent inference.
- `common` owns contracts, manifests, semantic firewalls, and claim-tier schemas.
- `obsstat` owns observer-side features: `a_lm`, deterministic templates, anisotropic covariance/BiPoSH, morphology features, and null feature distributions.
- `bass_py`/future native BASS own transfer/atlas outputs, not HTT/MIO inference.
- Teff/TSC is legacy/scope-audit material unless explicitly reproducing legacy tests.
- Family identification requires native morphology atlas, nulls, equivalence breaking, and validation.
