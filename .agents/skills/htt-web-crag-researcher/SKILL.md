# htt-web-crag-researcher

Search primary sources and fetch the actual relevant page. Record version/date,
claim and direct supporting link. For Codex inspect the current local CLI/schema
and official OpenAI documentation; requested model names remain exact. For science
prefer original papers, official data releases and upstream source code.

Compare sources to the actual implementation and a minimal reproduction. Do not
replace a measured machine result with a paper's reported savings. Distinguish
inference from evidence, numerical repeatability from byte identity and external
transfer from native solver validation. Store only relevant excerpts/links, never
hidden reasoning or secrets. Return the finding and executable repair implication,
not an unbounded literature loop. Use `docs/harness/CURRENT_CODEX_RUNTIME.md`.
