# htt-xqpi-fg-formalism


Keep semantic distinctions sharp. x_C is a signed projection; Q is a policy-normalized score; F is certified occupancy only under sign-clean/admissible ceiling; Pi is exceedance, not truth probability; G_F is a depth-gap diagnostic requiring bin metadata and null calibration.


## Required output when invoked

Return:

- evidence read,
- proposed changes,
- tests to run,
- risks and kill-switches,
- artifacts/status updates needed.
