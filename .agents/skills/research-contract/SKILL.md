# Research Contract
For `htt_base`, follow `AGENTS.md` and the selected task contract. Use applicable existing records; create a new artifact only when a consuming decision requires it. Preserve frozen and historical evidence. A skill verdict does not promote scientific admission beyond the applicable project gate.


1. Read the current project state and supplied sources.
2. Produce one primary research question and at most five subquestions.
3. Separate in-scope and out-of-scope work.
4. Define acceptable evidence, conventions, approval boundaries, and completion bar.
5. Update an existing `state/RESEARCH_STATE.md` when it is the task's consumer; otherwise return the contract to the task owner.
6. Stop before substantive literature search or hypothesis generation.
