# htt-observable-statistics


obsstat extracts features only. It does not infer models or certify truth. Deterministic template branch and covariance/BiPoSH branch are separate. All harmonic outputs require convention metadata. Any p-value requires null ensemble provenance and look-elsewhere notes.


## Required output when invoked

Return:

- evidence read,
- proposed changes,
- tests to run,
- risks and kill-switches,
- artifacts/status updates needed.
