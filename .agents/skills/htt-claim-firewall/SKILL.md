# htt-claim-firewall


Enforce: HTT posterior is not MIO certificate; MIO diagnostic is not truth; external transfer is not native; scalar scores are not geometry; family ID is blocked pre-native solver. Run banned-language checks. Require artifact metadata for owner, claim tier, scope, transfer source, caveats, and generating command.


## Required output when invoked

Return:

- evidence read,
- proposed changes,
- tests to run,
- risks and kill-switches,
- artifacts/status updates needed.
