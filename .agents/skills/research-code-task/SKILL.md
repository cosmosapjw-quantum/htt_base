# Research Code Task
For `htt_base`, follow `AGENTS.md` and the selected task contract. Use applicable existing records; create a new artifact only when a consuming decision requires it. Preserve frozen and historical evidence. A skill verdict does not promote scientific admission beyond the applicable project gate.


1. Read `AGENTS.md`, the selected task's existing scientific contract and validation evidence when applicable, and relevant code/tests.
2. Define task type, outcome, scope, preserved behavior, acceptance/reproduction, approvals, completion bar.
3. Reproduce or lock the baseline before editing.
4. Localize the execution/data/units flow.
5. Compare at most three substantively different solutions and select the smallest sufficient one.
6. Implement a coherent patch with tests.
7. Run software, scientific, numerical, and reproducibility checks as applicable.
8. Perform an independent review pass.
9. Update applicable existing plans, matrix, state and logs; preserve raw failures.
