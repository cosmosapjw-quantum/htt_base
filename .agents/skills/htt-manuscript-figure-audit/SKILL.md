# htt-manuscript-figure-audit


No figure without manifest. No manuscript number without generated source. Missing figures are blockers or quarantined. Public claims must map to artifacts, tests, owner, transfer source, and caveats. Build audit packages that let external reviewers reproduce the reasoning.


## Required output when invoked

Return:

- evidence read,
- proposed changes,
- tests to run,
- risks and kill-switches,
- artifacts/status updates needed.
