# Evidence Acquisition
For `htt_base`, follow `AGENTS.md` and the selected task contract. Use applicable existing records; create a new artifact only when a consuming decision requires it. Preserve frozen and historical evidence. A skill verdict does not promote scientific admission beyond the applicable project gate.


1. Read the research contract and current state.
2. Search primary sources first and record source scope.
3. Build a source map, conflict matrix, missing-evidence list, and evidence-ledger entries.
4. Avoid collecting repeated sources that do not change a claim state.
5. Stop when each core question has direct evidence or an explicit gap.
