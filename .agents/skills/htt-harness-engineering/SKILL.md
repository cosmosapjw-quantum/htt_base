# htt-harness-engineering

Read `docs/harness/CURRENT_CODEX_RUNTIME.md`, the touched entrypoint and its tests.
Reproduce a concrete failure before changing the runtime. Current global CUH-G
owns routing, child lifecycle, budget and telemetry; project hooks provide context.
Preserve dirty files and active task bindings. Do not create a new worktree without
owner approval. Distinguish active code from historical v1/CAS replay and physmath
3.1 vendor snapshots; installed physmath 4.0 skills are current when applicable.

Run the smallest falsifying test, then affected contract suites. Keep the 12,000
character total context limit; move detailed reference material out of injection.
Use the same-root installer and check its activation record. Do not claim trust or
live telemetry from installation. One independent review and one targeted repair
closeout per bounded task; a PASS must lead to execution or authorized publication.
Return changed behavior, actual tests, installation status and remaining limits.
