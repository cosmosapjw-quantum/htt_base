# shared-context-orchestrator

Read `docs/harness/CURRENT_CODEX_RUNTIME.md`. New native children use one global
CUH-G registration and its exact model/effort, fresh context and disjoint ownership.
No nested children or implicit full-parent transcript. Native runtime metadata must
be observed; a requested profile is not proof. Bonsai summaries retain source
references and scientific assumptions; use originals during outages.

Frozen v1 assignments retain their original run/assignment/context IDs, costs,
validator and independence mode. Their replay protocol is
`docs/harness/LEGACY_SHARED_CONTEXT_V1.md`; never silently migrate or close them.
Build the compact context view only when no active frozen run would be rebound.
Bootstrap + role + core remains within 12,000 characters; historical details are
on-demand references. Blind CAS axes/reviewers must not read sibling results.

Reuse exact task identity during continuation; telemetry spools metadata only.
Keep one production owner per file and at most four active agents. Reconcile child
returns through the actual global lifecycle before moving the registered HEAD.
Tests, candidate return, independent review and science admission are distinct.
