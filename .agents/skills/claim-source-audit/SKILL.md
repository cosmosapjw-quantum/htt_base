# Claim–Source Audit
For `htt_base`, follow `AGENTS.md` and the selected task contract. Use applicable existing records; create a new artifact only when a consuming decision requires it. Preserve frozen and historical evidence. A skill verdict does not promote scientific admission beyond the applicable project gate.


1. Work independently from the synthesis author.
2. Inspect each claim–citation pair for exact support, conditions, scope, and conflicts.
3. Assign `SUPPORTED`, `PARTIALLY_SUPPORTED`, `CONTESTED`, `UNSUPPORTED`, `MISATTRIBUTED`, or `INFERENCE_ONLY`.
4. Update an applicable existing evidence ledger, or return findings to its owner.
5. Prevent unsupported claims from entering hypothesis generation as facts.
