# External Audit Prompt Set

These prompts define the review lanes for the PR-114 external audit package.
The package is a claim-tiered observational/statistical framework handoff, not
a publication freeze.

Audit rules:

- Treat all current transfer-dependent outputs as transfer-conditional.
- Treat MIO certificates as diagnostic-only reports.
- Treat HTT likelihood/evidence outputs as HTT-owned inference artifacts only.
- Keep MIO diagnostics out of HTT likelihood/evidence inputs.
- The native morphology atlas is absent; geometry/family claims remain blocked.
- Require manifest metadata before using any report, figure, table, or result.
