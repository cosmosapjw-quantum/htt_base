### Candidate layouts considered

1. Put all H-lane contracts in a single `ver2_directional_shell.py`.
2. Split gate / scope / discrimination modules and leave the shell as a thin aggregator.

- Choose layout 2.
- Reason:
  - preserves the `SK-01C` schema barrier,
  - keeps HTT-specific semantics inside `htt/htt/htt/*`,
  - allows `ver2_directional_shell` to remain a solver-free aggregate while axis gating, likelihood scope, and discrimination stay testable as separate objects.

## 6. Ranked failure modes

1. `P0` diagnostic axis promoted into production
   - symptom: raw/ZoA axis used as HTT production seed
   - root cause: missing provenance/mock gate
   - cheapest test: production-axis gate unit tests
   - interpretation risk: spurious directional posterior seeded by diagnostic axis
2. `P0` MIO certificate merged into HTT posterior/evidence
   - symptom: `MioCertificate` accepted as HTT likelihood input
   - root cause: missing type/owner firewall
   - cheapest test: rejection test on `build_directional_likelihood_input`
   - interpretation risk: model-independent diagnostic semantics contaminate HTT evidence
3. `P0` TSC posterior correction sneaks into HTT
   - symptom: overlay toggles alter posterior arithmetic
   - root cause: caveat and correction channels not separated
   - cheapest test: hard-block `guard_tsc_posterior_correction`
   - interpretation risk: advisory adequacy layer treated as posterior math
4. `P1` local boost and global tilt collapse into one unlabeled response
   - symptom: identical side labels / normalizations
   - root cause: missing response-library metadata
   - cheapest test: response-library metadata tests
   - interpretation risk: observer and source/background effects become uninterpretable
5. `P1` spin-2 or morphology claims proceed with pending propagation
   - symptom: EE/TE/BB/template channels accepted without overlay validation
   - root cause: missing scope guard
   - cheapest test: scope-decision tests with pending overlay
   - interpretation risk: scalar-only or pending-propagation artifacts misread as geometry evidence
6. `P2` discrimination matrix reused as posterior odds
   - symptom: exploratory overlap object labeled as production evidence
   - root cause: insufficient manifest/caveat labeling
   - cheapest test: manifest-status and claim-tier assertions
   - interpretation risk: identifiability audit misread as Bayesian evidence
