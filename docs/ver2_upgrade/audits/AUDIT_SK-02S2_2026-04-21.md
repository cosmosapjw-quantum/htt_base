### Candidate layouts considered

1. Retrofit the existing executable hierarchy/transport/collision/history modules directly.
2. Add canonical VER2 S2 contract modules beside the legacy executable path and patch only a single load-bearing numerical floor if the touched-surface regression exposed one.
3. Create a separate `ver2/` subtree under the BASS solver packages.

### Converged choice

- Choose layout 2.
- Reason:
  - preserves the existing executable low-`ell` path without pretending it already satisfies VER2,
  - freezes the SSOT-mandated frame split and startup/history ownership now with minimal regression risk,
  - keeps future implementation obvious: `SK-03S3` and the implementation packets can bind the runtime to these interfaces rather than inventing new ones.

## 6. Ranked failure modes

1. `P0` frame ownership drift
   - symptom: transport, collision, and visibility silently use different direction/frame conventions
   - root cause: no canonical frame-split object
   - cheapest test: `FrameSplitMetadata` validation and geodesic/electron-frame shell tests
   - interpretation risk: sign errors mistaken for physical anisotropy
2. `P0` hidden low-`ell` closure promotion
   - symptom: `L=2` or startup-only approximations reused as if they were production closures
   - root cause: truncation/startup metadata absent
   - cheapest test: `TruncationMetadata` and startup-scope tests
   - interpretation risk: reduced shells overstated as finished solver physics
3. `P1` scalar-history shell mistaken for full anisotropic recombination
   - symptom: code or docs imply patchy / anisotropic atomic microphysics already exists
   - root cause: history scope not logged
   - cheapest test: `VisibilityHistoryContract` metadata tests
   - interpretation risk: physical scope overstated
4. `P1` tilted seed insertion treated as solved without projection
   - symptom: arbitrary tilted seeds accepted without post-insertion constraint projection
   - root cause: frame-aware seed rule exists but projection remains implicit
   - cheapest test: `SeedProjectionStub` remains pending and explicit
   - interpretation risk: inadmissible initial data interpreted as physical signal
5. `P1` tiny negative `Gamma_T` crashes the executable legacy solver
   - symptom: FLRW integrator fails near recombination-table edge
   - root cause: interpolation undershoot of a quantity that should be non-negative
   - cheapest test: full touched-surface `htt/bass/{hierarchy,transport,collision,recombination,closure}` regression
   - interpretation risk: numerical artifact misread as a solver-physics failure
