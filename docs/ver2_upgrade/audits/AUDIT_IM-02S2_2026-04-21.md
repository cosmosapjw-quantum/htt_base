# AUDIT_IM-02S2_2026-04-21

## 1. Audit target reconstruction

- Target packet: `IM-02S2`
- Lane: `S2`
- Semantic SSOT: `docs/ver2_upgrade/*` only.
- Goal: promote the VER2 S2 lane from frozen ownership contracts into a live low-`ell` transport/collision/history/startup/seed implementation surface without widening into the full Tier B runtime rewrite.
- Required deliverables from SSOT:
  - live photon geodesic and screen-basis transport in the `n^a` frame,
  - live projected electron-frame Thomson source with no FLRW-only shortcut,
  - live scalar-history visibility/reionization wiring plus tilted visibility modulation,
  - live startup gating for quadrupole-aware TCA use,
  - live seed-compatibility projection surface,
  - preservation of explicit low-`ell` `{I,E,B}` ownership and first-pass scalar-history limits.

### Candidate layouts considered

1. Rewrite the executable integrator immediately so every legacy call site consumes the new S2 modules.
2. Bind the new S2 contract modules to the existing executable LB-4/LB-5 physics surfaces now, and leave the runtime/orchestration retargeting to `IM-03S3A`.
3. Keep the S2 shells mostly isolated and relax expectations in docs/tests until the runtime packet.

### Converged choice

- Choose layout 2.
- Reason:
  - it satisfies the packet requirement to make the S2 surfaces real without reopening the entire Tier B runtime in the same commit;
  - it reuses already-tested production pieces (`thomson_pstf`, tilted Layer-B collision, `TiltedVisibility`, `quadrupole_tca`, background Codazzi projection) instead of inventing a parallel surrogate stack;
  - it preserves a clean next step: `IM-03S3A` can now bind runtime/orchestration onto real S2 surfaces rather than stubs.

## 6. Ranked failure modes

1. `P0` collision path silently falls back to orthogonal/FLRW when `v_e != 0`.
   - Mitigation: `project_thomson_source` now requires the tilted Layer-B path for nonzero `tilted_electron`.
2. `P0` transport uses the hard redshift law but leaves direction/screen basis frozen.
   - Mitigation: `photon_geodesic_rhs` now evolves all three pieces with explicit tangent/screen projection.
3. `P1` tilted visibility path exists elsewhere in the repo but is not wired into the S2 contract layer.
   - Mitigation: `build_tilted_visibility_source` now wraps `TiltedVisibility` directly and logs the scalar-history scope.
4. `P1` startup manifold exists but selection criteria stay implicit.
   - Mitigation: `decide_startup_gate` makes the `Gamma_T / H` decision explicit and blocks hidden diagnostic promotion.
5. `P1` seed projection remains purely declarative.
   - Mitigation: the geometry-backed branch now performs a real Codazzi projection; symbolic-only calls remain explicitly first-pass.
6. `P2` angular-grid ↔ PSTF radiation projection stubs remain unresolved.
   - Risk: Tier A / Tier B comparison cannot yet use those helpers directly.
7. `P2` runtime does not yet consume the new S2 surfaces end to end.
   - Risk: executable runtime still uses the legacy hierarchy path until `IM-03S3A`.
