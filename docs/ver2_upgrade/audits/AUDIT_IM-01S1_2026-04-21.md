## 3. Phys-math audit ledger

- Jacobi enforcement stays algebra-owned. No IC or evolution path reintroduces handwritten per-type Jacobi logic.
- Codazzi is now enforced through the actual algebra-generated divergence operator. No class-A/class-B shortcut was added.
- Orthogonal ICs now project arbitrary PSTF shear guesses onto `div sigma = 0`.
- Tilted ICs now either satisfy `div sigma = kappa q` or fail explicitly. Type-I single-fluid tilt is no longer silently accepted.
- The Hamiltonian closure now supports three physically distinct bounded moves in addition to `hold_H`:
  - solve `H`,
  - solve the algebra scale,
  - solve the shear amplitude.
- The executable evolution path uses the proper-time 1+3 Raychaudhuri/shear/energy equations in e-fold time and reports constraint/Weyl histories.

## 4. Equation-to-code mapping audit

- Candidate 1: patch `einstein_bianchi.py` directly so the old reduced solver consumes the new S1 operators.
  - rejected: too much hidden semantic overlap with the reduced `(a, Sigma_+, Sigma_-)` route and too much downstream regression risk inside a single packet.
- Candidate 2: keep `einstein_bianchi` for compatibility, but add a new canonical executable background path that is built directly from `BianchiAlgebra -> TetradGeometry -> IC builders -> assemble_background_rhs`.
  - selected: minimal semantic surface, explicit VER2 ownership, keeps legacy compatibility path available.
- Candidate 3: only upgrade IC/projection logic and leave executable evolution for later.
  - rejected: would leave the new S1 surfaces non-executable and violate the packet requirement to repair remaining placeholders on the production path.

## 5. Numerical/pipeline audit

- The new S1 executable path integrates in `N = ln a`, which keeps the expansion branch explicit and avoids mixing the old conformal-shear state with the new proper-time PSTF equations.
- Constraint monitoring is explicit at every sampled step through stored `BackgroundConstraintResiduals`.
- Weyl diagnostics are computed from the same geometry/RHS conventions as the evolution path.
- Tilted evolution deliberately uses a bounded fixed-velocity barotropic closure:
  - this is not a diagnostic surrogate;
  - it is an explicit first-pass background closure with exact tilted stress-energy recomputation at each scale factor;
  - full Euler/interaction-driven tilt evolution remains a later packet.

## 6. Ranked failure modes

1. Old reduced solver silently treated as the only production path.
   - Mitigation: `background/evolution.py` is now the canonical VER2 executable background path and the next-session prompt is updated accordingly.
2. Type-specific Codazzi hacks or class-A-only logic creep into tilted ICs.
   - Mitigation: projection uses the algebra-generated divergence matrix for every type.
3. Inadmissible single-species tilt accepted as a valid background.
   - Mitigation: `CodazziProjectionError` is raised on unresolved residuals.
4. Package import cycle continues to block runtime collection.
   - Mitigation: `bass.background` exports are now lazy and runtime wiring tests pass again.
5. Hamiltonian closure mutates matter content silently.
   - Mitigation: closure metadata records whether `H`, algebra scale, or shear amplitude was adjusted.
