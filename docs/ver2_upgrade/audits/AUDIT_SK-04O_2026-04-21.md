## 1. Audit target reconstruction

- Target: close the O-lane skeleton packet for VER2 observable/atlas/covariance/report substrates.
- Semantic SSOT: `docs/ver2_upgrade/*` only.

- Required packet outputs from SSOT:

  - sparse covariance / BiPoSH-like morphology export,
  - theory-side `AtlasEntryLite` builder,
  - full-covariance MES report shell with rank-failure no-claim behavior,
  - descriptive x/Q/Pi/F/G report plumbing,
  - manifest and sky-support propagation.

### Candidate layouts considered

1. Retrofit the existing FB-7 covariance module directly into a production observable layer.
2. Add VER2 observational producer shells beside the existing Planck/MES observational modules and keep `workspace/contracts` as thin aliases only.
3. Push all O-lane producers into `workspace/contracts/*` and leave BASS with only raw dictionaries.

### Converged choice

- Choose layout 2.
- Reason:
  - preserves the `SK-01C` schema barrier,
  - keeps BASS-owned producer logic inside `htt/bass/observational/*`,
  - allows HTT/MIO/TSC to consume stable manifest-backed artifacts later without redefining schema or overstating the current FB-7 proxy covariance path.

## 5. Numerical/pipeline audit

- Numerical behavior:
  - no live solver numerics were changed in this packet;
  - only guard-style linear algebra was added for covariance matrices.
- Pipeline effects:
  - BASS can now transform `SolverCoreOutput` into manifest-backed observables/atlas/report shells without waiting for executable Tier A/Tier B completion;
  - FB-7 covariance now exposes sparse-entry and PSD helper surfaces reused by O-lane shells.
- PSD / covariance guard:
  - TT, EE, and BB dense blocks are checked with `eigvalsh`;
  - TE is checked through the joint `[[TT, TE], [TE^T, EE]]` block;
  - results are metadata only and do not promote claims by themselves.
- Web CRAG lane:
  - used for primary-source cross-checks on statistical-isotropy morphology and MES bound semantics.
  - sources checked:
    - Joshi, Jhingan, Souradeep, Hajian 2010 DOI `10.1103/PhysRevD.81.083012`
    - Maartens, Ellis, Stoeger 1995 DOI `10.1103/PhysRevD.51.5942`
  - result:
    - no contradiction with the SSOT framing; the packet stays at descriptive/covariance-substrate level and keeps rank/noise caveats explicit.

## 6. Ranked failure modes

1. `P0` diagonal-only compression reused as the full anisotropic observable surface
   - symptom: only `C_ell` survives, off-diagonal morphology silently disappears
   - root cause: no sparse covariance export path
   - cheapest test: `test_observable_vector_builder_attaches_sky_support_and_manifest`
   - interpretation risk: anisotropy claims reduced to isotropic power summaries
2. `P0` rank-deficient covariance upgrade reported as weak evidence
   - symptom: full-covariance MES report still sounds informative when response rank is zero
   - root cause: missing no-claim gate
   - cheapest test: `test_full_cov_mes_rank_failure_returns_no_claim`
   - interpretation risk: morphology upgrade overstated
3. `P1` proxy `m`-block sparse output mislabeled as full BiPoSH
   - symptom: frame-dependent proxy entries treated as invariant morphology
   - root cause: representation caveat omitted
   - cheapest test: `test_covariance_proxy_and_feature_summary_record_guards`
   - interpretation risk: false basis-independent claim
4. `P1` uncertified filling mislabeled as certified occupancy
   - symptom: `F_status="certified_occupancy"` without claim/admissibility gates
   - root cause: Q/F semantics not enforced
   - cheapest test: `test_departure_report_stays_descriptive_without_claim_gate`
   - interpretation risk: report-card semantics merged with certification
5. `P1` sky-support metadata dropped when moving from observable to atlas/report artifacts
   - symptom: downstream directional or morphology consumers lose mask/mock context
   - root cause: shared contract has only one explicit `SkySupport` field
   - cheapest test: atlas/report manifest-statistics assertions
   - interpretation risk: uncalibrated sky comparisons
6. `P2` O-lane builders quietly redefine common schema
   - symptom: `workspace/contracts` starts shadowing canonical common contracts
   - root cause: alias barrier bypassed
   - cheapest test: `htt/workspace/contracts/tests/test_ver2_common_schema_barrier.py`
   - interpretation risk: cross-package schema drift
