## 1. Audit target reconstruction

- Target packet: `IM-03S3A`
- Lane: `S3`
- Semantic SSOT: `docs/ver2_upgrade/*` only.
- Goal: turn the frozen S3 runtime/output contracts into an executable bounded Tier-B low-`ell` solver path without pretending to deliver a universal solver rewrite inside the same packet.
- Required deliverables from SSOT:
  - executable Tier-B runtime/orchestrator,
  - observer-neutral `SolverCoreOutput`,
  - live anisotropic source-to-observer propagator route,
  - executable cutoff/convergence campaign hooks,
  - deterministic metadata-bearing runtime artifacts,
  - explicit consumption of the S1/S2 live hooks without importing observational interpretation into BASS.

### Candidate layouts considered

1. Rewrite the Tier-B numerical core around the S1/S2 modules immediately.
2. Keep the shipped Lowell Tier-B hierarchy as the bounded numerical core, but retarget runtime/orchestrator/output ownership so S1/S2 hooks are consumed end to end and the result exits through the VER2 contracts.
3. Keep the S3 layer thin and only add more metadata/tests around `build_solver_core_output_from_lowell_result`.

### Converged choice

- Choose layout 2.
- Reason:
  - it satisfies the SSOT requirement that Tier B becomes executable through the VER2 runtime shells now;
  - it closes the load-bearing carry-forward from `IM-02S2` without widening into a full solver rewrite outside this packet’s write scope;
  - it keeps the remaining caveat honest: the runtime is executable, but the core ODE stack is still the bounded Lowell bridge.
