# 역할 분류 검수

기존 목록 40,282개 묶음 / 104,780개 출처 발생 기록을 보존했다.
연구제안서의 구체적 정리 목표 172개 구간, 내부 보조 선언 93개,
명시적 문헌 이식 1개를 별도 목록으로 제공한다. 서로 다른 집계 단위이며
172개가 독립적·새로운 수학 정리 수라는 뜻은 아니다.

이전 키워드 검색은 개별 후보를 문서 제목/일반 언급 아래에만 보유하기도 했다.
이 때문에 후보 129개 구간은 이전 두 목록의 시작 위치와 직접 대응하지 않는다.
각 구간의 원문과 DB 레코드를 별도로 연결했고 기존 DB 및 증명 분류를 변경하지 않았다.

독립 읽기 검토자는 365개 역할 근거, 제안·사용 문맥, DB 레코드 연결을
해당 UTF-8 원문 행과 대조했다. 58개 내용 버전 / 370개 경로·버전 사본에서
실질적 불일치나 역할 분류의 수용 기준 위반을 보고하지 않았다.
원문 발췌는 splitlines 후 지정 행을 줄바꿈으로 연결하며 마지막 구분자는 포함하지 않는다.
최초 keepends 비교의 줄바꿈 차이는 이 규약으로 해소했다.

카탈로그 전용 테스트는 최종 54개 PASS, DAG 구조는 197개 PR에 대해 PASS다.
같은 입력의 전체 역할 내보내기 두 번은 바이트가 같고 배포 파일 31개와도 일치했다.
검토 도중 전체 proofs 디렉터리 해시는 부모의 생성 파일 갱신으로 달라졌지만,
명시적으로 고정한 원본 목록·출처 연결표 해시는 변경되지 않았다.
복원 SQLite의 SHA-256도 이전 배포값과 같으며 원본 체크아웃의 74개 변경 항목을 보존했다.

역할 보류 39,072개는 추가 내용 대조가 필요하다. 이 검수는 모든 역사적 제안/사용 관계의
의미 판정을 완료했다는 선언이 아니다. 연구 코드·연구 테스트 수집·CAS·Lean은 실행하지 않았다.
‘제안됨’과 ‘증명됨’, ‘학술적으로 새로움’은 서로 독립된 상태로 유지한다.

에이전트 종료 훅은 여전히 원본 체크아웃의 무관한 활성 run으로 잘못 전달된다.
작업 전용 경로의 실제 결과를 읽어 검토했으며 그 무관한 run을 수정하지 않았다.
검토 결과의 유효성과 훅 전달 오류는 구분한다.

원격 게시 결과와 파일 체크섬은 [validation.json](validation.json)에 기록한다.

일반 push한 산출물 커밋 `15becf53a30b9c823e5754308eb8aca2ee8901b4`를 별도 원격
체크아웃으로 받아 생성 파일 31개 체크섬을 확인했다. 존재하지 않는 DB 경로와
`python3 -S -B`로 역할 목록을 내보내어 같은 31개 파일을 재생성했다.
DB 복원은 발생하지 않았다. T-P1, T-P18, NT2-A1 및 mm_assoc의 원문 위치·버전·발췌 연결도 확인했다.

작업 하네스의 정상 종료 검사는 에이전트 결과 봉투의 메타데이터 형식 불일치로
통과하지 못했다. 실패를 보존하고 카탈로그 작업의 활성 포인터만 `--abandon`으로 해제했다.
이 운영 상태를 과학적 실패나 목록 검증 PASS로 바꾸지 않았으며, 위 내용 검수는 실제 근거 파일에 기초한다.
