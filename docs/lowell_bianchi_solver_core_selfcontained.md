# Low-\(\ell\) Tetrad Bianchi CMB Solver Core

## 1+3 gauge-invariant covariant PSTF formulation with tetrad algebra backend

**Document role.** This is the solver-core development specification. It deliberately excludes observer-side anomaly statistics, map likelihoods, Planck-specific interpretation, and conservative-template language. The purpose is to build a research solver for beyond-FLRW homogeneous anisotropic cosmologies, treating all Bianchi types as first-class backgrounds and allowing both orthogonal and tilted matter.

**Core design sentence.** The solver is a 1+3 covariant PSTF Einstein--Boltzmann system evaluated in an invariant tetrad basis. The tetrad algebra supplies the Bianchi type; all geometry, constraints, matter projections, photon transport, Thomson scattering, and low-\(\ell\) radiation multipoles are then generated by the same algebraic backend.

---

# 0. Scope and non-scope

This document specifies only the mathematical and algorithmic core:

\[
\boxed{
\text{Bianchi algebra}
\rightarrow
\text{1+3 covariant PSTF variables}
\rightarrow
\text{constraint-satisfying background}
\rightarrow
\text{tetrad photon transport}
\rightarrow
\text{PSTF radiation/Thomson solver}
}
\]

It does **not** specify low-\(\ell\) anomaly statistics, map-level estimators, data masks, likelihood conventions, or empirical interpretation. Those belong in the separate observables/statistics document.

The solver should not be organized around a single historically popular template such as only VII\(_h\). The goal is open exploration of homogeneous anisotropic physics. Therefore every Bianchi type below must be handled by the same backend:

\[
\boxed{
\mathrm{I},\ \mathrm{II},\ \mathrm{III},\ \mathrm{IV},\ \mathrm{V},\
\mathrm{VI}_0,\ \mathrm{VI}_h,\ \mathrm{VII}_0,\ \mathrm{VII}_h,\
\mathrm{VIII},\ \mathrm{IX}.
}
\]

The document keeps the original authority path of the earlier PR/WBS plan -- exact Bianchi transport, electron-frame Thomson scattering, explicit low-\(\ell\) temperature/polarization multipoles, scalar ionization history in the first implementation, and anisotropic line transport -- but rewrites the geometric core in 1+3 covariant PSTF language rather than ADM language.

# 1. Conventions

## 1.1 Units, signature, time

Metric signature:

\[
(-,+,+,+).
\]

The speed of light is kept explicitly unless a code module explicitly declares natural units. The default geometric time coordinate is

\[
\tau \equiv c t,
\]

so \(d/d\tau\) has dimension \(L^{-1}\). The Einstein coupling is

\[
\kappa \equiv \frac{8\pi G}{c^4}.
\]

Energy density and pressure have the same physical dimensions. Thus \(\kappa\rho\), \(\kappa p\), \(\Lambda\), \(H^2\), \(\sigma_{ab}\sigma^{ab}\), and the spatial Ricci scalar \({}^{3}R\) all have dimension \(L^{-2}\).

## 1.2 1+3 split

Choose a geometrically defined normal congruence \(n^a\):

\[
n^a n_a=-1,\qquad h_{ab}=g_{ab}+n_a n_b.
\]

Spatial projection:

\[
X_{\langle a_1\cdots a_\ell\rangle}
\equiv
\text{projected symmetric trace-free part with respect to }h_{ab}.
\]

The kinematic decomposition is

\[
\nabla_a n_b
=
-n_a A_b
+\frac13\Theta h_{ab}
+\sigma_{ab}
+\omega_{ab}.
\]

For the Bianchi backgrounds used here, the normal congruence is chosen hypersurface-orthogonal and geodesic:

\[
A_a=0,\qquad \omega_{ab}=0,
\]

while the matter species may be tilted relative to \(n^a\). Define

\[
H\equiv \frac13\Theta,
\qquad
\sigma^2\equiv \frac12\sigma_{ab}\sigma^{ab}.
\]

## 1.3 Tetrad basis

Use an orthonormal tetrad

\[
e_0=n,
\qquad
\{e_\alpha\}_{\alpha=1}^{3},
\qquad
h(e_\alpha,e_\beta)=\delta_{\alpha\beta}.
\]

Greek tetrad indices \(\alpha,\beta,\gamma\) are spatial and are raised/lowered with \(\delta_{\alpha\beta}\). The spatial volume form is \(\epsilon_{\alpha\beta\gamma}\), with

\[
\epsilon_{123}=+1.
\]

The tetrad may be Fermi-propagated or allowed to rotate. The default production gauge is Fermi-propagated:

\[
\Omega_\alpha=0.
\]

A rotating tetrad is allowed only if every equation includes the corresponding \(\epsilon_{\alpha\beta\gamma}\Omega^\gamma\) terms and the rotation convention is recorded in the run metadata.

## 1.4 Why this is the right “gauge” for this solver

This is not a scalar/vector/tensor metric-gauge perturbation code. The primary variables are covariantly defined tensors attached to \(n^a\):

\[
H,
\quad
\sigma_{ab},
\quad
E_{ab},
\quad
H_{ab},
\quad
\rho,
\quad
p,
\quad
q_a,
\quad
\pi_{ab},
\quad
I_{A_\ell},E_{A_\ell},B_{A_\ell}.
\]

The tetrad only supplies components of these covariant objects. Coordinate gauge modes never enter the solver state. Frame rotations remain a tetrad-gauge choice and must either be fixed by \(\Omega_\alpha=0\) or explicitly included.

# 2. Bianchi tetrad algebra

## 2.1 Spatial commutators

The spatial tetrad commutators are

\[
[e_\alpha,e_\beta]
=
C^\gamma{}_{\alpha\beta}e_\gamma,
\qquad
C^\gamma{}_{\alpha\beta}=-C^\gamma{}_{\beta\alpha}.
\]

Use the standard Bianchi decomposition

\[
\boxed{
C^\gamma{}_{\alpha\beta}
=
2a_{[\alpha}\delta_{\beta]}{}^\gamma
+
\epsilon_{\alpha\beta\delta}n^{\delta\gamma}
}
\]

where

\[
a_\alpha \quad\text{is a spatial vector},
\qquad
n_{\alpha\beta}=n_{\beta\alpha}
\quad\text{is a symmetric spatial tensor}.
\]

The Jacobi identity gives the algebraic Bianchi constraint

\[
\boxed{n_{\alpha\beta}a^\beta=0.}
\]

This single equation is the first constraint the code must enforce for every type.

## 2.2 Canonical algebra table for the 11 Bianchi types

The canonical frame is chosen so that

\[
a_\alpha=(a,0,0),
\qquad
n_{\alpha\beta}=\mathrm{diag}(n_1,n_2,n_3),
\]

except that type I has \(a=0\) and \(n_i=0\). The overall dimensional scale is not fixed by the table; the user supplies a physical curvature scale or an \(H\)-normalized scale.

| Type | Class | Canonical \(a_\alpha\) | Canonical \((n_1,n_2,n_3)\) | Parameter rule | Implementation note |
|---|---:|---:|---:|---|---|
| I | A | \((0,0,0)\) | \((0,0,0)\) | none | flat group algebra |
| II | A | \((0,0,0)\) | one nonzero entry, e.g. \((n,0,0)\) | \(n\ne0\) | axis permutations are equivalent tetrad choices |
| VI\(_0\) | A | \((0,0,0)\) | \((0,n,-n)\) | \(n\ne0\) | trace-free class-A open algebra |
| VII\(_0\) | A | \((0,0,0)\) | \((0,n,n)\) | \(n\ne0\) | Euclidean-type helical algebra |
| VIII | A | \((0,0,0)\) | signs \((-n,n,n)\) up to permutations | \(n>0\) | negative-curvature non-compact semisimple case |
| IX | A | \((0,0,0)\) | \((n,n,n)\) | \(n>0\) | positive-curvature compact algebra |
| V | B | \((a,0,0)\) | \((0,0,0)\) | \(a>0\) | open isotropic limit exists |
| IV | B | \((a,0,0)\) | \((0,0,n)\) or \((0,n,0)\) | \(a,n>0\) | one nonzero \(n\)-eigenvalue |
| III | B | \((a,0,0)\) | \((0,n,-n)\) with special normalization | conventionally VI\(_{h=-1}\) | keep as named alias for clarity |
| VI\(_h\) | B | \((a,0,0)\) | \((0,n_2,n_3)\), \(n_2n_3<0\) | \(h\equiv a^2/(n_2n_3)<0\), convention-dependent sign | excludes the named III alias in user-facing tables if desired |
| VII\(_h\) | B | \((a,0,0)\) | \((0,n_2,n_3)\), \(n_2n_3>0\) | \(h\equiv a^2/(n_2n_3)>0\) | class-B helical algebra |

The sign convention for \(h\) must be stored in `BianchiAlgebra.h_convention`. Some literature defines \(h\) with the opposite sign for VI\(_h\). The code must not assume literature sign conventions without metadata.

## 2.3 Algebra object

All Bianchi types must be represented by the same object:

```python
@dataclass
class BianchiAlgebra:
    type_name: str
    a: Array[3]          # a_alpha, dimension L^-1 or H-normalized
    n: Array[3, 3]       # symmetric n_{alpha beta}
    C: Array[3, 3, 3]    # C^gamma_{alpha beta}
    h_parameter: float | None
    class_label: Literal["A", "B"]
    h_convention: str
```

Construction rule:

```python
def build_C(a, n):
    C = zeros((3,3,3))
    for gamma in range(3):
        for alpha in range(3):
            for beta in range(3):
                curvature_part = sum(
                    eps[alpha, beta, d] * n[d, gamma]
                    for d in range(3)
                )
                C[gamma, alpha, beta] = (
                    a[alpha] * delta[beta, gamma]
                    - a[beta] * delta[alpha, gamma]
                    + curvature_part
                )
    return C
```

Jacobi check:

```python
def jacobi_residual(a, n):
    return n @ a
```

Hard rule:

\[
\|n_{\alpha\beta}a^\beta\| < \varepsilon_{\rm jacobi}
\]

must hold before any geometry, matter, or radiation module is called.

# 3. Tetrad connection, curvature, and PSTF operators

## 3.1 Spatial connection from the algebra

Define spatial connection coefficients by

\[
\nabla_{e_\alpha}e_\beta
=
\Gamma^\gamma{}_{\beta\alpha}e_\gamma.
\]

Lower the first index with \(\delta_{\alpha\beta}\):

\[
\Gamma_{\gamma\beta\alpha}
\equiv
\delta_{\gamma\delta}\Gamma^\delta{}_{\beta\alpha}.
\]

The Koszul formula for an orthonormal anholonomic frame gives

\[
\boxed{
2\Gamma_{\gamma\beta\alpha}
=
C_{\alpha\beta\gamma}
-C_{\beta\gamma\alpha}
+C_{\gamma\alpha\beta}.
}
\]

This formula is the code authority. All closed-form Ricci formulas are optional optimizations and must be tested against this connection routine.

Pseudocode:

```python
def spatial_connection(C):
    Gamma = zeros((3,3,3))  # Gamma[gamma,beta,alpha]
    for gamma,beta,alpha in product(range(3), repeat=3):
        Gamma[gamma,beta,alpha] = 0.5 * (
            C[alpha,beta,gamma]
            - C[beta,gamma,alpha]
            + C[gamma,alpha,beta]
        )
    return Gamma
```

Metric compatibility and torsion-free tests:

\[
\Gamma_{\gamma\beta\alpha}
=-\Gamma_{\beta\gamma\alpha},
\]

\[
\Gamma^\gamma{}_{\beta\alpha}
-
\Gamma^\gamma{}_{\alpha\beta}
=C^\gamma{}_{\alpha\beta}.
\]

The second equation fixes the sign convention. It must be a unit test.

## 3.2 Spatial Ricci tensor

With constant tetrad structure coefficients on each homogeneous slice, spatial curvature is computed by

\[
{}^{3}R^\delta{}_{\gamma\alpha\beta}
=
\Gamma^\epsilon{}_{\gamma\beta}\Gamma^\delta{}_{\epsilon\alpha}
-
\Gamma^\epsilon{}_{\gamma\alpha}\Gamma^\delta{}_{\epsilon\beta}
-C^\epsilon{}_{\alpha\beta}\Gamma^\delta{}_{\gamma\epsilon}.
\]

Then

\[
{}^{3}R_{\gamma\beta}
=
{}^{3}R^\alpha{}_{\gamma\alpha\beta},
\qquad
{}^{3}R
=
\delta^{\gamma\beta}{}^{3}R_{\gamma\beta}.
\]

The PSTF spatial Ricci part is

\[
{}^{3}S_{\alpha\beta}
\equiv
{}^{3}R_{\langle\alpha\beta\rangle}
=
{}^{3}R_{\alpha\beta}
-\frac13\delta_{\alpha\beta}{}^{3}R.
\]

Pseudocode:

```python
def spatial_ricci(C):
    Gamma = spatial_connection(C)
    Riem = zeros((3,3,3,3))  # Riem[delta,gamma,alpha,beta]
    for delta,gamma,alpha,beta in product(range(3), repeat=4):
        term = 0.0
        for eps_i in range(3):
            term += Gamma[eps_i,gamma,beta] * Gamma[delta,eps_i,alpha]
            term -= Gamma[eps_i,gamma,alpha] * Gamma[delta,eps_i,beta]
            term -= C[eps_i,alpha,beta] * Gamma[delta,gamma,eps_i]
        Riem[delta,gamma,alpha,beta] = term
    Ric = zeros((3,3))
    for gamma,beta in product(range(3), repeat=2):
        Ric[gamma,beta] = sum(Riem[alpha,gamma,alpha,beta] for alpha in range(3))
    R = trace(Ric)
    S = pstf2(Ric)
    return Ric, R, S
```

## 3.3 Covariant derivative of homogeneous tetrad components

For a homogeneous spatial vector \(V_\alpha(\tau)\), the spatial frame derivative has no component derivative but does have connection terms:

\[
D_\beta V_\alpha
= -\Gamma^\gamma{}_{\alpha\beta}V_\gamma.
\]

For a homogeneous spatial tensor \(X_{\alpha\beta}\),

\[
D_\gamma X_{\alpha\beta}
=
-\Gamma^\delta{}_{\alpha\gamma}X_{\delta\beta}
-
\Gamma^\delta{}_{\beta\gamma}X_{\alpha\delta}.
\]

The divergence and curl operators used by constraints and the radiation module are therefore purely algebraic:

\[
(\mathrm{div}\,X)_\alpha
\equiv
D^\beta X_{\alpha\beta},
\]

\[
(\mathrm{curl}\,X)_{\alpha\beta}
\equiv
\epsilon_{\gamma\delta\langle\alpha}D^\gamma X_{\beta\rangle}{}^\delta.
\]

Pseudocode:

```python
def div_pstf2(X, Gamma):
    out = zeros(3)
    for alpha,beta in product(range(3), repeat=2):
        # D_beta X_{alpha beta}
        D = 0.0
        for delta in range(3):
            D -= Gamma[delta,alpha,beta] * X[delta,beta]
            D -= Gamma[delta,beta,beta] * X[alpha,delta]
        out[alpha] += D
    return out


def curl_pstf2(X, Gamma):
    Y = zeros((3,3))
    for alpha,beta in product(range(3), repeat=2):
        val = 0.0
        for gamma,delta in product(range(3), repeat=2):
            # D_gamma X_{beta delta}
            D = 0.0
            for mu in range(3):
                D -= Gamma[mu,beta,gamma] * X[mu,delta]
                D -= Gamma[mu,delta,gamma] * X[beta,mu]
            val += eps[gamma,delta,alpha] * D
        Y[alpha,beta] = val
    return pstf2(Y)
```

The implementation should generate these operators from the connection rather than hand-coding type-specific component formulas.

# 4. 1+3 Einstein--Bianchi background system

## 4.1 Matter decomposition with respect to \(n^a\)

The total stress-energy tensor is decomposed as

\[
T_{ab}
=
\rho n_a n_b
+p h_{ab}
+2q_{(a}n_{b)}
+\pi_{ab},
\]

with

\[
q_a n^a=0,
\qquad
\pi_{ab}=\pi_{\langle ab\rangle}.
\]

In tetrad components:

\[
\rho=T_{ab}n^a n^b,
\qquad
p=\frac13h^{ab}T_{ab},
\qquad
q_\alpha=-h_\alpha{}^cT_{cd}n^d,
\qquad
\pi_{\alpha\beta}=T_{\langle\alpha\beta\rangle}.
\]

## 4.2 Raychaudhuri equation

For geodesic, irrotational \(n^a\),

\[
\boxed{
\dot H
=
-H^2
-\frac23\sigma^2
-\frac{\kappa}{6}(\rho+3p)
+\frac{\Lambda}{3}.
}
\]

Here and below a dot means \(d/d\tau\).

Dimension check:

\[
[\dot H]=L^{-2},
\qquad
[H^2]=[\sigma^2]=[\kappa\rho]=[\Lambda]=L^{-2}.
\]

## 4.3 Shear propagation

The PSTF Ricci identity for \(n^a\), combined with the Gauss relation, gives the homogeneous Bianchi shear propagation equation

\[
\boxed{
\dot\sigma_{\alpha\beta}
=
-3H\sigma_{\alpha\beta}
-{}^{3}S_{\alpha\beta}
+\kappa\pi_{\alpha\beta}.
}
\]

This is the main background anisotropy equation. The source terms are transparent:

- \(-3H\sigma_{\alpha\beta}\): expansion damping,
- \(-{}^{3}S_{\alpha\beta}\): anisotropic spatial curvature forcing,
- \(+\kappa\pi_{\alpha\beta}\): matter anisotropic stress forcing.

For type I with no anisotropic stress, \({}^{3}S_{\alpha\beta}=0\) and \(\sigma_{\alpha\beta}\propto a^{-3}\) in the small-shear regime.

## 4.4 Algebra evolution from the tetrad Jacobi identity

The time-space commutator is written

\[
[e_0,e_\alpha]
=-B_\alpha{}^\beta e_\beta,
\]

with

\[
B_\alpha{}^\beta
=H\delta_\alpha{}^\beta
+\sigma_\alpha{}^\beta
+\epsilon_\alpha{}^{\beta\gamma}\Omega_\gamma.
\]

For the default Fermi tetrad, \(\Omega_\gamma=0\). The Jacobi identity

\[
[e_0,[e_\alpha,e_\beta]]
+[e_\alpha,[e_\beta,e_0]]
+[e_\beta,[e_0,e_\alpha]]=0
\]

gives the evolution of the structure coefficients:

\[
\boxed{
\dot C^\gamma{}_{\alpha\beta}
=
C^\delta{}_{\alpha\beta}B_\delta{}^\gamma
-B_\beta{}^\delta C^\gamma{}_{\alpha\delta}
+B_\alpha{}^\delta C^\gamma{}_{\beta\delta}.
}
\]

This equation propagates the Bianchi algebra scale and shape in the evolving orthonormal frame. The code may equivalently evolve \(a_\alpha,n_{\alpha\beta}\), but the authoritative implementation should evolve \(C^\gamma{}_{\alpha\beta}\) and reconstruct \(a,n\) only for diagnostics.

Jacobi preservation test:

\[
\frac{d}{d\tau}(n_{\alpha\beta}a^\beta)=0
\]

must hold numerically up to integration tolerance.

## 4.5 Gauss constraint

The covariant Gauss constraint is

\[
\boxed{
3H^2
=
\kappa\rho+\Lambda
+\sigma^2
-\frac12{}^{3}R.
}
\]

Equivalently,

\[
\mathcal C_G
\equiv
3H^2
-\kappa\rho
-\Lambda
-\sigma^2
+\frac12{}^{3}R
=0.
\]

This is not optional. It is used both for initial condition construction and runtime monitoring.

If \(H_i\) is not specified, solve

\[
\boxed{
H_i
=+\sqrt{\frac13\left(
\kappa\rho_i+
\Lambda+
\sigma_i^2-\frac12{}^{3}R_i
\right)}
}
\]

for an expanding branch. The expression under the square root is a hard physical admissibility condition.

## 4.6 Codazzi momentum constraint

For homogeneous \(H\) and \(A_a=\omega_a=0\), the 1+3 Codazzi constraint reduces to

\[
\boxed{
D^\beta\sigma_{\alpha\beta}
=
\kappa q_\alpha.
}
\]

In code:

\[
\mathcal C_{M,\alpha}
\equiv
(\mathrm{div}\,\sigma)_\alpha-
\kappa q_\alpha
=0.
\]

This is the main constraint coupling tilt to geometry.

Orthogonal matter has \(q_\alpha=0\), so the shear must satisfy

\[
(\mathrm{div}\,\sigma)_\alpha=0.
\]

Tilted matter has \(q_\alpha\ne0\), so the allowed total momentum density is not arbitrary:

\[
\boxed{
q_\alpha
=\kappa^{-1}(\mathrm{div}\,\sigma)_\alpha.
}
\]

This equation is the clean 1+3 replacement for ad hoc tilted initial conditions.

## 4.7 Magnetic Weyl constraint

The magnetic Weyl tensor is not an independent input for the homogeneous background. With \(A_a=\omega_a=0\), the Ricci identity gives

\[
\boxed{
H_{\alpha\beta}^{\rm Weyl}
=(\mathrm{curl}\,\sigma)_{\alpha\beta}.
}
\]

This supplies a strong diagnostic for the tetrad curl operator and for polarization-basis transport.

## 4.8 Electric Weyl tensor as diagnostic

The shear propagation equation implies

\[
E_{\alpha\beta}^{\rm Weyl}
= -\dot\sigma_{\alpha\beta}
-2H\sigma_{\alpha\beta}
-\sigma_{\gamma\langle\alpha}\sigma_{\beta\rangle}{}^\gamma
+\frac12\kappa\pi_{\alpha\beta}.
\]

The solver does not need to evolve \(E_{\alpha\beta}\) as a primary variable in the minimal background module, but it should compute it for diagnostics and for optional Weyl-Bianchi consistency checks.

## 4.9 Twice-contracted Bianchi identity

The identity

\[
\nabla^bG_{ab}=0
\]

implies

\[
\nabla^bT_{ab}=0
\]

for minimally coupled matter. This is the authority for matter evolution. In interacting modules,

\[
\nabla^bT^{(s)}_{ab}=Q^{(s)}_a,
\qquad
\sum_sQ^{(s)}_a=0.
\]

The background integrator must verify that constraint residuals do not grow independently of the matter conservation residuals.

# 5. Orthogonal and tilted species

## 5.1 Species 4-velocity

For each matter species \(s\), write

\[
u_{(s)}^a
=\Gamma_s(n^a+v_{(s)}^a),
\qquad
v_{(s)}^a n_a=0,
\]

\[
\Gamma_s=(1-v_s^2)^{-1/2},
\qquad
v_s^2=v_{(s)\alpha}v_{(s)}^\alpha.
\]

Orthogonal species:

\[
v_{(s)}^\alpha=0,
\qquad
\Gamma_s=1.
\]

Tilted species:

\[
0<v_s^2<1.
\]

## 5.2 Perfect-fluid rest-frame stress-energy

For a perfect fluid in its own rest frame,

\[
T^{(s)}_{ab}
=(\mu_s+P_s)u^{(s)}_a u^{(s)}_b+P_sg_{ab},
\]

where \(\mu_s\) and \(P_s\) are rest-frame energy density and pressure.

The normal-frame projections are

\[
\boxed{
\rho_s
=\Gamma_s^2(\mu_s+P_s)-P_s,
}
\]

\[
\boxed{
p_s
=P_s+\frac13\Gamma_s^2(\mu_s+P_s)v_s^2,
}
\]

\[
\boxed{
q^{(s)}_\alpha
=\Gamma_s^2(\mu_s+P_s)v^{(s)}_\alpha,
}
\]

\[
\boxed{
\pi^{(s)}_{\alpha\beta}
=\Gamma_s^2(\mu_s+P_s)
 v^{(s)}_{\langle\alpha}v^{(s)}_{\beta\rangle}.
}
\]

Total normal-frame quantities are sums:

\[
\rho=\sum_s\rho_s,
\quad
p=\sum_sp_s,
\quad
q_\alpha=\sum_sq^{(s)}_\alpha,
\quad
\pi_{\alpha\beta}=\sum_s\pi^{(s)}_{\alpha\beta}+\pi^{\rm rad}_{\alpha\beta}+\pi^{\nu}_{\alpha\beta}.
\]

## 5.3 Barotropic equations of state

For minimal background runs:

\[
P_s=w_s\mu_s,
\]

with default components

\[
w_c=0,
\qquad
w_b=0,
\qquad
w_\gamma=\frac13,
\qquad
w_\nu=\frac13,
\qquad
w_\Lambda=-1.
\]

Radiation anisotropic stress should eventually be supplied by the radiation multipole solver. For early background-only tests, one may set \(\pi^{\rm rad}_{\alpha\beta}=0\) and mark the run as `perfect_fluid_radiation_approx`.

## 5.4 Matter evolution algorithm from \(\nabla_bT^{ab}=0\)

For a non-interacting species,

\[
\nabla_bT^{ab}_{(s)}=0.
\]

Rather than hand-coding a type-specific tilted Euler equation, the solver should construct the conservation residual directly in tetrad components and solve for

\[
\dot\mu_s,
\qquad
\dot v_{(s)}^\alpha.
\]

For any tetrad tensor,

\[
\nabla_bT^{ab}
=e_b(T^{ab})
+\Gamma^a{}_{cb}T^{cb}
+\Gamma^b{}_{cb}T^{ac}.
\]

Because the background is homogeneous,

\[
e_\alpha(T^{ab})=0,
\]

while \(e_0(T^{ab})\) contains \(\dot\mu_s\) and \(\dot v_s^\alpha\). The time connection is supplied by

\[
\nabla_{e_\beta}e_0
=(H\delta_\beta{}^\alpha+\sigma_\beta{}^\alpha)e_\alpha
\]

after setting \(\Omega_\alpha=0\), and by the corresponding antisymmetric tetrad connection if \(\Omega_\alpha\ne0\).

Pseudocode:

```python
def species_rhs_from_conservation(species, geom):
    # unknown ydot = [mu_dot, v_dot_1, v_dot_2, v_dot_3]
    # build residual R^a = nabla_b T^{ab} - Q^a
    def residual(ydot):
        T = stress_energy_tetrad(species.mu, species.v, species.w)
        dT_dtau = stress_energy_time_derivative(species, ydot)
        R = covariant_divergence_T(T, dT_dtau, geom.full_connection)
        return R - species.interaction_Q

    # R^a is linear in ydot for a barotropic perfect fluid.
    M, b = linearize_residual(residual)
    ydot = solve(M, b)
    return ydot
```

Orthogonal check:

\[
v_s^\alpha=0
\quad\Rightarrow\quad
\dot\mu_s=-3H(\mu_s+P_s).
\]

Small-tilt check:

\[
q^{(s)}_\alpha\simeq(\mu_s+P_s)v^{(s)}_\alpha.
\]

## 5.5 Tilt admissibility

Tilt is physically allowed only when the total momentum constraint is satisfied:

\[
\sum_s\Gamma_s^2(\mu_s+P_s)v^{(s)}_\alpha
=
\kappa^{-1}(\mathrm{div}\,\sigma)_\alpha.
\]

Therefore the initial-condition builder must expose two valid modes:

**Mode T1: choose shear, solve total tilt.**

Input:

\[
\sigma_{\alpha\beta},\quad \mu_s,\quad w_s,
\quad \text{tilt direction fractions }r_{s\alpha}.
\]

Solve amplitudes \(V_s\) such that

\[
\sum_s\Gamma_s^2(\mu_s+P_s)V_s r_{s\alpha}
=
\kappa^{-1}(\mathrm{div}\,\sigma)_\alpha.
\]

**Mode T2: choose tilts, solve shear components.**

Input:

\[
v_s^\alpha,
\quad
\mu_s,
\quad
w_s,
\quad
\text{free shear shape parameters}.
\]

Solve the three linear Codazzi equations for three shear components or reject the IC if the chosen shear ansatz cannot support the momentum density.

A single tilted fluid is not automatically valid for every type. In types where \((\mathrm{div}\,\sigma)_\alpha=0\) for the selected shear ansatz, the total \(q_\alpha\) must vanish. Multi-species counter-streaming tilts are valid if the total \(q_\alpha\) satisfies Codazzi.

# 6. Background state vector and initialization

## 6.1 Minimal background state

The minimal background state is

\[
Y_B
=
\{H,\ \sigma_{\alpha\beta},\ C^\gamma{}_{\alpha\beta},\ \mu_s,\ v_s^\alpha\}_{s\in\mathcal S}.
\]

Constraints:

\[
\mathrm{tr}\,\sigma=0,
\qquad
C^\gamma{}_{\alpha\beta}=-C^\gamma{}_{\beta\alpha},
\qquad
n_{\alpha\beta}a^\beta=0,
\]

\[
\mathcal C_G=0,
\qquad
\mathcal C_{M,\alpha}=0.
\]

Optional normalized variables:

\[
\Sigma_{\alpha\beta}\equiv \frac{\sigma_{\alpha\beta}}{H},
\qquad
\mathcal C^\gamma{}_{\alpha\beta}\equiv \frac{C^\gamma{}_{\alpha\beta}}{H},
\qquad
\Omega_s\equiv \frac{\kappa\rho_s}{3H^2}.
\]

The dimensional form remains the reference implementation; normalized variables are a numerical convenience.

## 6.2 IC builder: orthogonal branch

Input:

\[
\text{Bianchi type},
\quad
C_i^\gamma{}_{\alpha\beta},
\quad
\mu_{s,i},
\quad
w_s,
\quad
\sigma_{i,\alpha\beta},
\quad
\Lambda.
\]

Set

\[
v_{s,i}^\alpha=0.
\]

Then

\[
q_{i,\alpha}=0,
\qquad
\pi_{i,\alpha\beta}=0
\]

for perfect-fluid matter, unless radiation/neutrino anisotropic stress is explicitly supplied.

Required constraints:

\[
(\mathrm{div}\,\sigma_i)_\alpha=0,
\]

\[
H_i=+\sqrt{\frac13\left(
\kappa\rho_i+
\Lambda+
\sigma_i^2-\frac12{}^{3}R_i
\right)}.

Pseudocode:

```python
def build_ic_orthogonal(type_name, algebra_params, species, sigma_shape, Lambda):
    alg = make_bianchi_algebra(type_name, algebra_params)
    assert norm(jacobi_residual(alg.a, alg.n)) < tol
    Ric, R3, S3 = spatial_ricci(alg.C)

    for s in species:
        s.v = zeros(3)

    rho, p, q, pi = total_matter_projections(species)
    sigma = pstf2(sigma_shape)
    assert abs(trace(sigma)) < tol

    Gamma = spatial_connection(alg.C)
    CM = div_pstf2(sigma, Gamma) - kappa*q
    if norm(CM) > tol:
        sigma = project_shear_to_codazzi(sigma, Gamma, q=zeros(3))

    sigma2 = 0.5 * contract(sigma, sigma)
    H2 = (kappa*rho + Lambda + sigma2 - 0.5*R3)/3.0
    assert H2 > 0
    H = sqrt(H2)
    return BackgroundState(H, sigma, alg.C, species)
```

def build_ic_tilted(type_name, algebra_params, species, sigma_or_ansatz, tilt_or_ansatz, Lambda):

## 6.4 Constraint projection policy

After each accepted integrator step:

1. Symmetrize and trace-remove \(\sigma_{\alpha\beta}\).
2. Reconstruct \(a_\alpha,n_{\alpha\beta}\) from \(C^\gamma{}_{\alpha\beta}\) and project to the nearest algebra satisfying \(n_{\alpha\beta}a^\beta=0\), if the residual exceeds tolerance.
3. Recompute matter projections.
4. Monitor \(\mathcal C_G\) and \(\mathcal C_{M,\alpha}\).
5. Optionally project \(H\) through Gauss if the user requested `constraint_projection="gauss"`.

Projection must be recorded. Silent projection is forbidden.

# 7. Background RHS pseudocode

```python
def rhs_background(tau, Y, config):
    H, sigma, C, species = unpack(Y)

    # 1. Algebra and geometry
    alg = algebra_from_C(config.type_name, C)
    Gamma = spatial_connection(C)
    Ric3, R3, S3 = spatial_ricci(C)

    # 2. Matter projections
    rho, p, q, pi = total_matter_projections(species)

    # 3. Covariant 1+3 equations
    sigma2 = 0.5 * contract(sigma, sigma)
    H_dot = -H*H - (2.0/3.0)*sigma2 - (kappa/6.0)*(rho + 3.0*p) + Lambda/3.0
    sigma_dot = -3.0*H*sigma - S3 + kappa*pi
    sigma_dot = pstf2(sigma_dot)

    # 4. Tetrad algebra evolution from Jacobi
    B = H*eye(3) + sigma + rotation_matrix_from_Omega(config.Omega)
    C_dot = jacobi_evolve_C(C, B)

    # 5. Species evolution from nabla_b T^{ab}=Q^a
    species_dot = []
    full_conn = build_full_tetrad_connection(H, sigma, C, config.Omega)
    for s in species:
        species_dot.append(species_rhs_from_conservation(s, full_conn))

    # 6. Diagnostics, not used as RHS unless projection enabled
    constraints = {
        "Gauss": 3*H*H - kappa*rho - Lambda - sigma2 + 0.5*R3,
        "Codazzi": div_pstf2(sigma, Gamma) - kappa*q,
        "Jacobi": jacobi_residual(alg.a, alg.n),
    }

    return pack(H_dot, sigma_dot, C_dot, species_dot), constraints
```

Integrator recommendation:

- Non-stiff background-only runs: DOP853 or high-order adaptive Runge--Kutta.
- Tilted relativistic fluids near \(v^2\to1\): implicit Radau or BDF with velocity limiter.
- Coupled radiation + Thomson scattering: IMEX or fully implicit collision step.

Hard velocity condition:

\[
v_s^2 < 1-\varepsilon_v.
\]

# 8. Photon tetrad transport

## 8.1 Photon momentum

Write the photon 4-momentum as

\[
k^a=E(n^a+e^a),
\]

where

\[
e^a n_a=0,
\qquad
e^ae_a=1.
\]

Tetrad components:

\[
e^\alpha e_\alpha=1.
\]

## 8.2 Energy redshift

For \(A_a=\omega_a=0\), the geodesic equation gives

\[
\boxed{
\frac{d\ln E}{d\tau}
=-H-\sigma_{\alpha\beta}e^\alpha e^\beta.
}
\]

If a reference scale factor \(a_{\rm ref}\) is defined by

\[
\frac{d\ln a_{\rm ref}}{d\tau}=H,
\]

then

\[
\boxed{
\frac{d\ln(a_{\rm ref}E)}{d\tau}
=-\sigma_{\alpha\beta}e^\alpha e^\beta.
}
\]

This is the minimal deterministic temperature-template equation. In collisionless propagation, the brightness perturbation obeys

\[
\dot\Theta(e)
= -\sigma_{\alpha\beta}e^\alpha e^\beta
-\text{monopole subtraction}
\]

when linearized around an isotropic blackbody.

## 8.3 Direction transport

The spatial direction evolves as

\[
\boxed{
\dot e^\alpha
= -\left(\delta^\alpha{}_{\beta}-e^\alpha e_\beta\right)
\sigma^\beta{}_{\gamma}e^\gamma
-\Gamma^\alpha{}_{\beta\gamma}e^\beta e^\gamma
-\epsilon^\alpha{}_{\beta\gamma}\Omega^\beta e^\gamma.
}
\]

The first term is shear lensing/drift on the observer sky. The second term is the Bianchi spatial algebra contribution. The third term is tetrad rotation and vanishes for the default Fermi frame.

Norm preservation test:

\[
\frac{d}{d\tau}(e_\alpha e^\alpha)=0.
\]

Pseudocode:

```python
def rhs_photon_direction(e, geom):
    sigma = geom.sigma
    Gamma = geom.spatial_connection
    Omega = geom.Omega

    shear_vec = sigma @ e
    shear_proj = -(eye(3) - outer(e, e)) @ shear_vec

    conn_vec = zeros(3)
    for alpha,beta,gamma in product(range(3), repeat=3):
        conn_vec[alpha] -= Gamma[alpha,beta,gamma] * e[beta] * e[gamma]

    rot_vec = -cross(Omega, e)
    return shear_proj + conn_vec + rot_vec
```

## 8.4 Screen basis and polarization rotation

Choose two screen vectors \(s_A^\alpha\), \(A=1,2\), satisfying

\[
s_A^\alpha e_\alpha=0,
\qquad
s_A^\alpha s_{B\alpha}=\delta_{AB}.
\]

The basis is parallel transported and reprojected to the screen:

\[
\dot s_A^\alpha
=\mathcal P^\alpha{}_{\beta}\left[-\Gamma^\beta{}_{\mu\nu}e^\mu s_A^\nu
-\left(H\delta^\beta{}_{\nu}+\sigma^\beta{}_{\nu}\right)s_A^\nu
-\epsilon^\beta{}_{\mu\nu}\Omega^\mu s_A^\nu
\right],
\]

where

\[
\mathcal P^\alpha{}_{\beta}=\delta^\alpha{}_{\beta}-e^\alpha e_\beta.
\]

After each step, Gram--Schmidt reorthonormalization is allowed and must be recorded as numerical stabilization.

Define the polarization rotation rate \(\psi\) relative to a chosen reference screen dyad by

\[
\dot m^\alpha=i\dot\psi\,m^\alpha+\text{basis-independent transport terms},
\]

where

\[
m^\alpha=\frac{1}{\sqrt2}(s_1^\alpha+i s_2^\alpha).
\]

The Stokes variables then obey

\[
\left(\frac{d}{d\tau}\right)(Q\pm iU)
\supset
\mp2i\dot\psi(Q\pm iU).
\]

# 9. Radiation variables in PSTF form

## 9.1 Distribution choice

The code authority variable is the photon occupation matrix, not raw specific intensity. For direction \(e^\alpha\), frequency \(E\), and screen dyad indices \(A,B\), define

\[
N_{AB}(E,e).
\]

The occupation matrix is Liouville invariant in collisionless transport. Frequency-integrated brightness variables may be used after blackbody or greybody assumptions are declared.

For low-\(\ell\) CMB temperature/polarization work, the default reduced state is

\[
\mathcal R_L
=
\{I_{A_\ell},E_{A_\ell},B_{A_\ell}\}_{0\le\ell\le L},
\]

where each object is PSTF with respect to \(h_{ab}\). The temperature brightness perturbation \(\Theta_{A_\ell}\) may be used in place of \(I_{A_\ell}\) after fixing normalization.

## 9.2 Angular PSTF expansion

For a scalar brightness field,

\[
I(e)
=\sum_{\ell=0}^{L} I_{A_\ell} e^{\langle A_\ell\rangle},
\]

where

\[
e^{A_\ell}=e^{a_1}\cdots e^{a_\ell}.
\]

For code, an orthonormal real-PSTF basis \(\mathcal Y_r(e)\) is recommended:

\[
I(e)=\sum_r I_r\mathcal Y_r(e),
\qquad
\int d\Omega\,\mathcal Y_r(e)\mathcal Y_s(e)=\delta_{rs}.
\]

This avoids normalization ambiguity in early implementation. A conversion layer maps between real-PSTF coefficients and \((\ell,m)\) coefficients.

## 9.3 Radiation anisotropic stress

The photon anisotropic stress that sources the background is the quadrupole:

\[
\pi^{\gamma}_{\alpha\beta}
\propto
I_{\alpha\beta}.
\]

The exact coefficient depends on brightness normalization. The code must define one normalization file:

```python
RadiationNormalization = {
    "I0_to_rho_gamma": ...,
    "I2_to_pi_gamma": ...,
    "E2_convention": ...,
    "B2_convention": ...,
}
```

No background-radiation feedback run is valid unless this normalization file is attached.

# 10. Electron-frame Thomson scattering

## 10.1 Electron frame

Electron 4-velocity:

\[
u_e^a=\Gamma_e(n^a+v_e^a).
\]

For photon direction \(e^a\), electron-frame photon energy is

\[
\boxed{
\tilde E
=-u_e^ak_a
=\Gamma_eE(1-v_{e\alpha}e^\alpha).
}
\]

Thus the direction-dependent scattering rate per normal-frame path length is proportional to

\[
\boxed{
\tilde\Gamma_T(e)
=n_e\sigma_T\Gamma_e(1-v_e\cdot e),
}
\]

when \(e^\alpha\) is the photon propagation direction. If another module uses the observed sky direction \(\hat n_{\rm sky}=-e\), the same factor is

\[
1+v_e\cdot\hat n_{\rm sky}.
\]

This sign convention must be tested.

## 10.2 Exact classical Thomson tensor

Let \(s_A^a(e)\) be the outgoing screen basis and \(s'_B{}^a(e')\) the incoming screen basis, both evaluated in the electron rest frame. Define the Jones projection matrix

\[
J_{AB}(e,e')=s_A^a(e)s'_{Ba}(e').
\]

The exact classical Thomson collision operator for the occupation matrix is

\[
\boxed{
C_{AB}^{\rm Th}(E,e)
=
-\tilde n_e\sigma_T N_{AB}(E,e)
+
\frac{3\tilde n_e\sigma_T}{8\pi}
\int d\Omega'\,
J_{AC}(e,e')N_{CD}(E,e')J^*_{BD}(e,e').
}
\]

This is “exact Thomson” in the classical electron rest frame. It is still linear in the radiation field. It is not a nonlinear Compton kernel.

Required tests:

\[
C[aN_1+bN_2]=aC[N_1]+bC[N_2],
\]

isotropic unpolarized radiation is a null mode,

\[
C[N_{AB}\propto\delta_{AB}]=0,
\]

and a pure quadrupole generates the standard polarization source in the FLRW scalar limit.

## 10.3 PSTF projection of Thomson scattering

The production PSTF solver should not hard-code only the FLRW scalar shortcut. It should project the exact electron-frame collision operator:

\[
\dot X_r\big|_{\rm Th}
=\int d\Omega\,\mathcal Y_r(e)C^{\rm Th}[N](e),
\]

where \(X_r\) are real-PSTF or spin-PSTF coefficients.

Pseudocode:

```python
def thomson_collision_projected(rad_coeffs, electron_frame, basis, quad):
    # reconstruct N_AB at angular nodes in the electron frame
    N_nodes = reconstruct_occupation_matrix(rad_coeffs, basis, quad.nodes)

    C_nodes = []
    for e in quad.nodes:
        out = -ne_tilde * sigma_T * N_at(e)
        inc = zeros((2,2), complex)
        for eprime, w in zip(quad.nodes, quad.weights):
            J = jones_projection(e, eprime, electron_frame)
            inc += w * J @ N_at(eprime) @ J.conj().T
        out += (3*ne_tilde*sigma_T/(8*pi)) * inc
        C_nodes.append(out)

    return project_to_pstf(C_nodes, basis, quad)
```

# 11. PSTF Boltzmann transport solver

## 11.1 Two equivalent production paths

The solver should support two mathematically equivalent paths:

**Path A: angular-grid reference solver.**

Evolve \(N_{AB}(E,e_i)\) on angular quadrature nodes using exact ray, screen-basis, redshift, and Thomson terms. This is slower but closest to the geometric equations.

**Path B: PSTF Galerkin solver.**

Evolve \(\{I_{A_\ell},E_{A_\ell},B_{A_\ell}\}_{\ell\le L}\) by projecting the exact angular operator onto a finite PSTF basis. This is the production path.

The two paths must share the same tetrad geometry and Thomson kernel.

## 11.2 Collisionless Liouville operator

For frequency-integrated brightness perturbations in a blackbody approximation, the collisionless operator is obtained from

\[
\frac{d}{d\tau}N_{AB}(E,e)=0
\]

with

\[
\dot E/E=-H-\sigma_{\alpha\beta}e^\alpha e^\beta,
\qquad
\dot e^\alpha=F^\alpha(e;C,\sigma,\Omega),
\qquad
\dot\psi=\Psi(e;C,\sigma,\Omega).
\]

For spin variables,

\[
\left(\partial_\tau
+F^\alpha\partial_{e^\alpha}
\right)(Q\pm iU)
\mp2i\dot\psi(Q\pm iU)
=C_\pm.
\]

The PSTF Galerkin RHS is

\[
\boxed{
\dot X_r
=\sum_s\mathsf L_{rs}^{\rm Bianchi}(H,\sigma,C,\Omega)X_s
+\mathsf C_{rs}^{\rm Th}(v_e,n_e)X_s
+S_r.
}
\]

The matrix \(\mathsf L^{\rm Bianchi}\) is built by quadrature or precomputed symbolic PSTF products. It must not assume FLRW spherical symmetry.

## 11.3 Galerkin projection pseudocode

```python
def radiation_rhs_pstf(tau, X, background, basis, quad, config):
    geom = geometry_from_background(background)

    # reconstruct fields on angular nodes
    fields = reconstruct_stokes_or_occupation(X, basis, quad.nodes)

    # collisionless angular transport
    L_nodes = []
    for node in quad.nodes:
        e = node.direction
        F = rhs_photon_direction(e, geom)
        psi_dot = polarization_rotation_rate(e, geom)
        redshift = -geom.H - contract2(geom.sigma, outer(e,e))
        L_nodes.append(apply_liouville(fields, node, F, psi_dot, redshift, basis))

    # electron-frame Thomson collision
    C_nodes_or_coeffs = thomson_collision_projected(
        X,
        electron_frame=background.electron_frame,
        basis=basis,
        quad=quad
    )

    # optional external source terms: recombination visibility, reionization, seed perturbations
    S = source_terms_pstf(tau, X, background, config)

    L_coeffs = project_to_pstf(L_nodes, basis, quad)
    return L_coeffs + C_nodes_or_coeffs + S
```

## 11.4 Low-\(\ell\) cutoff policy inside the solver

The solver cutoff \(L\) is a numerical truncation of the PSTF hierarchy, not an observational statement. Default development values:

\[
L=4\quad\text{minimal smoke},
\qquad
L=6\quad\text{baseline},
\qquad
L=8\quad\text{local convergence check}.
\]

If strong shear, large tilt, or rapid class-B curvature mixing excites higher multipoles, the run must increase \(L\) until the retained low-\(\ell\) coefficients stabilize.

Closure rule:

\[
X_{A_{L+1}}=0
\]

is allowed only as a first closure. A better closure uses asymptotic free-streaming from the angular-grid reference solver.

# 14. All 11 Bianchi types: orthogonal and tilted implementation sheets

The evolution equations are identical for every type. Only the algebra object changes. The following sheets specify how each type enters the common backend.

## 14.1 Type I

Algebra:

\[
a_\alpha=0,
\qquad
n_{\alpha\beta}=0,
\qquad
C^\gamma{}_{\alpha\beta}=0.
\]

Curvature:

\[
{}^{3}R_{\alpha\beta}=0.
\]

Orthogonal branch:

\[
q_\alpha=0,
\qquad
(\mathrm{div}\,\sigma)_\alpha=0
\]

is automatic because \(C=0\). The shear equation reduces to

\[
\dot\sigma_{\alpha\beta}=-3H\sigma_{\alpha\beta}+\kappa\pi_{\alpha\beta}.
\]

Tilted branch:

Since \((\mathrm{div}\,\sigma)_\alpha=0\), Codazzi requires

\[
q_\alpha^{\rm tot}=0.
\]

Thus a single tilted perfect fluid is not admissible unless another component cancels its momentum density or the matter sector carries compensating non-perfect stresses. Multi-species counter-streaming tilt is valid if the total momentum vanishes.

## 14.2 Type II

Algebra:

\[
a_\alpha=0,
\qquad
n_{\alpha\beta}=\mathrm{diag}(n,0,0)
\]

up to spatial permutations.

Orthogonal branch:

\[
q_\alpha=0,
\qquad
(\mathrm{div}\,\sigma)_\alpha=0
\]

becomes a nontrivial algebraic restriction on the allowed off-diagonal shear components. The IC builder must project \(\sigma_{\alpha\beta}\) onto the Codazzi surface.

Tilted branch:

Momentum density can be supported only in directions generated by

\[
(\mathrm{div}\,\sigma)_\alpha(C_{\rm II},\sigma).
\]

The code should solve Codazzi generically rather than using a handwritten type-II component formula.

## 14.3 Type VI\(_0\)

Algebra:

\[
a_\alpha=0,
\qquad
n_{\alpha\beta}=\mathrm{diag}(0,n,-n).
\]

Orthogonal branch:

Class A implies no \(a_\alpha\) term. Orthogonal ICs require the \(N\)-shear contraction in Codazzi to vanish:

\[
(\mathrm{div}\,\sigma)_\alpha=0.
\]

Tilted branch:

Allowed total tilt momentum is exactly

\[
q_\alpha=\kappa^{-1}(\mathrm{div}\,\sigma)_\alpha.
\]

Both signs in \((n,-n)\) make this type useful for testing sign stability of the curl and Ricci routines.

## 14.4 Type VII\(_0\)

Algebra:

\[
a_\alpha=0,
\qquad
n_{\alpha\beta}=\mathrm{diag}(0,n,n).
\]

Orthogonal branch:

Again \(q_\alpha=0\), so shear must satisfy the algebraic class-A Codazzi constraint.

Tilted branch:

Tilt is allowed when the total momentum matches the algebraic divergence of shear. Because VII\(_0\) has a helical spatial algebra with zero class-B vector, it is a clean test of helicity without class-B momentum effects.

## 14.5 Type VIII

Algebra:

\[
a_\alpha=0,
\qquad
n_{\alpha\beta}=\mathrm{diag}(-n,n,n)
\]

up to permutations and overall scale.

Orthogonal branch:

The anisotropic spatial Ricci \({}^{3}S_{\alpha\beta}\) is generally nonzero and sources shear even when \(\pi_{\alpha\beta}=0\). Codazzi still demands \(q_\alpha=0\).

Tilted branch:

The admissible tilt is fully determined by the class-A Codazzi relation. This type is numerically useful because the semisimple algebra tends to produce stronger curvature forcing than types I/II.

## 14.6 Type IX

Algebra:

\[
a_\alpha=0,
\qquad
n_{\alpha\beta}=\mathrm{diag}(n,n,n).
\]

Orthogonal branch:

The isotropic closed limit is obtained when

\[
\sigma_{\alpha\beta}=0,
\qquad
\pi_{\alpha\beta}=0,
\qquad
{}^{3}S_{\alpha\beta}=0.
\]

Anisotropic type IX runs can have strong curvature-induced shear dynamics, so adaptive stepping and constraint monitoring are mandatory.

Tilted branch:

Codazzi again fixes total \(q_\alpha\). Because type IX can be dynamically stiff, tilted runs should default to an implicit or semi-implicit integrator when \(|\sigma|/H\) becomes large.

## 14.7 Type V

Algebra:

\[
a_\alpha=(a,0,0),
\qquad
n_{\alpha\beta}=0.
\]

Orthogonal branch:

The open isotropic limit is recovered for

\[
\sigma_{\alpha\beta}=0,
\qquad
q_\alpha=0,
\qquad
\pi_{\alpha\beta}=0.
\]

Codazzi contains the class-B vector contribution through the connection-derived divergence operator. Do not replace it by the class-A formula.

Tilted branch:

Class-B geometry naturally supports momentum constraints involving \(a_\alpha\sigma^\alpha{}_{\beta}\). Therefore type V is a baseline class-B tilted test. ICs may be generated either by solving tilt from shear or shear from tilt.

## 14.8 Type IV

Algebra:

\[
a_\alpha=(a,0,0),
\qquad
n_{\alpha\beta}=\mathrm{diag}(0,0,n)
\]

or the equivalent permutation with one nonzero \(n\)-eigenvalue.

Orthogonal branch:

The orthogonal constraint surface is more restrictive than type V because both \(a_\alpha\) and one \(n\)-direction contribute to \(D^\beta\sigma_{\alpha\beta}\). The code must use the generic connection divergence.

Tilted branch:

Tilt can source momentum components coupled to both the class-B vector and the single \(n\)-eigenvalue. This type is a useful test of the general algebra backend because it is neither purely vector-curvature nor fully diagonal class-A.

## 14.9 Type III

Algebra:

Type III is implemented as a named class-B alias, conventionally corresponding to VI\(_h\) with \(h=-1\). A canonical choice is

\[
a_\alpha=(a,0,0),
\qquad
n_{\alpha\beta}=\mathrm{diag}(0,n,-n)
\]

with the normalization chosen so that the stored \(h\)-metadata equals \(-1\) under the code convention.

Orthogonal branch:

Set \(q_\alpha=0\) and project shear to the Codazzi surface. The code must not silently merge type III with a generic VI\(_h\) run unless metadata records the alias.

Tilted branch:

Tilt is allowed by the same class-B Codazzi relation. Type III is valuable as a special-point regression test for the VI\(_h\) family.

## 14.10 Type VI\(_h\)

Algebra:

\[
a_\alpha=(a,0,0),
\qquad
n_{\alpha\beta}=\mathrm{diag}(0,n_2,n_3),
\qquad
n_2n_3<0.
\]

Parameter:

\[
h=\frac{a^2}{n_2n_3}
\]

under the code convention, so \(h<0\). If the opposite convention is desired, it must be stored explicitly.

Orthogonal branch:

\[
q_\alpha=0
\]

is imposed by projecting shear to satisfy the full class-B Codazzi constraint. The anisotropic spatial Ricci source \({}^{3}S_{\alpha\beta}\) must be computed from \(C\), not from a type-specific formula copied from a fixed convention.

Tilted branch:

The total momentum density must satisfy

\[
q_\alpha=\kappa^{-1}(\mathrm{div}\,\sigma)_\alpha.
\]

The parameter \(h\), tilt vector, and shear orientation can be varied independently only after the constraints are solved. Raw input parameter independence is not physical independence.

## 14.11 Type VII\(_h\)

Algebra:

\[
a_\alpha=(a,0,0),
\qquad
n_{\alpha\beta}=\mathrm{diag}(0,n_2,n_3),
\qquad
n_2n_3>0.
\]

Parameter:

\[
h=\frac{a^2}{n_2n_3}>0
\]

under the code convention.

Orthogonal branch:

Set \(q_\alpha=0\) and solve the Codazzi constraint. The class-B helical algebra is handled by the same \(C\)-generated connection, curvature, and photon transport routines.

Tilted branch:

Tilted VII\(_h\) is a full class-B tilted test: electron tilt affects Thomson scattering, total tilt affects Codazzi, and the helical algebra affects photon direction and polarization-basis transport. None of these effects should be collapsed into a precomputed temperature template in the solver core.

# 15. Integrators and numerical strategy

## 15.1 Background integrator

Use adaptive integration for

\[
Y_B' = F_B(Y_B).
\]

Recommended choices:

- `DOP853`: default for smooth non-stiff orthogonal and mildly tilted backgrounds.
- `Radau` or `BDF`: relativistic tilt, strong type IX curvature dynamics, or radiation feedback.
- `IMEX`: when Thomson scattering and free streaming are coupled in one evolution system.

Step acceptance must check:

\[
|\mathcal C_G| < \epsilon_G,
\qquad
\|\mathcal C_M\| < \epsilon_M,
\qquad
\|n_{\alpha\beta}a^\beta\|<\epsilon_J,
\qquad
|e^2-1|<\epsilon_e.
\]

## 15.2 Radiation integrator

The low-\(\ell\) radiation equation is schematically

\[
\dot X
=\mathsf L_B(\tau)X+
\mathsf C_T(\tau)X+S(\tau).
\]

When \(\Gamma_T\gg H\), \(\mathsf C_T\) is stiff. Use one of:

1. implicit collision step,
2. tight-coupling algebraic closure,
3. operator splitting:

\[
X(\tau+\Delta\tau)
\approx
\exp(\Delta\tau\mathsf C_T)
\,
\mathcal T\exp\left(\int_\tau^{\tau+\Delta\tau}\mathsf L_Bd\tau'\right)
X(\tau)
+\text{source integral}.
\]

## 15.3 Constraint-aware stepping pseudocode

```python
def integrate_background(Y0, tau_span, config):
    solver = make_integrator(config.integrator)
    Y = Y0
    tau = tau_span[0]
    while tau < tau_span[1]:
        Y_trial, err = solver.propose_step(rhs_background, tau, Y)
        residuals = compute_constraints(Y_trial, config)
        if err < config.err_tol and constraints_ok(residuals, config):
            Y = maybe_project_constraints(Y_trial, residuals, config)
            tau = solver.accept()
            save_diagnostics(tau, Y, residuals)
        else:
            solver.reject_and_reduce_step()
    return trajectory
```

## 15.4 Full solver loop pseudocode

```python
def run_bianchi_solver(config):
    # 1. Build algebra and constraint-satisfying background IC
    if config.tilt.enabled:
        YB0 = build_ic_tilted(...)
    else:
        YB0 = build_ic_orthogonal(...)

    # 2. Build radiation IC in electron frame, then transform if needed
    XR0_electron = build_radiation_ic_electron_frame(config)
    XR0 = transform_radiation_to_normal_frame(XR0_electron, YB0.electron_velocity, config)

    # 3. Integrate coupled or background-then-radiation system
    if config.coupling == "background_then_radiation":
        BG = integrate_background(YB0, config.tau_span, config)
        XR = integrate_radiation_on_background(XR0, BG, config)
    elif config.coupling == "fully_coupled":
        Y0 = pack(YB0, XR0)
        Y = integrate_coupled_einstein_boltzmann(Y0, config)
        BG, XR = unpack_solution(Y)

    # 4. Export solver-level products only
    return SolverCoreOutput(
        background=BG,
        radiation_pstf=XR,
        constraints=load_constraint_history(),
        convention_metadata=config.conventions,
    )
```

The solver-core output may include maps or \(a_{\ell m}\) as serialized representations, but it must not compute anomaly p-values or data likelihoods in this document's module boundary.

# 16. Validation gates

## 16.1 Algebra gates

For all 11 Bianchi types:

\[
C^\gamma{}_{\alpha\beta}=-C^\gamma{}_{\beta\alpha},
\]

\[
n_{\alpha\beta}a^\beta=0,
\]

\[
\Gamma^\gamma{}_{\beta\alpha}
-
\Gamma^\gamma{}_{\alpha\beta}
=C^\gamma{}_{\alpha\beta},
\]

and spatial Ricci symmetry

\[
{}^{3}R_{\alpha\beta}={}^3R_{\beta\alpha}
\]

must hold.

## 16.2 Background gates

For every type and both orthogonal/tilted branches where admissible:

\[
|\mathcal C_G|/H^2<\epsilon_G,
\qquad
\|\mathcal C_M\|/(H^2/\sqrt\kappa)<\epsilon_M,
\]

with a documented dimensional normalization.

Type I no-stress test:

\[
{}^{3}S_{\alpha\beta}=0,
\qquad
\dot\sigma_{\alpha\beta}+3H\sigma_{\alpha\beta}=0.
\]

Orthogonal FLRW subcases:

- type I flat limit,
- type V open limit,
- type IX closed limit.

These are tests of isotropic submanifolds, not restrictions on the anisotropic exploration program.

## 16.3 Photon gates

Norm preservation:

\[
e_\alpha e^\alpha=1.
\]

FLRW redshift:

\[
\sigma_{\alpha\beta}=0
\quad\Rightarrow\quad
E\propto a_{\rm ref}^{-1}.
\]

Type I analytic redshift:

For diagonal Bianchi I with directional scale factors \(a_i\), covariant photon momenta are conserved and

\[
E^2(\tau)=\sum_i\frac{p_i^2}{a_i^2(\tau)}.
\]

The tetrad ray solver must reproduce this relation.

## 16.4 Thomson gates

Linearity:

\[
C[aN_1+bN_2]=aC[N_1]+bC[N_2].
\]

Isotropic null:

\[
N_{AB}=f(E)\delta_{AB}
\quad\Rightarrow\quad
C_{AB}^{\rm Th}=0.
\]

Electron-frame sign:

\[
\tilde E/E=\Gamma_e(1-v_e\cdot e)
\]

must be verified by explicit Lorentz transformation.

## 16.5 PSTF/angular-grid agreement

For each of a representative set of Bianchi types, run both:

- angular-grid reference transport,
- PSTF Galerkin transport.

The projected low-\(\ell\) coefficients must agree within truncation error:

\[
\|X^{\rm grid}_{\ell\le L_*}-X^{\rm PSTF}_{\ell\le L_*}\|
\le
\epsilon_{L_*}.
\]

# 18. Final implementation contract

A result is solver-core valid only if it provides:

1. the Bianchi algebra metadata \((a_\alpha,n_{\alpha\beta},C^\gamma{}_{\alpha\beta},h\text{ convention})\),
2. the 1+3 state \((H,\sigma_{\alpha\beta},\rho,p,q_\alpha,\pi_{\alpha\beta})\),
3. Gauss/Codazzi/Jacobi residual histories,
4. orthogonal or tilted species metadata,
5. photon transport convention \((e^\alpha\text{ propagation direction},\hat n_{\rm sky}=-e\text{ if used})\),
6. radiation normalization metadata,
7. Thomson frame metadata,
8. integrator tolerances and projection policy.

The architecture can then explore beyond-FLRW anisotropic cosmologies by changing only the algebra object and physical initial data, while preserving a single covariant PSTF/tetrad code path.

\[
\boxed{
\text{Bianchi type} = \text{tetrad algebra input};
\qquad
\text{physics} = \text{1+3 PSTF equations + constraints + radiation transport}.
}
\]
