# PR-CATALOG-003 — 연구제안 정리 후보와 내부 보조명제의 역할 구분

사용자 요청에 따라 기존 40,282개 명제·후보 묶음에 역사적 연구 역할을 추가한다.
과거 제안 문서의 구체적인 명제 구간, 사용된 보조정리의 선언·호출 근거를 대조한다.
원본 증명 분류와 SQLite를 보존하고 불명확한 역할은 보류한다. 신규성 문헌 조사,
새 증명, CAS·연구 코드 실행, 수학적 동치 통합은 범위 밖이다.

카탈로그 전용 테스트, 재생성 동일성, 독립 근거 검토 후 일반 push 및 원격 조회를 확인한다.

카탈로그 테스트 최종 54 PASS, DAG 197개 구조 PASS. 독립 원문 검토 365개 근거에 실질적 결함 없음.
반복 내보내기 31개 파일은 동일했다. 학술 신규성·새 증명·수학적 동치 통합은 수행하지 않았다.
[역할별 길잡이](../project_catalog/proofs/roles/README.md)와 [검수](../project_catalog/proofs/roles/REVIEW.md)에
집계 단위, 미대응 후보 구간, 역할 보류 및 훅 전달 한계를 공개한다.
