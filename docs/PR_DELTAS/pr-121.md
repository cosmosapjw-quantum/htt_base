## External documentation verification

Current packaging behavior was checked against primary documentation on
2026-07-15:

- Setuptools package discovery documents that `pyproject.toml` discovery scans
  implicit namespaces by default and that `namespaces = false` disables that
  behavior: <https://setuptools.pypa.io/en/stable/userguide/package_discovery.html>.
- Setuptools data-file rules document the precedence of explicit
  `package-data`, `exclude-package-data`, and `MANIFEST.in`:
  <https://setuptools.pypa.io/en/stable/userguide/datafiles.html>.
- Pip documents distinct regular and editable local-install semantics and
  warns that behavior can differ by build backend:
  <https://pip.pypa.io/en/stable/topics/local-project-installs/>.
- The PyPA wheel specification requires `RECORD` membership and secure hashes
  for every wheel member except the unhashed `RECORD` self-row:
  <https://packaging.python.org/en/latest/specifications/binary-distribution-format/>.

## Implemented increment

- Made `bass-py` the sole distribution carrying Python namespace files. The
  `htt==8.3.0` compatibility project is a fileless metapackage with one exact
  dependency on `bass-py==0.8.2+w8.2`; its `pyproject.toml` is the metadata
  SSoT and its legacy `setup.py` contains only `setup()`.
- Disabled implicit namespace discovery, excluded build/egg/bytecode caches,
  and replaced package-data globs with exact runtime fixture filenames.
  Clean and injected-cache source snapshots build byte-identical wheels, while
  injected matching-name untracked data is absent from the wheel.
- Restricted the compatibility sdist to packaging metadata/documentation and
  verified that its PEP 660 finder has empty package/namespace mappings and no
  source-root path.
- Aligned repository-root and installed `htt` wrappers, made nested HTT modules
  lazy, prevented `import htt` from mutating `sys.path` or
  `HTT_PIPELINE_OUTDIR`, and preserved canonical object identity and module
  metadata for arbitrary nested compatibility aliases in both import orders.
- Migrated active `htt.bass.*` consumers to canonical `bass.*` imports. Kept
  historical `htt.teff.*` imports in the frozen reproduction lane and marked
  the packaged top-level `teff` surface explicitly `TSC_LEGACY`; historical
  `owner: TEFF` payload metadata cannot authorize new active work.
- Added installed-resource lookup for observational defaults and exact wheel
  package data for the tracked runtime fixtures; scientific result payloads
  under `workspace/results` are not distributed.
- Added COMMON-owned package topology, archive-safety, collision, exact
  dependency, wheel `RECORD`, bound-input, structured-hash, and receipt
  validators.
- Preserved the declared Python 3.10 floor with a conditional `tomli`
  dependency and guarded fallback in the packaged topology helper, replay
  runner, and packaging regression entrypoint.
- Added a SPEC-driven hermetic replay runner and mutation suite that uses only
  a Git-index snapshot, a content-addressed dependency layer, sanitized
  no-network environments, unrelated CWDs, and isolated Python invocations.
- Sealed the shared dependency layer physically read-only (`0444`/`0555`
  files, `0555` directories) and verified its byte, type, shape, and full-mode
  manifest before and after the build and every install cell.
- Assigned every install cell a distinct writable `TMPDIR` below its private
  cell root. Receipt validation requires exact baseline/build/cell phase
  identities, non-null SHA-256 values, positive shape counts, and all six
  private temporary-directory records; the Markdown exposes all 15 phase rows.
- Replayed the actual installed `python -I -m common.status_snapshot --write`
  path in every cell, then independently parsed and matched all three generated
  companions: status snapshot, claim ledger, and status matrix.
- Retired PR-120's six reviewed sidecar pins after their exact bytes became
  Git-HEAD tracked by the PR-120 commit. The quarantine checker still rejects
  every unused transitional pin and the canonical inventory/block artifacts
  remain current.

  covariance, transfers, native solver output, or family identification.

  documented blockers. None is counted as a pass.

  data work skipped.
