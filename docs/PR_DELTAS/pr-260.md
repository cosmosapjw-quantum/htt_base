## Reproduced source ambiguity

The supplied sources do not define a mathematical Pillar T containing 65 rows
and a statistical Pillar S containing 58 rows. They define:

- 65 frozen legacy signature rows partitioned as `31 T + 34 S`;
- 58 proposal-registry rows partitioned as `30 I + 24 II + 4 BRIDGE`;
- proof obligations `U1–U9`, `TC-01–20`, and `ST-01–25`; and
- new obligations `VT-T1–14` and `VT-S1–14`.

Reclassifying all 65 rows as theory or all 58 rows as statistics would silently
change the supplied scientific ownership. The intake therefore records
`requested_pillar_T_65` and `requested_pillar_S_58` as cardinality aliases only,
with a machine-enforced semantic guard retaining the true source partitions.
