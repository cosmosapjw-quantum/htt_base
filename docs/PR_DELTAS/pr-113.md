## Chosen plan

- Add `scripts/audit_manuscript_figures.py` with public builder/rendering
  functions and a deterministic CLI.
- Parse manuscript TeX files, strip comments, extract `\graphicspath` and
  `\includegraphics`, and resolve extensionless references against expected
  graphics suffixes.
- Classify existing references through PR-011 quarantine data as `resolved` or
  `quarantined`; classify absent references as `missing`.
- Compose with PR-015 forbidden-claim scanning and add narrow manuscript text
  risk detection for manual status numbers, solver-validation wording,
  overstrong validation wording, production-value wording, and pre-native
  family-ID wording.
- Render generated Markdown reports with owner, implementation scope, claim
  tier, transfer source, sky/null status, config hash, input hashes, caveats,
  generating command, git commit, and worktree state.
- Store text issue rows as source/type/rule/text-digest rows rather than
  unsafe source-text quotes.

## Review findings and fixes

- Finding: the first scanner pass missed the manuscript line that implies
  pre-native family-ID enablement.
  - Fix: added `premature_family_identification` risk detection with an
    explicit negative-guardrail allowance for wording that says family-ID is
    not established or remains blocked.
- Finding: generated reports initially quoted unsafe manuscript text, causing
  broader claim scanners to fail on the audit artifacts themselves.
  - Fix: report text issue rows now include source, issue type, rule id, and
    SHA-256 text digest, not verbatim source text.
- Finding: the test fixture contained contiguous unsafe phrases and a rule-id
  literal that triggered scanner scripts when tests were scanned as source.
  - Fix: fixture strings and the MIO rule id are constructed at runtime without
    embedding scanner-triggering text in one source line.
- Finding: PR-113 should block manuscript freeze, but the PR-card dry-run
  command should remain usable as a deterministic inventory command.
  - Fix: dry-run reports findings with exit zero; the generated
    missing/quarantined report and handoff blockers carry the freeze-blocking
    state.
