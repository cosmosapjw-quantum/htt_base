## What it does

`htt/obsstat/desi_exact_selection_mock.py` + the heavy real-data card producer
`scripts/desi_exact_selection_card.py` (reads the ~2.3 GB randoms once, ACT
pattern; the runner reads the card).

1. **Exact-selection mock.** The mock draws from the REAL random-catalogue
   density per cap (`alpha·Rp·(1 + δ_clustering + …)`, Poisson-sampled), so the
   survey selection/window/cap is matched exactly — not a binary mask. The
   NGC/SGC cap ratio (2.83) is **source-derived** from the data counts (NGC
   4.08M, SGC 1.44M), never hard-coded.

2. **Per-mock refit.** On every mock (and the observed data) the random-to-data
   normalisation `alpha` (per cap) AND a systematic nuisance amplitude `beta`
   (Rp-weighted LS against the imaging template) are re-fit — never fixed. The
   **RAW** dipole is the primary observable (**|D| = 0.00949**, matching the
   window-corrected value); the nuisance-cleaned dipole (0.00196) is a
   **disclosed secondary** because the imaging template's ℓ=1 part is degenerate
   with the dipole estimand.

3. **Two-tier covariance.** A fast tier (clustering+shot) is compared to a
   high-realism tier carrying a **per-mock random, un-modelled ℓ≥2 imaging
   systematic the estimator does not fit**; the trace ratio (0.94) and the
   **relative Frobenius gap** (0.47, full eigenstructure) show the fast tier
   under-estimates the covariance when that systematic is present.

4. **Component confusion matrix.** Clustering/kinematic/selection are each
   injected at a matched dipole-scale amplitude and read by the same estimator;
   confounding is asserted only when the off-diagonal leakage is a **material
   fraction** of the diagonal response (selection → dipole channel at 0.68 of the
   kinematic response; kinematic → nuisance channel at 0.29) — not a `>0`
   tautology.

5. **Survey-conditional null (attribution abandoned).** The official DESI DR1
   validation mocks (1000 EZmocks + 25 AbacusSummit) are NOT on disk, so per the
   KILL rule causal attribution is abandoned; only the **two-sided**
   survey-conditional pooled-rank null is reported — the RAW observed dipole is
   in the **bulk** (percentile 0.28, p=0.721), consistent, no excess AND no
   deficit.

## Multi-lane adversarial review

Workflow (3 refute-lenses — statistics / claim-honesty / data-provenance — each
find→verify, effort high). **No P0; 10 findings, all CONFIRMED (0 refuted), all
fixed pre-commit.** They clustered into three real defects:

- **Silent signal deflation (P1×2 + P2×2)** — the original nuisance template was
  `vec[2]` (the z basis vector), collinear with the dipole's z-component, so
  `per_mock_refit` subtracted the dipole's own N-S axis into the "nuisance",
  deflating the reported observed amplitude (0.00229 vs raw ~0.0095) undisclosed,
  and the survey-conditional null then tested only the cleaned residual. Fixed:
  the **RAW** dipole is now the primary observable (no deflation), the cleaned
  dipole is a disclosed secondary, the fit template is an ℓ=1+ℓ=2 mix whose ℓ=1
  degeneracy is stated, and the null is **two-sided** (a deficit is now visible).
- **Vacuous two-tier validation (P1 + P2×2)** — the high-realism tier injected
  the same template the fit removes (and a deterministic systematic contributes
  0 to the cross-mock covariance), so the tiers agreed by construction. Fixed:
  the high-realism tier now injects a **per-mock random ℓ≥2 systematic not in the
  fit basis**, and agreement is measured by the relative Frobenius gap (full
  eigenstructure), not the trace alone.
- **Tautological confounded flag (P1 + P2×2)** — `>0.0` on positive floats is
  always True. Fixed: confounding requires the off-diagonal leakage to exceed a
  pre-registered **material threshold** (0.10) relative to the diagonal response,
  with matched-amplitude injections.
