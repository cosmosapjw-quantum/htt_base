## Chosen plan

- Added `htt.departure.local_global_mixture` at the live package root
  `htt/htt/htt/departure/local_global_mixture.py`, correcting the stale
  `htt/src/htt/...` PR-card path in all backlog mirrors.
- Added `LocalGlobalMixtureBlock`, `LocalGlobalMixtureSpec`,
  `LocalGlobalMixtureReport`, and `build_local_global_mixture_report()`.
- Required exactly one `local_boost`, `global_tilt`, `survey_systematic`, and
  `noise` block, with distinct primitive parameter names and distinct field
  IDs. The builder rejects a shared local/global beta field and rejects
  F/G/G_F names as primitive parameters.
- Composed PR-060 `require_rank_audit_for_model_run()`, PR-061
  `evaluate_global_tilt_local_null_gate()`, and PR-062
  `evaluate_survey_systematic_null_gate()` as fail-closed prerequisites.
  Gate reports and hashes are manifest inputs and statistics definitions; they
  are not likelihood weights.
- Added a response-consistency gate so a passing PR-060 audit can only certify
  the local/global responses used by the current mixture blocks.
- Added a whitened full-design rank/condition gate over local boost, global
  tilt, and survey/systematic response columns, blocking collinear or
  near-collinear designs before likelihood evaluation.
- Implemented a small positive-definite Gaussian skeleton only when gates pass,
  with noncanonical diagnostic fit scores emitted as generated functionals.
  Blocked reports have no likelihood value and carry blocked claim tier.
- Added manifest-validator provenance fields to the report payload:
  `sky_support_status`, `null_mock_status`, `git_commit_or_worktree_state`,
  plus top-level config/input provenance.
- Exported the new module through a lazy `htt.departure.__getattr__` so
  existing `htt.nulls -> htt.departure.response_overlap` imports do not form a
  cycle.

Rejected alternatives: placing this under MIO or COMMON, extending the
diagnostic discrimination matrix with likelihood semantics, accepting a single
beta parameter shared by local/global blocks, primitive fitted F/G inputs,
accepting unrelated PR-060 audit responses, and any native solver, morphology
compatibility, geometry, or family-identification claim.

## Claim-tier impact

This PR adds an HTT-owned pre-solver mixture-likelihood skeleton. Passing its
prerequisite gates yields at most a conditional local/global discrimination
candidate while the artifact production status remains diagnostic-only
pre-native. The generated diagnostic fit scores are computed from the primitive
block evaluation and gate state; they are not primitive parameters, posterior
odds, evidence terms, MIO certificate content, native solver output, morphology
compatibility evidence, or geometry/family-identification evidence. The emitted
generated diagnostics intentionally avoid canonical F/G/G_F payload keys so
they cannot be mistaken for MIO x/Q/Pi/F/G diagnostics.

- owner: HTT
- implementation_scope: htt
- pr_scope: pre-solver
- claim_tier: blocked when prerequisites fail; conditional candidate ceiling
  when PR-060/061/062 gates pass
- transfer_source: none
- sky_support_status: not_directional
- null_mock_status: PR-061 local-null and PR-062 survey/systematic prerequisite
  reports required for ready reports
- covariance_status: positive-definite diagnostic covariance required
- ppc_status: not_applicable
- loocv_status: not_applicable
