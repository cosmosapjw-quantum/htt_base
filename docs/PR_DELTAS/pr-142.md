## Typed MeasureSpec + three distinct measures

`htt/src/common/mio_joint_measure.py`: a typed `MeasureSpec` (identity in
canonical component order, weights, pairing, depth/reference policy, and a
declared per-component reference noise scale) defines three DISTINCT
diagnostics over a departure-component table (Sigma^2, W^2, Omega_tilt,
DeltaOmega_k): F (a weighted second-moment / RMS magnitude), Pi (a weighted
first-moment / signed contrast), and G_F (the SET-VALUED feasible range of
F over an identified set). F, Pi, and Q are never interchangeable, and none
of them is a posterior, an evidence, an HTT likelihood, or a truth
certificate — MIO reports, it never manufactures inference.

## Measure-appropriate matched-null calibration

Each measure is calibrated against a MATCHED null (same spec) that is
appropriate to the measure: Pi (a signed contrast) against a symmetric
sign-flip null with a TWO-SIDED p-value; F (a magnitude) against a
reference-scale null whose per-component noise scale is VALIDATED against
the data's robust (MAD) scale, one-sided upper. A sign-flip null for the
second-moment F is DEGENERATE (F is sign-invariant) and refused. Each
measure also reports its permutation invariance, a pairing counterexample
(a paired spec differs from an unpaired one), a depth-policy sensitivity,
and a bootstrap uncertainty that respects the spec's estimand (a paired
spec resamples pair clusters). A calibrated scalar is emitted only when a
scientifically-justified measure is registered; otherwise the status is
`no_justified_measure` and only the measure-family sensitivity is reported.
Changing the weights or pairing after the result requires a NEW registered
diagnostic family with updated look-elsewhere multiplicity.
