## Four explicit competitors + mandatory abstention

`htt/src/common/mixture_competition.py`: a fixed, pre-registered model
list — isotropy (null), a local kinematic boost (dipole), a survey /
calibration systematic (a known template), and a shared global anisotropy
(quadrupole). Each amplitude has a normalized Gaussian prior; the exact
marginal evidence is `N(y; 0, sig2 I + tau2 X X^T)`. For any data the
framework computes each model's evidence, an identifiability check, an
out-of-sample predictive gain over the null, a posterior-predictive
adequacy check, and the evidence sensitivity across a prior-scale grid.
The ONLY admissible non-null result is a discrimination CANDIDATE when a
non-null model is decisively favored (a look-elsewhere-adjusted margin)
AND identified AND adequate AND predicts held-out data better than the
null AND is not prior-sensitive; otherwise the mandatory result is
`abstain` / `non_identified`.

## Recovery / confusion / abstention matrix

Over 12 synthetic cells (3 regimes x 4 true branches): the clean regime
recovers local/sys/global and abstains on iso (no gain); the confused
regime (a nearly collinear dipole/systematic pair) abstains
`non_identified` on the local/sys pair and recovers global; the weak
regime abstains everywhere (no predictive gain). Two additional demos
exercise the remaining gates — a global signal with heavy outlier
contamination abstains `inadequate` (PPC p ~ 5e-4), and a marginal global
signal over a wide prior grid abstains `prior_sensitive`. A THIRD demo (a
genuine local+global superposition, a signal outside the single-component
list) abstains `non_identified` because the combined model materially
beats the best single model.

## Anti-drift, enforced on the production path

Residuals are never all absorbed into the global component; a MIO score
is never a likelihood factor; the deterministic (profile / fixed-
amplitude) branch is compared separately and never used for model
comparison; the model list is fixed and pre-registered (changing it after
the outcome requires a new registered family and updated look-elsewhere
multiplicity — the automatable list-fingerprint part is enforced, the
post-hoc human-change rule is a documented process control); and a
discrimination candidate is never a detection, a geometry, or a Bianchi
family. Every anti-drift guard is invoked LIVE inside `discriminate()`
(with the admissible inputs) so a drift supplies a rejected input.

## Adversarial review lane (multi-lane, pre-commit)

Three refute-prompted lenses (discrimination/abstention correctness;
statistical validity/determinism; guard liveness/overclaim), each
verifying against scipy and direct simulation, plus an adversarial
verification pass. No P0. Two CONFIRMED P1 were fixed: (1) the
identifiability gate was `(ev_gap < gap) AND collinear`, which structurally
could NEVER fire for the orthogonal-template local/global pair — so the
module's headline discrimination had no confusion guard and returned a
noise-flipped candidate on a superposition. Fixed: identifiability is now
governed by the EVIDENCE GAP alone (collinearity is reported as the
mechanism when present, never a necessary condition), plus a combined-model
gate that abstains when the data want more than one component. (2) Four of
six mutations killed guards the production path never invoked — fixed by
wiring every anti-drift guard live into `discriminate()`. Two P2 were fixed
(a look-elsewhere penalty for selecting the max evidence over three
competitors; the model-list process-rule limit documented). The clean
9-cell matrix is preserved and a strong superposition now reliably abstains
(combined gain 14-25).
