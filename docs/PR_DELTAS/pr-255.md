## Implemented changes

1. Added `common.anchored_response_geometry` as the single numerical contract
   for
   \[
   J_{\mathcal A}=P_{\rm nuisance}C_{\rm supp}^{-1/2}R D_{\mathcal A}.
   \]
   It returns supported rank, original rank, singular spectrum, reachable and
   null anchored directions, nuisance rank, principal angles, exact replay
   matrices, and covariance-null response.
2. Required the normalizer to be available, invertible, coordinate-label
   matched, and explicitly registered for `RESPONSE_CONDITIONING`. A
   numerically apparent rank change after right scaling fails closed.
3. Added `TransferSource` to every response geometry call. `none` requires a
   digest-shaped receipt identity and forbids a transfer spec; the frozen
   benchmark derives that receipt from an explicitly serialized synthetic
   response descriptor. Every non-`none` source requires a complete matching
   `TransferFunctionSpec`. Transfer and mask fields are receipt identities,
   not automatically verified byte-content claims. Covariance identifiers are
   separately recomputed from canonical numeric bytes and must match exactly.
   Missing identity fields return typed `MISSING_INPUT`; conflicting
   provenance raises.
4. Added a same-joint-covariance Schur contract:
   \[
   R_{m|b}=R_m-C_{mb}C_{bb}^{+}R_b,\qquad
   S=C_{mm}-C_{mb}C_{bb}^{+}C_{bm}.
   \]
   Incremental morphology information is computed from `R_m|b` and `S`, then
   added to the baseline information matrix. It is never a subtraction of
   statistics produced under different covariance models.
5. Added a local Gaussian identified-subspace contraction report. A finite
   confidence-ellipsoid volume ratio is emitted only when baseline and joint
   information have the same identified subspace. Rank gain, changed
   subspace, or no identified subspace has a structural status and no finite
   ratio. Global feasible-set contraction is explicitly `NOT_COMPUTED` because
   this change-set does not receive a feasible-set object.
6. Kept singular covariance explicit. The supported quotient is used for
   whitening, while any response in the covariance null space is returned
   separately as `EXPLICIT_NULL_RESPONSE` or
   `OUTSIDE_SUPPORTED_QUOTIENT`; it is never assigned zero cost. Support and
   Schur decisions are made in channel-standardized covariance coordinates,
   so diagonal observable-unit congruences cannot change rank, information,
   null-response status, or scalar-reduction eligibility. PSD validity uses a
   separate machine-backward-error bound rather than the support `rtol`. The
   standardized joint covariance is truncated to its supported quotient once,
   before any Schur block is formed, so a near-singular mode excluded from the
   joint quotient cannot be normalized back to unit variance and reintroduced
   downstream.
7. Added a typed eight-cell nonlinearity phase report covering linear
   anchor-compatible, linear premise-mismatch, nonlinear anchor-compatible,
   nonlinear plus exceedance, frame mismatch, derivative failure, systematics
   mimic, and unknown source.
8. Each phase cell now serializes its anchor interval, `T_parallel`, `T_perp`,
   `Delta_NL` or an explicit not-computed status, covariance-null residual,
   held-out and matched-injection nonlinear gain over the best registered
   control, and attribution status. Coverage is reported by the repeated
   synthetic benchmark where it is defined; nonlinear DGP cells use an
   explicit `NOT_APPLICABLE` status rather than a fabricated coverage number.
9. Anchor stress is never passed into candidate scoring and
   `stress_used_for_attribution` is factory-fixed to false. Incomplete
   competition, a winning registered alternative, an unknown source,
   non-identification, missing response, or covariance-null residual
   abstains.
10. Added a COMMON-owned HTT re-export. HTT retains model-dependent ownership
    of the existing source competition; COMMON owns only the matrix and
    semantic contracts.
11. Preserved
    `htt.statistics.mes_information_gain.build_mes_information_gain_report`
    byte-for-byte for historical result-pack replay. The new active
    compatibility adapter accepts only a measured exact one-dimensional
    baseline/joint reduction without covariance-null response. Multidimensional
    geometry, rank gain, or unsupported response is rejected.
12. Added a frozen synthetic benchmark with seed `20260728`, 60/20/20
    identity-bound partitions, adaptive Monte Carlo precision, per-cell

13. Added a separate direct-Fisher oracle with seed `20260729`. Across 300

## Mathematical and statistical boundary

The implementation uses a finite-dimensional Gaussian response geometry on
the positive-eigenvalue support of one declared covariance. The normalizer is
an invertible coordinate transformation on the declared parameter channel.
It may change singular values and numerical conditioning but cannot add
response rank or data information.

The Schur report is conditional information under one declared joint
covariance. Its finite contraction number is a local Gaussian
confidence-ellipsoid volume ratio, not a global partial-identification
feasible-set contraction, posterior volume, Bayes factor, e-value, or evidence
for a physical source.

The phase diagram combines two non-convertible outputs:

- an anchor interval, used only to state consistency or exceedance of the
  registered premise body; and
- a held-out/matched-injection source-competition result from PR-251.

`Delta_NL` remains absent unless a separately registered nonlinear model
manifold supplies that distance. A large `T_perp` without a winning registered
nonlinear candidate is `UNATTRIBUTED_OFF_MANIFOLD`.
