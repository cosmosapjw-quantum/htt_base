# PR-032 - Legacy theorem-to-test map retained for audit only

## Goal

- Owner: COMMON
- Depends: PR-030, PR-031
- Level: L2
- Scope: pre-solver
- Risk: medium

Retain the legacy TSC/Teff theorem-to-test map as a generated COMMON audit
artifact. The map links legacy theorem labels to validation obligations and
historical test witnesses while explicitly blocking production observation
claims, HTT evidence, MIO certificates, transfer/native validation, morphology
compatibility, and geometry/family-identification use.

## Chosen plan

- Add `scripts/codex_harness/generate_theorem_to_test_map.py`, a deterministic
  generator for `docs/generated/theorem_to_test_map_legacy_tsc.json`.
- Derive rows from `CORE_THEOREM_MAP` and witnesses from
  `build_tsc_validation_witnesses()`.
- Record required artifact metadata: owner, implementation scope, claim tier,
  transfer source, config hash, input hashes, sky/covariance/null statuses,
  caveats, generation command, and git/worktree state.
- Store top-level and row-level non-consumption fields for production claims,
  HTT evidence, MIO certificates, transfer/native validation, and
  geometry/family-identification use.
- Add `docs/deprecation/theorem_to_test_map.md` as the human-readable
  audit-only boundary.
- Add `tests/contracts/test_theorem_to_test_map.py` to compare generated rows
  against the legacy source, collect witness pytest nodes, scan claim language,
  and verify generator reproducibility.

Alternatives rejected: migrating TSC validation into COMMON, deleting the
legacy TSC map, adding an active validation registry, using FORBIDDEN status
values such as `validated`, or relying on a hand-written JSON snapshot.

## Claim-tier impact

This PR is COMMON audit-retention infrastructure. The generated artifact is
diagnostic-only and transfer-source `none`. It preserves legacy TSC/Teff theorem
labels as `TSC_LEGACY` provenance and validation obligations only.

It does not provide production observation validation, observable adequacy,
transfer validation, native solver validation, HTT evidence, MIO certificates,
posterior/likelihood support, null/mock/covariance support, response-rank
support, morphology compatibility, or geometry/family-identification evidence.

## Risk log

- DoD:
  - Legacy proofs map to validation obligations, not production claims.
  - The deprecation note surfaces why Teff/TSC was deprecated without losing
    audit traceability.
- Kill switch:
  - Reject any downstream use that treats legacy theorem status or witness
    tests as observation validation, HTT evidence, MIO certification,
    transfer/native validation, morphology compatibility, or
    geometry/family-identification evidence.
- Residual risks:
  - The map preserves historical witness paths; future witness renames must
    update the generated artifact and pass node collection.
  - PR-032 does not migrate all old TSC theorem prose in archived documents;
    it creates the active audit-only generated artifact for new consumers.
