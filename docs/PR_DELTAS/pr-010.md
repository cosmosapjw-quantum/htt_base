## What this PR owns

### 5 Source Channels (per SSOT v2.0 §5)

```rust
source_sw(inp)                       // SW: g · (δ_γ/4 + 2Φ + η_mb/2)
source_isw(inp, exp_minus_tau)       // ISW: e^{-τ} · (Ψ̇ + Φ̇)
source_doppler(inp)                  // Doppler: via core::ssot::doppler_source
source_polter_quad(inp, polter_dot)  // Quad: via core::ssot::quad_source_no_polterddot
source_emode(inp, conv)              // E-mode: Polter or PiBass convention
```

### `EmodeConvention` enum

명시적 선택: `Polter` (CAMB production) vs `PiBass` (exact transport).
Call site 에서 explicit 명시 의무. default 없음.

### `assemble()` 함수

5 channel 을 `ChannelOutputs { s_sw, s_isw, s_dop, s_quad, s_e }` 로 집계. `s_total_temperature()` 는 TT = SW+ISW+Dop+Quad; s_e 는 별도 (EE).

## TDD gate (5 categories, 12 tests, all PASS)

### Identity (3)
- `identity_sw_formula_direct` — SW = g·(δ_γ/4 + 2Φ + η_mb/2) 직접 계산 일치
- `identity_doppler_equals_ssot_helper` — registry 는 `core::ssot::doppler_source` 경유 확정
- `identity_polter_quad_equals_ssot_helper` — registry 는 `core::ssot::quad_source_no_polterddot` 경유 확정

### Limit (2)
- `limit_no_visibility_no_source` — visibility-off (g=g'=g''=0) → SW/Dop/Quad/E = 0
- `limit_pol_off_reduces_polter_quad` — pol-OFF 경로 올바른 1/10 계수 적용

### Channelwise (3)
- `channelwise_emode_independent_of_sw` — δ_γ/Φ/η_mb 변경은 s_e 에 무영향
- `channelwise_sw_independent_of_e2` — E₂/E₀ 변경은 s_sw 에 무영향
- `channelwise_emode_two_conventions_differ` — Polter vs PiBass 값 달라짐 (hand-check: 0.039 vs 0.062)

### Regression (1)
- `regression_assemble_matches_production_s_sw_s_dop_s_quad` — assemble 결과가 ssot 헬퍼와 bit-identical
- **추가 검증**: `dump_dl_spectrum_sparse` 재실행 시 D_2 = 1002.086744 **bit-identical** 보존 확인 (69.66 s, 498/498 k-modes)

### Caveat/provenance (3)
- `caveat_total_temperature_sums_correctly` — s_total_temperature = SW + ISW + Dop + Quad (s_e 미포함)
- `caveat_emode_convention_is_explicit` — default 없음, caller 가 반드시 Polter 또는 PiBass 명시
- `caveat_no_pol_reduction_emode` — pol-OFF 환원 시 각 convention 별 정확한 계수
