## Chosen plan

- Added `htt.statistics.mes_cov_bound` with
  `build_mes_covariance_bound()` and `MesCovarianceBoundResult`.
- The branch consumes caller-supplied OBSSTAT BiPoSH/sparse-covariance feature
  metadata and typed PR-076 null provenance.
- The branch computes:
  - covariance whitening from a supplied full positive-definite covariance;
  - nuisance projection in whitened feature space;
  - raw and projected SVD rank;
  - projected singular values, rank threshold, projected response norms,
    nuisance rank, and condition number.
- A finite synthetic covariance/BiPoSH bound is emitted only when all
  covariance, BiPoSH provenance, typed-null provenance, and projected-rank
  gates pass.
- Rank-deficient, near-singular, nuisance-erased, missing-covariance,
  missing-BiPoSH, or mismatched-null states set `covariance_bound=None`, preserve
  the diagonal fallback baseline, and report information gain 1.
- Rejected native solver simulation, BiPoSH coefficient estimation from maps,
  HTT likelihood/evidence plumbing, MIO certificate plumbing, BASS/native
  transfer validation, and geometry/family wording.
