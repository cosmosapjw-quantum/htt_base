## 주요 설계 결정

### 1. MB-95 `camb_rhs` 를 primary oracle 로 사용 (`pr-022b-design.md §2.3`)

Pre-audit 에서 `src/pstf/collision_lm.rs:107-118` 의 ℓ=1 block matrix 가 **Θ 와 F convention 혼재** 로 의심됨:
- Row 1 `[−κ̇, κ̇]` (F-natural)
- Row 2 `[3κ̇/(4·r_b), −κ̇/r_b]` (**hybrid 3/4 factor** — pure Θ 도 pure F 도 아닌 momentum-conserving 불가능 pair)

**올바른 Θ convention** (MB-95 `camb_rhs:491-494, 486-487`):
```
dΘ_1/dη |_coll = −κ̇·(Θ_1 − v_b/3)
dv_b/dη |_drag = +(κ̇/r_b)·(3·Θ_1 − v_b)
```

Row coefficient pair: `(1, 1/3)` on Θ_1 side, `(3, 1)` on v_b side — momentum-conserving 검증됨.

**결정**: PR-022b 는 `collision_lm.rs` 를 G4 target 으로 **사용 안 함**. MB-95 `camb_rhs` 를 primary oracle 로 사용. `collision_lm` bug 의심은 Phase 2 로 defer (production 경로 밖, 9 consecutive bit-identical 로 impact 없음 확인).

이것은 PR-020 의 `flrw_norm_ratio_down` 함정과 동일한 pattern — 잘못된 reference 에 얽매이는 대신 scope 축소 + 올바른 oracle 로 재정렬.

### 2. `FrameConvention` enum + FLRW frame equivalence

DESIGN LAW 는 electron rest frame ζ̃ 를 요구. FLRW 에서는 `n^a = u_e^a` (isotropy) 이므로 hypersurface-normal frame 과 수치 일치. `caveat_frame_equivalence_flrw` test 가 ElectronRestFrame 과 HypersurfaceNormalFrame 이 동일 `dy` 를 생성함을 증명 (all n_state entries exactly equal).

Bianchi tilt 로 확장 시 두 frame 이 divergence — Phase 4 scope. PR-022b 는 **enum 을 structural tag 로 도입** 하여 future divergence 를 대비.

### 3. Pol feedback 를 default off (flag 로 활성화 가능)

`use_pol_feedback: false` 기본값 — PR-022b scope 은 pol-off 만. E-mode RHS 가 별도 PR 로 필요하므로 pol activation 은 future work. `limit_no_pol_feedback` test 가 pol-off path 를 직접 검증 (`C[Θ_2] = −κ̇·Θ_2`, no 9/10 factor, no E_2 term).

구현은 `use_pol_feedback=true` + `layout.has_pol()` 두 조건 모두 만족할 때만 MB-95 의 `−0.9·κ̇·Θ_2 + (3/20)·κ̇·E_2` path 활성화. Fallback 은 pure damping.

### 4. Additive 설계 (free-streaming + collision 합성)

`pstf_thomson_collision` 은 `dy` 를 zero-initialize 하지 않고 `+=` 로 accumulate. 의도된 사용:

```rust
let mut dy = vec![0.0; layout.n_state];
pstf_free_streaming_rhs(state, &mut dy, &free_inputs, layout);   // PR-022a
pstf_thomson_collision(state, &mut dy, &coll_inputs, layout);    // PR-022b
// ... + metric (PR-023) + fluid (PR-023) + Jacobian (PR-022c)
```

이것이 PR-024 (LoS source + solve_pstf_spectrum) 에서 통합될 RHS dispatcher 의 기반. `regression_collision_matches_mb95_full_path` test 가 이 합성이 MB-95 `camb_rhs` 와 bit-identical 함을 검증.

## Channelwise verification (no-touch invariants)

`pstf_thomson_collision` 은 의도적으로 **photon intensity + baryon v_b 만** touch. `channelwise_neutrino_no_collision` + `channelwise_cdm_metric_untouched` 가 보장:

- Neutrino sector (모든 ℓ): zero contribution (ν 는 Thomson 과 decoupled)
- Metric sector (index 0..11): zero
- CDM sector (4 entries): zero
- Baryon δ_b (baryon_start + 0): zero (velocity slot baryon_start + 2 만 touch)
- B-mode: zero (PR-022b scope 아님)
- Higher-m (|m| ≥ 1) photon intensity: touch 안 함 (FLRW m=0 only)

이 invariants 는 PR-024 RHS dispatcher 에서 sector 별 additive 합성을 가능하게 하는 기반.
