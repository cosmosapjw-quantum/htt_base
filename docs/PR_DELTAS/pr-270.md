## Capability and hard boundary

PR-270 freezes one assumption- and branch-aligned R3 CAS contract for the
exact algebraic cores of VT-T5 through VT-T8 and the invariant chain-rule core
of VT-T13. It also verifies the conditional finite-dimensional cores VT-T11
and VT-T12 and records the VT-T14 external-geometry refusal.

The repaired parent-observed aggregate is `CAS_4AXIS_PASS`: Wolfram
Engine+xAct, SymPy, SageMath+Singular, and mathlib-backed Lean each execute and
pass the same contract. No exception is registered or applied, and majority
vote remains structurally forbidden.

This PR does not rewrite the frozen source theorem status, establish global
orbit separation, invent a 1+3 evolution branch, validate a native solver or
atlas, or identify a geometry/family.

## Reproduced defects and first blind review

`9c00451ff64d13895f34c3c1c8dc4b2a75d0e2e4` was audited in harness run
`pr270-cas-4axis-20260730-r2`. That run is retained as failed diagnostic

The blind axes found four concrete failure classes:

4. The first Wolfram reviewer accidentally invoked `merge_results.py --help`;
   the script has no help mode and briefly created then removed
   `MERGED_RESULTS.json`. The reviewer recorded the unique-path protocol
   violation, so that r2 Wolfram envelope is diagnostic-only.

The r2 result set also exposed a strict-envelope defect in the Lean result
(`producer` omitted and one invalid finding verdict). Consequently r2 was not
