## Reproduced defect

Before production edits:

```bash
python3 .agent-harness/scripts/cas_gate.py preflight --all
```

reported `wolfram_xact: BLOCKED_PACKAGE_UNAVAILABLE`. Direct execution showed:

```text
Your Wolfram Engine installation is not activated or is experiencing a
license-related problem. Please run wolframscript with the -activate option.
```

`wolframscript` returned 255. The harness classifier previously distinguished
only exit 127/124 and therefore misclassified a known activation transcript as
a missing xAct package. The repair adds bounded transcript-aware licensing
markers and classifies this case as `BLOCKED_PLATFORM_OR_LICENSE`. Unknown
nonzero transcripts still fail closed as package-unavailable.
