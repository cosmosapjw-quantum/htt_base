# PR-251 — Equivariant orbit response and model discrepancy

Status: implementation candidate. This is an internal DAG card, not a GitHub
pull request.

## Implemented scope

- Added an exact Cartesian STF5 action for the signed departure state.  Shear
  transforms as a rank-two tensor, beta as a polar vector, omega as an axial
  vector, and the signed curvature coordinate as a scalar.
- Bound every state action to an explicit coordinate frame and active O(3)
  convention.  Proper rotations preserve the preregistered even and odd
  invariants; reflections preserve the five even invariants and reverse only
  `det[beta,sigma beta,sigma^2 beta]`.
- Added a fixed six-invariant catalogue whose report records the multiplicity
  method, alignment-null identity, preregistration, frame, congruence, window,
  scale, basis and perturbative order.
- Added a response-rank report computed only from an explicitly supplied
  post-transfer/post-mask response and covariance.  Missing transfer, mask or
  covariance identities return `MISSING_INPUT`; they never default to rank
  eight or full rank.
- Added supported-quotient whitening for singular PSD covariance.  Parameter
  null directions and covariance-null residuals remain visible.
- Fixed the historical wide-response ladder defect: when
  `rank < parameter_dimension`, `min_singular` is now exactly zero even if the
  economy SVD returns only non-zero observed singular values.
- Added tangent/perpendicular residual statistics and an optional explicit
  nonlinear-manifold distance.  `NONLINEAR_COMPATIBLE` can be constructed only
  when the same registered candidate beats linear, systematics,
  frame-mismatch and derivative-failure alternatives on both held-out and
  matched-injection scores by a positive declared margin.
- Bound the OBSSTAT low-ell pole definition, ell set, numerical gap tolerance,
  coordinate frame and harmonic convention into a stable analysis identity.
  Added explicit scalar-alm inversion parity and O(3) tensor/antipodal-axis
  actions without changing the existing pole estimator.

## Claim boundary

All outputs are diagnostic-only pre-solver contracts.  `FOUND-EQUIV` remains
`ACTIVE_CONDITIONAL` pending `EGS3-B1`.  The invariant catalogue is not an
inverse morphology atlas; rank is not a family label; and an off-manifold
residual is unattributed unless the complete held-out competition succeeds.
No output identifies a Bianchi family, detects geometry, supplies an HTT
posterior/evidence term, or uses PR-151 partial acquisition.

Anchor stress and nonlinearity remain independent report types.  A state can be
within or above an anchor while having the same off-manifold classification;
neither report authorizes a conversion into the other.

## Kill conditions

The candidate fails if a hard-coded rank is emitted without the exact
response/covariance identities, a structural parameter null has positive
`min_singular`, a covariance-null residual receives zero cost, a reflection
does not flip exactly the parity-odd invariant, relative orientation collapses
to a norm, an incomplete or in-sample candidate competition produces
`NONLINEAR_COMPATIBLE`, or a diagnostic is described as family/native-solver
evidence.
