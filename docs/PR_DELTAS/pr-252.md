# PR-252 — Lossless statistical-foundation consumer migration

Status: implementation candidate. This is an internal DAG card, not a GitHub
pull request.

## Scope and authority

PR-252 migrates live HTT, MIO, BASS, result-pack and manuscript consumers onto
the typed contracts delivered by PR-248--251.  It does not change PR-151,
consume partial acquisition data, reactivate a withheld coefficient, produce a
solver output, or promote a scientific claim.

The canonical methodology authority is
`docs/research_program/STAT_FOUNDATIONS_REVIEW_20260727.md`.  Historical
receipts and result bytes remain preserved.  The PR-122 inventory and PR-248
supersession are not rewritten; the hash-bound
`pr252_mes_consumer_migration.yaml` records exact active-to-active,
active-to-legacy and exclusion-byte transitions.

## Live-consumer migration

- The active `htt.core` surface exports typed geodesic anchors, sector stress
  and dependency-light weighted statistics.  The former float-returning
  bounds implementation is reproduced only through
  `tsc_legacy.htt_core_bounds`.
- The active HTT directional artifact is schema v2.  `x_C`, `Q`, `Pi` and `F`
  are segregated in a BC1/BC2 legacy-projection section; HTT model evidence is
  a separate HTT-owned section.  Missing legacy values fail closed instead of
  becoming zero.
- The active HTT-to-MIO adapter carries an evidence-free
  `MioCrossCheckExport`.  The historical `PosteriorExportBundle` and integrated
  pipeline JSON path require `legacy_reproduction=True`; the `"0.10"` legacy
  Pi threshold is read explicitly and no absent alias receives a zero default.
- The active BASS comparator reports the signed budget coordinate and typed,
  channel-matched anchor stress.  Bare `x_max` arithmetic is available only in
  `bass.validation.legacy_comparator_policy`.  The Bianchi-IV structural
  report carries no Bayes-factor expectation.
- The active MIO namespace exports state, identified-set, stress and
  nonlinearity contracts.  Historical Q/F/Pi/G_F builders are available under
  `mio.legacy_projection`, emit deprecation warnings and cannot authorize
  occupancy, probability, evidence, family or local/global language.
- `StatisticalFoundationResultCard` keeps departure state, identified set,
  anchor stress, legacy projection, nonlinearity and OBSSTAT morphology
  references as separate output spaces with no automatic conversion.
- Former corrected-shear, Teff, scalar ceiling-family and historical figure
  consumers are exact-hash legacy exclusions.  The live MES registry scans
  seven typed consumers and rejects undeclared or drifted active surfaces.

## Integration defects found and repaired

The PR-252 integration test exposed two additional fail-closed defects:

1. typed MES construction used `bound * bound` while exact self-validation
   used `bound ** 2`, allowing a one-ulp rounding difference to reject a legal
   calibration.  Construction and validation now share one rounding path;
2. the historical HTT adapter looked only for Pi key `"0.1"` while the frozen
   source uses `"0.10"`, previously enabling a silent zero.  The adapter now
   accepts the explicit registered aliases, rejects conflicting aliases, and
   returns the ordered historical interval.

Neither repair changes a frozen artifact or claim status.
