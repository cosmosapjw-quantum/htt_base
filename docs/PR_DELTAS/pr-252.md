  channel-matched anchor stress.  Bare `x_max` arithmetic is available only in

## Integration defects found and repaired

The PR-252 integration test exposed two additional fail-closed defects:

1. typed MES construction used `bound * bound` while exact self-validation
   used `bound ** 2`, allowing a one-ulp rounding difference to reject a legal
   calibration.  Construction and validation now share one rounding path;
2. the historical HTT adapter looked only for Pi key `"0.1"` while the frozen
   source uses `"0.10"`, previously enabling a silent zero.  The adapter now
   accepts the explicit registered aliases, rejects conflicting aliases, and
   returns the ordered historical interval.

Neither repair changes a frozen artifact or claim status.
