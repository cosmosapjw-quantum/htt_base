- Added the missing PR-card test path

  `sky_support_complete` adequacy indicators to directional MIO certificates.

  `statistics_definitions` with machine-readable covariance/null/sky status,
  transfer source, direction convention, weighting convention, cross-probe

  production status, claim tier, and public-grade label.

  `has_covariance`, `has_null_mocks`, and `sky_support_status` arguments so
  emitted JSON can preserve caller-provided readiness state instead of always
  using the default incomplete state.
- Preserved the existing MIO readiness contract: missing covariance blocks as
  `blocked_missing_covariance`; missing null mocks block as
  `blocked_missing_null_mocks`; incomplete sky support remains
  `diagnostic_only`; all explicit gates can reach `production_candidate`.
- Preserved `MioCertificate.reduction_status == "diagnostic-only"` and did not
  add HTT inference, posterior odds, likelihood/evidence terms, transfer
  validation, native solver output, morphology compatibility, or family/geometry
  claims.
