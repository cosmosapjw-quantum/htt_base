# PR-320 — derive HSC–KiDS covariance from paired same-sky nulls

PR-320 removes the arbitrary supplied HSC–KiDS cross block from the scientific
decision path.  A joint covariance now exists only when the HSC and KiDS
feature rows carry the same exact, ordered, unique realization IDs and are
declared to come from the same cosmic sky on a bound common support.  The
implementation then forms one concatenated feature matrix and computes

\[
  \widehat C = \frac{(X-\bar X)^\mathsf{T}(X-\bar X)}{N-1}.
\]

The HSC auto, KiDS auto, and cross blocks are slices of this single estimator;
they are not assembled from three unrelated matrices.  Feature order, units,
normalization identities, null source, overlap support, and both survey
operator identities are part of the derivation contract.

The evidence type has no public constructor.  Normal code can obtain an
instance only through the paired-row factory, so an arbitrary SPD cross block
cannot acquire scientific authority merely by being wrapped in the expected
Python type.  This is a provenance boundary for the estimator, not a hostile
security mechanism.  The factory also stores read-only covariance arrays so a
validated instance cannot be numerically rewritten in place.

## Scientific resolution

The prior worker's synthetic `0.08 I` block was useful only as a numerical
fixture.  It had no scientific provenance and could incorrectly produce a
full-rank terminal.  That path has been removed.  A caller-supplied legacy
matrix now has no covariance authority and ends at
`NON_IDENTIFIED_CROSS_SURVEY_COVARIANCE`.

An estimated cross block that is exactly zero is different from absent cross
information.  It is accepted when, and only when, it is the output of the
complete paired-row estimator.  Conversely, a positive-semidefinite but
singular sample covariance is scientifically valid covariance evidence but
cannot support Cholesky whitening.  It terminates as
`COVARIANCE_VALID_WHITENING_UNAVAILABLE` before response rank; no pseudoinverse
fallback is introduced.

The retained response check is a covariance-whitened, column-scaled local
structural rank diagnostic.  Its positive label is therefore
`LOCAL_STRUCTURAL_FULL_INCREMENTAL_RANK`, not practical or global
identification.  It creates no likelihood, p-value, coefficient, source
label, or finite-mock precision claim.

## Release and overlap evidence

The [HSC S19A/Y3 release](https://hsc-release.mtk.nao.ac.jp/doc/index.php/s19a-shape-catalog-pdr3/)
and [KiDS-1000 DR4 release](https://kids.strw.leidenuniv.nl/DR4/KiDS-1000_cosmicshear.php)
remain separate official data products.  A published joint reanalysis of HSC
and KiDS discusses independence and full-overlap approximations rather than a
released exact cross-covariance for these products
([MNRAS 520, 5016](https://academic.oup.com/mnras/article/520/4/5016/7008908)).
Neither approximation is promoted here.  Observed HSC–KiDS execution remains
blocked until a paired same-sky null ensemble processed through the exact two
operators and overlap support is admitted.

The synthetic closure uses 64 paired rows with shared latent-sky modes plus
survey-specific noise.  It demonstrates only the estimator and refusal
semantics; it is not a model of the observed surveys and is not an observed
result.
