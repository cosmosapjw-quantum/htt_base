## Reproduced capability gap

Existing depth-oriented modules can group redshift bins or summarize selected
catalogues, but they do not bind one ordered path to exact finite sky-support
units, mask, selection, covariance, source, feature layout, and an explicit
transport kernel on every edge. They also do not provide a shared typed
boundary that keeps OBSSTAT feature extraction, MIO diagnostic coherence, and
HTT model-conditional likelihood separate. Consequently, incompatible sky
supports could be compared outside those modules without one fail-closed path
contract.

## Implemented change

1. Added immutable `MaskStratum`, `TransportKernel`, and `DepthPath` contracts.
   Depth coordinates increase strictly, later supports must be exact subsets
   of earlier supports, and every edge binds the exact source/target content
   identities and feature layouts.
2. Reused `common.contracts.SkySupport`; no parallel sky-support contract was
   introduced. Coordinate frame, pixelization, `nside`, universe size, mask
   identity, and exact retained-sky fraction must agree.
3. Added OBSSTAT-owned `ObservableFeatureStep` plus feature and covariance
   transport. Kernel composition requires the same exact middle stratum and
   applies \(K C K^\mathsf{T}\) to covariance.
4. Added MIO-owned `DepthCoherenceReport`. Each adjacent cell evaluates the
   transported residual with target covariance plus transported source
   covariance. Rank-deficient covariance returns
   `COVARIANCE_RANK_DEFICIENT` with no score.
5. Made the covariance-rank decision relative to the covariance scale, so a
   change of physical scale alone cannot turn a full-rank matrix into a
   missing result.
6. Added a preregistered non-identity depth-scramble negative control. Its
   source step identity remains in the negative-control provenance, and a
   missing baseline or scrambled score is `INCONCLUSIVE`.
7. Added HTT-owned `DepthModelPrediction` and Gaussian
   `DepthLikelihoodResult`. The adapter accepts an explicit model prediction
   only, refuses a MIO report as a prediction, binds transfer/config identity,
   and requires positive-definite covariance through a Cholesky factorization.
8. Added owner-specific OBSSTAT, MIO, and HTT facades plus mutation-detecting
   content identities for all claim-relevant contracts and results.
