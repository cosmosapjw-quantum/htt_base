## Corrected official selection identity

The initial planning phrase incorrectly read the `21.5` suffix as an apparent
`r < 21.5` threshold and made the redshift endpoints inclusive. Official DESI
DR1 documentation instead defines the relevant chain as:

- base BGS BRIGHT target selection with apparent `r < 19.5`;
- the `BGS_BRIGHT-21.5` cosmology sample with absolute `M_r < -21.5`;
- strict `0.1 < z < 0.4`;
- separately identified NGC and SGC catalog/window products;
- DR1 LSS `iron` v1.5 as the selected current release.

The implementation freezes those semantics and refuses `BGS_ANY`, reversed cap
order, alternate window identities, endpoint rows, nonmember rows, rows at
either magnitude threshold, or a different operator. Each compact row carries
the official-sample membership bit and the apparent/absolute magnitude values;
the selection document also binds the official derivation identity.
Sources: [DESI 2024 II](https://arxiv.org/abs/2411.12020),
[DESI DR1 clustering products](https://data.desi.lbl.gov/doc/releases/dr1/vac/full-shape-bao-clustering/).
The canonical DAG card and all four mirrors were corrected first in GitHub
PR #401, merged as `00fbc5c7bf11765fb2f49cf68ea3ea3ee6cc489f`; this
candidate starts from that exact stack base.

## Scientific contract

- Each observed, EZmock, and Abacus realization uses the same frozen feature
  order: NGC then SGC, three redshift bins, and Cartesian dipole components.
- PR-289 units, frame, sign, direction, mask, sky-support, covariance, null,
  and transfer identities are replayed from every admitted record and must
  match the operator selection document.
- Random normalization and the selection-template nuisance amplitude are
  re-fit independently in every cap and redshift bin for every realization.
- Exactly EZmock realizations 1–1000 own the full empirical covariance.
- Exactly Abacus realizations 0–24 are retained as a separate held-out
  validation tier and are never pooled into that covariance.
- The component-confusion matrix reports only normalized response overlap. It
  cannot identify a causal component.
- Response rank is evaluated after Cholesky whitening and per-column weighted
  L2 scaling. Independent column rescaling/sign changes leave the verdict
  unchanged; nuisance or candidate dependence yields `NON_IDENTIFIED_ABSTAIN`
  with no p-value or forced label.
- Compact admitted inputs are processed one realization at a time into frozen
  feature rows, avoiding retention of all catalog rows in memory.
- Synthetic profiles at 1/8/32/128/full rows expose serial, small-thread, and
  small-process modes with one BLAS/OpenMP thread per process. Partial profiles
  time only the refit path and cannot reach covariance, rank, or a statistic.

Official release-level roles and counts are supported by the
[DESI DR1 release documentation](https://data.desi.lbl.gov/doc/releases/dr1/)
and the [AbacusSummit data model](https://desidatamodel.readthedocs.io/en/latest/DESI_ROOT/survey/catalogs/RELEASE/mocks/AbacusSummit/index.html).
Local admission still has to prove every file is present and correctly bound.
