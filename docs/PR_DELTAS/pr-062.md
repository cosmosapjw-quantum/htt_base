## Chosen plan

- Added `SelectionResponseMetadata` and `SurveyAxisMetadata` to carry hashed
  selection-function, depth-response, selection-metadata, and survey-axis
  provenance with unit-vector validation.
- Added `SelectionResponseDepthNull` and `SurveyAxisCoherenceNull` under the
  live `htt/htt/htt/nulls` package root. Both generate deterministic
  depth-complete `DepthNullSample` mocks with normalized directions, beta,
  log_G_F, G_F, angular thresholds, sky/mask/scan hashes, config/input hashes,
  random seeds, generating command, and git/worktree provenance.
- Added `SurveySystematicNullMockBank`,
  `SurveySystematicNullFprReport`,
  `build_survey_systematic_null_fpr_report()`, and
  `evaluate_survey_systematic_null_gate()` with Wilson intervals,
  look-elsewhere adjustment, selection/survey hash pinning, PR-060
  response-overlap rank binding, and fail-closed mismatch handling.
- Tightened post-review gates so survey/systematic promotion requires explicit
  caller-supplied config/input/report/selection/survey-axis/response-overlap
  hashes at the matrix boundary, rejects non-strict FPR ceilings above 0.2,
  blocks non-ready selection/survey statuses, and records full report
  provenance at the top level and in the nested manifest.
- Kept PR-062 depth/null APIs out of `NULL_REGISTRY`; the old scalar null
  registry remains exactly the existing five families.
- Wired `build_discrimination_matrix()` so the
  `global_tilt|local_boost` pair requires both the PR-061 local-null FPR gate
  and the PR-062 survey/systematic FPR gate before reaching conditional
  local/global discrimination status; the matrix production status remains
  `diagnostic_only` pre-native even for a conditional candidate.
- Corrected stale PR-062 backlog paths from `htt/src/htt/nulls/...` to
  `htt/htt/htt/nulls/...` across YAML, JSON, and markdown mirrors.

Rejected alternatives: fake native solver values, native morphology atlas
claims, HTT posterior/evidence plumbing, MIO certificate reuse, scalar-only
survey wrappers, and allowing local-null FPR to stand in for survey/systematic
null calibration.

    and markdown backlog mirrors.

  satisfy the PR-062 depth, direction, FPR, manifest, or selection-metadata
  contract.
  - Fix: added distinct depth-resolved PR-062 generators and kept the scalar
    registry unchanged.
- Finding: local-null FPR alone could become a hidden substitute for
  survey/systematic null calibration in `build_discrimination_matrix()`.
  - Fix: added a separate survey/systematic FPR gate and require both gates for
    `global_tilt|local_boost` conditional status.
- Finding: the first dual-gate integration fixture exceeded the default FPR
  ceiling.
  - Fix: retuned the pass fixture to a low-FPR calibration case and preserved
    separate high-FPR and non-strict-ceiling fail-closed unit tests.
- Finding: post-review auditors found that the discrimination matrix could
  self-authorize stale survey reports by passing report-internal hashes back
  into the gate.
  - Fix: `build_discrimination_matrix()` now requires external survey
    config/input/report/selection/survey-axis/response-overlap hashes for the
    survey/systematic gate, and tests cover missing and stale bindings.
- Finding: post-review auditors found that `max_false_positive_rate=1.0` made
  the survey gate vacuous.
  - Fix: survey/systematic FPR reports now block ceilings above 0.2, and tests
    cover the non-strict ceiling blocker.
- Finding: post-review auditors found that generated status sidecars used
  generic DAG-row `not_statistical` notes for PR-062 and the progress
  scoreboard still referenced the pre-PR-062 state.
  - Fix: added a PR-062 status-snapshot note hook, regenerated status/claim
    sidecars, and regenerated the progress scoreboard.
- Finding: post-review auditors found that a conditional matrix used
  `production_candidate` despite pre-native morphology atlas limits.
  - Fix: the pair can remain `conditional` as a local/global discrimination
    candidate, but the matrix manifest production status stays
    `diagnostic_only` and carries prerequisite-only/non-evidence metadata.

## Claim-tier impact

This PR adds HTT diagnostic-only survey/systematic null calibration metadata.
It supplies a fail-closed prerequisite gate for downstream local/global
discrimination, but passing the gate removes only this specific prerequisite
blocker and does not authorize model-dependent inference output.

- owner: HTT
- implementation_scope: htt
- pr_scope: pre-solver
- claim_tier: diagnostic_only
- transfer_source: none
- sky_support_status: `pr040_sky_support_attached` in test fixtures and report
  payloads when supplied by callers
- null_mock_status: `survey_systematic_null_fpr_available` for the FPR report
- covariance_status: caller-supplied diagnostic covariance status, checked by
  the FPR gate
- ppc_status: not_applicable
- loocv_status: not_applicable

PR-062 does not run or fake a native solver, validate native transfer, create
HTT posterior/evidence content, create MIO certificate content, establish
morphology compatibility, or support geometry/family claims.
The discrimination-matrix artifact remains `production_status=diagnostic_only`
pre-native even when the `global_tilt|local_boost` pair reaches conditional
candidate status.
