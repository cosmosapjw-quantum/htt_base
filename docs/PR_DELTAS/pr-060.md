# PR-060 - Response-overlap and rank audit for local/global discrimination

## Goal

- Owner: HTT
- Depends: PR-014, PR-040, PR-055
- Level: L3
- Scope: pre-solver
- Risk: high

Add an HTT-owned response-overlap and nuisance-projected rank audit before
local/global discrimination can emit model-dependent directional outputs. Rank
deficiency or missing audit evidence must yield no-claim status and block the
dedicated HTT directional posterior artifact writer.

## Chosen plan

- Added `htt.departure.response_overlap.ResponseOverlapAudit` with checked
  response vectors, covariance whitening, nuisance projection, SVD rank,
  rho_LB_GT, condition number, no-claim reasons, manifest metadata, transfer
  provenance, and model-run gate.
- Added `require_rank_audit_for_model_run()` as the fail-closed guard for
  the response-rank precondition. Passing this guard does not by itself
  authorize model-dependent directional output emission.
- Extended VER2 directional likelihood inputs and readiness checks with
  `response_overlap_audit`, `response_overlap_rank_ready`, audit caveats, and
  manifest statistics.
- Wired `build_ver2_directional_inputs()` and
  `emit_directional_posterior_artifact()` so dedicated HTT directional
  posterior artifacts cannot be written without an allowed rank audit and full
  directional readiness gates.
- Bound attached response audits to observable/discrimination metadata and
  carried audit artifact/config/input hashes plus transfer source/spec into
  downstream directional manifests.
- Wired `build_posterior_bundle(..., directional_inputs=...)` to fail closed
  under the same directional readiness guard.
- Exposed the new `htt.departure` import surface through package smoke tests
  and `__all__`.

Rejected alternatives: fake native morphology support, family-ranking fields,
MIO certificate plumbing, raw unwhitened overlap, scalar-only gates, and
post-hoc sanitizing of no-claim directional artifacts.

## Review findings and fixes

- Finding: the first positive shell tests could still reach old live-hook paths
  without proving the new rank gate.
  - Fix: added `_response_overlap_audit()` and required it in every positive
    production-candidate or artifact-emission path.
- Finding: missing rank audit was only visible in readiness metadata, not in
  the artifact writer.
  - Fix: `emit_directional_posterior_artifact()` now calls
    `require_rank_audit_for_model_run()` before materializing payloads.
- Finding: the pre-existing null-mock regression became ambiguous once
  response-rank was a required gate.
  - Fix: added a valid rank audit to keep that test isolating the null-mock
    branch.
- Finding: static forbidden-language scanners can flag scanner vocabularies.
  - Fix: split high-risk reserved strings in `response_overlap.py` while
    preserving runtime checks.
- Finding: a rank-deficient audit's serialized gate could be mutated after
  construction and then trusted by the guard.
  - Fix: made `model_run_gate` immutable at normal runtime and rewired
    `require_rank_audit_for_model_run()` to recompute block reasons from
    rank status, no-claim reasons, projected norms, and rho.
- Finding: a full-rank audit from stale observable/discrimination inputs could
  unlock readiness.
  - Fix: `DirectionalLikelihoodInputs` now requires audit artifact metadata to
    match observable manifest/config, sky/mask hashes, and discrimination
    matrix artifact/config hashes.
- Finding: downstream directional manifests carried only an audit ref, not the
  audit config/input refs or transfer provenance.
  - Fix: output manifests now include audit artifact/config/input refs in
    `input_hashes` and expose rank status, claim status, transfer source, and
    transfer spec in statistics/caveats.
- Finding: `emit_directional_posterior_artifact()` and
  `build_posterior_bundle(..., directional_inputs=...)` could emit values after
  a rank precondition pass even when null/PPC/LOOCV/readiness gates failed.
  - Fix: added `require_directional_model_outputs_ready()` and wired both
    output paths to require full directional readiness.
- Finding: caller-supplied directional posterior manifests could omit
  response-overlap audit provenance.
  - Fix: the dedicated writer rejects override manifests missing the audit
    artifact/config/input refs, transfer source/spec, or production-candidate
    status.
- Finding: the PR card used the stale `htt/src/htt` package path.
  - Fix: corrected PR-060 backlog paths to the live
    `htt/htt/htt/departure/response_overlap.py` import root in both YAML
    mirrors and the markdown backlog.

## Claim-tier impact

This PR adds HTT pre-inference diagnostic rank bookkeeping and a fail-closed
directional emission gate. It does not create native solver output, validate
external transfer as native, create MIO certificates, or make geometry/family
claims.

- owner: HTT
- implementation_scope: htt
- pr_scope: pre-solver
- claim_tier: diagnostic_only for the response audit
- transfer_source: none by default; external transfer metadata requires PR-014
  `TransferFunctionSpec` provenance and remains transfer-conditional
- sky_support_status: recorded by audit input metadata
- mask_status: recorded by audit input metadata
- covariance_status: recorded by audit input metadata
- null_mock_status: recorded by audit input metadata
- ppc_status: not calibrated by PR-060
- loocv_status: not calibrated by PR-060

## Risk log

- DoD:
  - Computes rho_LB_GT and nuisance-projected rank.
  - Rank deficiency yields no-claim status.
  - Dedicated HTT directional artifact emission and directional-input export
    fail closed when the rank audit is missing, no-claim, stale, missing from
    manifest provenance, or when full directional readiness gates fail.
- Kill switch: reject if posterior/evidence runs when rank audit says no
  identifiable direction.
- Residual risks:
  - PR-060 supplies an explicit rank gate and diagnostic manifest, but it does
    not calibrate null FPR or response libraries from a native morphology atlas.
  - Existing local/global discrimination matrix code remains a separate
    feature-support heuristic; PR-060 adds the stricter rank gate rather than
    replacing all earlier diagnostics.
