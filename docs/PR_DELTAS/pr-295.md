## Entry and scope

Implementation started from merged target
`eaaff9db2636099e8286fb81acc1e652b018fbc5` in an isolated worktree. PR-280's
exact active-core failure was reproduced before edits: the production external
code policy failed only on the live `import camb` under
`htt/bass/transfer/visibility_camb_crosscheck.py`. The EGS2 numerical suite
passed 10 tests and the historical seal check was current, so this PR repairs
the production/package boundary without changing the registered numerical
result.

Setuptools 68.1.2 was exercised locally. The current upstream Setuptools
documentation records that `build`, `dist`, and egg-info caches can become
stale after file-layout changes and recommends removing them before rebuilding:
<https://setuptools.pypa.io/en/stable/userguide/miscellaneous.html#caching-and-troubleshooting>.

## Implemented repair

1. Moved the external CAMB oracle to the repository-only module
   `scripts/oracles/egs2_camb_visibility.py`. The installed BASS source tree no
   longer contains the oracle or any live CAMB import.
2. Updated the EGS2 test, direct seal runner, packaging inventory, current v8/v9
   audit builders, PR card, active ticket, and claim ledgers to the new path.
   Frozen historical audit/package manifests retain their old content-addressed
   paths and are not rewritten as if they described the new tree.
3. Restricted `BLOCKED_CAMB_UNAVAILABLE` to an exact missing top-level `camb`
   module. A missing `camb.*` submodule, missing transitive dependency, numerical
   exception, or failed check is `FAIL`, and the runner returns 1. Exact CAMB
   absence remains a lane-local blocker with exit 2 and no seal write.
4. Added `htt/src` to the direct runner bootstrap so execution without ambient
   `PYTHONPATH` reaches the registered CAMB-state classification.
5. Added a guarded `build_py` hook that refreshes only the project-local
   generated `build/lib` staging directory before a non-editable wheel build.
   It rejects a path outside the project build tree and any symlinked staging
   component. Editable builds retain the frontend-owned fresh temporary staging
   path. This prevents a deleted production oracle cached under `htt/build/lib`
   from being silently re-shipped.
6. Split the combined OBSSTAT/BASS ledger row. The BASS row uses canonical
   `TransferSource.external_transfer`; CAMB 1.6.6 remains the source identity in
   evidence and caveats. No external result is relabelled native.
