## Claim-tier impact

This PR adds a MIO L2 diagnostic-only formalism bundle for signed `x_C`
comparator projections. It provides metadata and validation only. It is not
native solver validation, transfer validation, HTT inference evidence, MIO
certificate evidence, morphology compatibility, or a geometry/family claim. It
carries no C5/C6 science claim.

## Risk log

- DoD: `B_C` components, comparator `C`, frame, units, and cancellation index
  are explicit.
- DoD: `x_C` is a signed projection, not an anisotropy norm.
- Kill switch: `x_C` cannot be exported without comparator/frame/units metadata.
- Residual risk: component values remain caller-supplied; PR-050 validates
  metadata and algebra but does not calibrate the physical inputs.
- Residual risk: cancellation index is algebraic only and not a significance
  measure without covariance/null calibration.
- Residual risk: component-level frame transforms are not implemented; mixed
  frame/units metadata is rejected rather than transformed.
