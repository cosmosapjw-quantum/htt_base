# PR-031 - Generic semantic guards extracted from TSC legacy

## Goal

- Owner: COMMON
- Depends: PR-030
- Level: L2
- Scope: pre-solver
- Risk: high

Extract generic COMMON-owned semantic guard records for source adequacy,
propagation adequacy, and observable status without reviving TSC as an active
science owner. The PR lets artifacts carry trace/source caveats without TSC
ownership and blocks source-to-observable overclaim language. It does not
establish statistical observable validation, null calibration, response rank,
mask/covariance support, transfer provenance, native solver validation, HTT
evidence, MIO certification, morphology compatibility, or geometry/family
evidence.

## Review findings and fixes

- Finding: `SourcePropagationStatus` allowed a caller-supplied
  `claim_tier_ceiling` but silently recomputed it.
  - Fix: the subclass field is no longer in the public constructor.
- Finding: scanner coverage missed punctuation, source-adequacy wording, and
  wrapped prose.
  - Fix: the scanner now uses a broader source/observable conflation pattern
    plus adjacent-line windows; tests assemble hostile examples at runtime so
    source files remain scanner-clean.
- Finding: metadata used a field name that could read as an observable
  adequacy assertion for `not_evaluated`.
  - Fix: metadata now separates `observable_status_is_explicit` from
    `observable_adequacy_is_established`.
- Finding: semantic records could appear to support conditional claims.
  - Fix: `SemanticAdequacyRecord` accepts only diagnostic-only, exploratory,
    or blocked ceilings; `SourcePropagationStatus` computes only
    diagnostic-only or blocked ceilings.
- Finding: semantic caveats could be attached to a stronger manifest tier.
  - Fix: `attach_semantic_caveats()` rejects manifest claim tiers above the
    record ceiling.
- Finding: source/propagation hard failures could remain exploratory.
  - Fix: source-inadequate, propagation-blocked, observable-blocked, or
    observable-inadequate records now compute a blocked ceiling.
- Finding: untracked handoff/config artifacts are present in the worktree.
  - Fix: they are deliberately excluded from the PR-031 staged set.

## Claim-tier impact

This PR is COMMON semantic guard infrastructure. It is diagnostic-only
pre-solver contract work with `transfer_source=none`,
`sky_support_status=not_directional`, and
`null_mock_status=not_statistical`.

The new statuses are guard metadata only. They do not provide statistical
observable validation, null/mock support, mask/covariance support,
response-rank/equivalence evidence, transfer provenance, native solver
validation, HTT likelihood/evidence, MIO certificates, morphology
compatibility, or geometry/family-identification evidence.

## Risk log

- DoD:
  - Source, propagation, and observable status are separate enums/fields.
  - Trace/source caveats can attach to artifacts without TSC ownership.
  - Source status cannot auto-promote observable status.
- Kill switch:
  - Reject any downstream use that treats these semantic guards as statistical
    observable validation or as evidence for geometry/family claims.
- Residual risks:
  - Legacy TSC overlay dataclasses still exist in `common.contracts` for
    compatibility; PR-031 extracts reusable guard behavior but does not migrate
    all old TSC surfaces.
  - Future consumers must provide explicit null/mask/covariance/rank/transfer
    gates before making stronger observable claims.
  - The broader DAG checkpoint is due after the next completed PR.
