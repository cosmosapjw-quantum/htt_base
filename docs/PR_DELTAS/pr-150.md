## Data readiness

The PR3 lane is no longer a 300-realization diagnostic. It uses every usable
Planck FFP10 SMICA CMB realization: 999 of the nominal 1000, plus all 300 noise
realizations. CMB ID `00970` is excluded because the missing file was officially
confirmed by the Planck helpdesk and no replacement exists.

PR4 remains a separate required analysis. The observed public SEVEM map is
`COM_CMB_IQU-sevem_2048_R4.00.fits`; matched simulations are not ingested in
PLA and the NERSC source `/global/cfs/cdirs/cmb/data/planck2020` still requires
a CMB PI, PI proxy, or Globus share. PR4 therefore emits no numerical result.

## Concrete PR3 measurement

The observed SMICA map and all 999 CMB null maps pass through the same frozen
NSIDE=64, masked, `ell_max=30`, six-statistic precision path. Each CMB ID is
paired with `noise_id = cmb_id mod 300`; the production run used `--jobs 20`.

- Six-statistic max-scan: 38 of 999 null scores meet or exceed the observed
  score, giving the finite-ensemble rank `39/1000 = 0.039`.
- Registered local ranks: `S_1/2 = 0.009`, quadrupole-octopole alignment
  `0.019`, parity asymmetry `0.066`, even/odd parity ratio `0.066`, planarity
  `0.096`, and CMB-dipole-axis separation `0.905`.
- Noise-reuse cycle ranks are `0.03322259136212625`,
  `0.04318936877076412`, `0.04983388704318937`, and `0.04`.
- A 20,000-replicate noise-cluster bootstrap gives median
  `0.03884462151394422` and percentile interval
  `[0.026262626262626262, 0.05321285140562249]`.

This is a concrete PR3/FFP10-conditional morphology result. The observed
max-scan score lies in a roughly four-percent empirical tail, but the reused
noise dependence, the bootstrap interval crossing 0.05, and the absent PR4
systematics comparison preclude a detection claim. The idealised correlated-GRF
super-uniformity calculation is retained only as preflight.

The earlier low-concurrency background attempt was superseded before this full
rerun. The completed production card records `jobs: 20`; the host had 64 GiB of
swap available, and the result includes all 999 usable CMB realizations rather
than a reduced diagnostic subset.

## Minimal reproducibility retention

The actual analysis inputs were reduced directly from the raw maps to the
authoritative pre-mask NSIDE=64 float64 arrays used by this estimator. The
combined compact archive is
`/mnt/sn850x2t/htt_base_e2e/k1_e2e_reduced_pr150/k1_ffp10_reduced_smica.npz`;
its independent copy is
`workdir/compact_products/planck_pr3_pr150/k1_ffp10_reduced_smica.npz`.
Both are 512,054,072 bytes with SHA-256
`86b792c821b3e641c76c83d96523148c65e9d30a439d7c850acc808c1bc5fadb`
and reside on distinct filesystem devices.

The deletion-grade gate hashes and directly replays all 999 CMB plus 300 noise
maps, authenticates the observed map and common mask, verifies the independent
copy, and exactly reproduces the retained 999-by-6 statistic matrix, max scores,
local ranks, and global rank. Its result is captured by
`docs/generated/pr150_compact_retention_receipt.json`.

Astropy reports that CMB file `00818` is 1,218 bytes short of its expected
trailing FITS block padding. This is retained as a provenance caveat rather
than hidden: the data HDU remains readable, the complete file SHA-256 matches
the registered raw-input manifest, and its direct NSIDE64 array is bit-exact
against the compact cache. The first full gate invocation therefore wrote the
green JSON receipt but exited while formatting a relative output path; the
path-only CLI defect was fixed and covered by a regression test without
altering the computed receipt.

The raw 731 GB PR3 ensemble has **not** been deleted. Even a green compact gate
cannot authorize deletion while PR4 access is externally blocked. A future
swap requires a versioned `PR4_REPLACEMENT_READY` receipt containing the exact
observed-map, simulation, exclusion, and noise-fix inventory. The gate resolves
every path and independently recomputes every size and full SHA-256 plus a
canonical inventory hash; shape-only or digest-string-only receipts fail.
Mechanical eligibility still performs no deletion and explicit authorization
of the PR3-to-PR4 storage swap remains a separate later human action. This
validator may report `mechanically_deletion_eligible=true`, but deliberately
keeps `safe_to_delete_raw=false` because it has no human-authorization channel.
`scripts/k1_e2e_cache_gate.py` contains no deletion operation.

## Claim boundary

The `0.039` global rank is conditional on the PR3/FFP10 ensemble, registered
six-statistic pipeline, mask, and noise-reuse construction. It is not an iid
exact-rank theorem, isotropy proof, preferred-axis result, anisotropy or shear
detection, geometry inference, Bianchi-family identification, or native-solver
result. PR3 and future PR4 results must be reported side by side, never pooled.
