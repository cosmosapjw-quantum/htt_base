## Frozen specification

Capability: `CF4_CURRENT_STACK_AFFINE_FLOW_CLOSURE_AND_ATTENDED_SINGLE_LANE_EXECUTION`.

This PR must reuse exact PR-289 admission objects and the PR-305/306 attended
transaction. It may add CF4 as one exact registered primary-lane profile, but
must continue to reject `--all`, `CROSS_PROBE`, caller-selected entrypoints,
shell execution, root execution, downloads, signatures, keys, and nonces.

The CF4 operator binds the raw group catalogue and selected rows to Galactic
coordinates, positive-receding radial-velocity sign, declared distance and
velocity units, grouping, nested depth cuts, and zone-of-avoidance masks. It
fits monopole, three bulk components, and five traceless-shear components with
the full covariance. It reports response rank and the nuisance-identified set;
rank loss or a set containing the no-flow boundary produces a typed abstention,
never a forced point estimate or source label.

## Implementation result

- The dispatcher now has one immutable profile table whose exact key set is
  `PLANCK`, `CF4`. It continues to execute one lane at a time and now rechecks
  the worker path/argv, environment, output, timeout, runtime, and data-root
  bindings immediately before writing `start.json`.
- The CF4 operator has exactly nine columns: monopole, three bulk components,
  and five symmetric trace-free shear components. It consumes a positive-
  definite off-diagonal covariance in exact catalogue row order, applies
  distance-scale nuisance changes coherently to selection, velocity and shear,
  and checks affine rank 9 plus monopole-projected flow rank 8.
- Nuisance cases remain a joint finite identified set. Any failed profile or
  weak response returns a typed abstention with no coefficient point estimate.
  No p-value, source label, q/Q/Pi/F/G, posterior, or family result is emitted.
- The worker requires the nine exact PR-289 CF4 component identities and the
  literal Galactic/positive-receding/unit/group/depth/ZoA contracts. It writes
  the observed-open marker only after the attended start receipt exists. This
  PR never invoked that admitted mode.
