# PR-250 — Joint partial identification and finite covariance

Status: implementation candidate. This is an internal DAG card, not a GitHub
pull request.

## Implemented scope

- Added a joint random numerator/anchor contract with mandatory conditioning,
  identification status, shared-data identity and cross covariance.
- Added Fieller confidence sets. A denominator interval that touches zero
  returns `RATIO_UNIDENTIFIED`, an unbounded set and no point estimate.
- Added covariance-marginalized multivariate-t likelihood under explicit
  Gaussian/Wishart/independence/known-mean premises.
- Defined singular covariance inference on the supported quotient and reports
  any orthogonal null residual instead of assigning it zero cost.
- Made missing cross-block covariance fail in the claim-bearing lane; an
  explicit zero-factorization assumption exists only in the exploratory lane.
- Added split-sample and cross-fit prior-learning receipts. Same-observation
  selection and estimation is rejected, while fixed physical priors remain
  distinct from empirical-Bayes learning.
- Added null-sector reports that expose bounds and prior-sensitivity classes
  but cannot carry posterior or likelihood-evidence flags.
- Preserved Hartlap as a domain-checked diagnostic comparator and made unknown
  PR-200 coverage method names fail instead of silently selecting a fallback.
- Extended the exact rational feasible-set path to preserve objective
  recession as infinity rather than a synthetic big-M endpoint.

## Claim boundary

All likelihood uses are conditional on their declared assumptions. Partial
identification, random-anchor stress, covariance likelihood, and null-sector
sensitivity remain different outputs. Nothing here identifies a Bianchi
family, detects geometry, or uses PR-151 partial acquisition.

## Kill conditions

The candidate fails if a zero-crossing denominator returns a finite ratio,
missing cross covariance becomes zero in a claim-bearing lane, singular null
residual is hidden, same-data empirical Bayes is admitted without a held-out
path, or Hartlap is presented as the evidence-grade finite-covariance
likelihood.
