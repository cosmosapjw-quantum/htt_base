# PR-053 - F certified filling fraction implementation

## Goal

- Owner: MIO
- Depends: PR-051, PR-052
- Level: L2
- Scope: pre-solver
- Risk: high

Implement a MIO-owned diagnostic-only certified `F` contract that pushes
sample-wise signed sign-clean `x_C` samples through admissible positive
ceilings. `F_Bayes` is the mean of sample-wise `F` values, not a ratio of
means.

## Chosen plan

- Add frozen `CertifiedFillingFraction` and
  `build_certified_filling_fraction`.
- Require matched `DepartureBundle`/`BudgetSpec` samples with matching
  comparator, frame, and units.
- Require `BudgetUse.CERTIFIED_FILLING_CEILING`,
  `is_admissible_ceiling=True`, finite nonnegative signed `x_C`, positive
  finite `U`, and `0<=F_i<=1`.
- Define `F_Bayes = math.fsum(F_i) / sample_count`; serialize
  `ratio_of_means_used=false`.
- Reject invalid samples rather than exporting invalid numeric payloads.
- Preserve separate departure and budget transfer provenance, reject
  mismatched transfer spec IDs, and leave external-transfer-derived departures
  explicitly transfer-conditional.
- Require `generating_command` plus either `git_commit` or `worktree_state`
  before payload export.
- Export the contract from `mio.formalism` and add MIO boot import coverage.

Alternatives rejected: legacy BASS clipping, Q extension, HTT evidence path,
weighted/posterior aggregation, external-transfer certified ceilings,
pre-native atlas certified ceilings, observational certified ceilings, and any
family or geometry interpretation.

## Claim-tier impact

This PR adds a MIO L2 diagnostic-only certified filling-fraction contract. It
is pre-solver sample-wise diagnostic bookkeeping under strict admissible-ceiling
and sign-clean conditions. It does not create HTT inference evidence, posterior
content, a MIO certificate, native solver output, transfer validation,
morphology compatibility, or geometry/family-identification evidence.

- owner: MIO
- implementation_scope: mio

  PR-014 metadata and remain transfer-conditional

## Risk log

- DoD:
  - F requires a sign-clean sector.
  - F requires an admissible `U>0` certified ceiling.
  - F samples are bounded by `0<=F<=1`.
  - F is computed sample-wise.
  - `F_Bayes` is a sample mean, not a ratio of means.
- Kill switch: invalid F cannot export as physical occupancy.
- Residual risks:
  - F remains diagnostic bookkeeping; no statistical null calibration,
    PPC/LOOCV, native transfer, or morphology atlas support is added.
  - External-transfer-derived departure inputs can feed F only with explicit
    transfer provenance; PR-053 does not validate external transfer as native.
  - Legacy BASS descriptive report clipping remains a legacy compatibility
    path and is not the new MIO F contract.
