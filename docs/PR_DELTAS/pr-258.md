## Implemented changes

1. Added factory-only finite analytic/synthetic
   `ResponseClassManifoldSpec` values. Public identifiers use only the
   `response-class-*` namespace; exact duplicate nodes are removed
   canonically, every coordinate numerically equal to zero is normalized to
   `+0.0`, and every retained node gets a stable content identity.
2. A future-native class and adapter remain schema-only at `NEEDS_NATIVE`.
   They cannot carry synthetic or external-transfer response values.
3. All distances use
   `OBSERVABLE_COVARIANCE_SQUARED_DISTANCE_V1`. Equivalence tolerance,
   unknown threshold, and decision margin occupy the same squared-score
   space with conservative equality behavior.
4. PR-258 reuses the public PR-255 supported-geometry path with identity
   response-coordinate scaling. It does not copy PR-255 private covariance
   helpers or attribute information gain to an anchor.
5. Reports retain supported rank and covariance-null residuals.
   `OUTSIDE_SUPPORTED_QUOTIENT` dominates a finite-node candidate.
6. Tolerance-nearness is closed by connected components while retaining
   direct edges and the full squared-distance matrix. Non-clique closure is
   `TYPE_UNIDENTIFIED`, not pairwise equality.
7. Added node-keyed `ReopeningObservableSpec`. Each available added
   observable binds every base support-node ID, an enlarged joint covariance
   including cross-covariance, and an enlarged nuisance identity. The full
   graph over every response class is recomputed.

   `NOT_APPLICABLE`; local/global-labelled classes require a PR-256 report

   `SUM_ONLY`, and missing-provider statuses prevent a response-class

   report contract.
