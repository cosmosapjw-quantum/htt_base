# PR-249 — State, estimand and reporting separation

Status: implementation candidate. This is an internal DAG card, not a GitHub
pull request.

## Implemented scope

- Added immutable `DepartureState` for the signed 12-component irreducible
  state and a separate non-negative `SummaryDepartureState`.
- Added recession-aware `IdentifiedDepartureSet`, support-function and explicit
  structural/leading-order/numerical null kinds. Empty sets do not project to
  apparently bounded intervals.
- Added channel-keyed `SectorStress` and `AnchorStressReport`; mismatched or
  missing anchors return typed non-numeric statuses. The report label is
  independently bound to the anchor target sector, so reusing an otherwise
  valid channel key under another sector is rejected.
- Added `BudgetRadiusResult` and a supported-quotient implementation that
  reports null residuals instead of assigning them zero cost. Rank uses a
  relative eigenspectrum tolerance and is invariant under positive changes of
  budget units.
- Classified unchanged historical `x_C`, `Q`, `F`, `F_C+/-`, `Pi`, and `G_F`
  values through `LegacyProjectionReport` with immutable BC1/BC2 allowed-use
  rules, exact diagnostic identities, and required bin/null metadata.
- Removed active cross-sector `sector_filling`; the explicit compatibility
  helper labels its denominator `SYNTHETIC_SUPPORT_BOUND`.
- Made `W2` canonical and retained `V2` only as a typed alias that explicitly
  excludes Nilsson `W_N2`.
- Consolidated the three Imbens-Manski critical-value implementations behind
  one strict common primitive.

## Claim and compatibility posture

This card changes representation and active allowed-use semantics, not the
numeric value of any frozen historical `x_C` artifact. A more explicit state
does not promote its claim tier. Stress, morphology, nonlinearity, probability,
occupancy and evidence remain distinct outputs.

## Tests

The card tests exercise immutability, component shapes, signed cancellation,
recession support, empty-set propagation, structural-null identity,
channel-mismatch and missing-anchor outcomes, singular budget quotients,
synthetic-bound legacy compatibility, and common IM boundary behavior.

Initial implementation suite: `394 passed` (two pre-existing warning-only
diagnostics).

The first sealed read-only review failed on three independent counterexamples:
cross-sector relabelling, scale-dependent PSD rank, and caller-weakened
BC2/Q-F-Pi-G_F metadata. The repaired card test has `8 passed`; the independent
counterexample oracle now fails at construction as required. The repaired
relevant suite has `296 passed, 8 skipped`, plus one infrastructure-only
failure because the isolated worktree intentionally has no `venv/bin/python`.
Running that byte-stability check directly with the canonical environment
returns `ok: true`.

The second sealed review found two further type-boundary bypasses. The final
repair requires actual frozen `DiagnosticScalarReport`/`ScalarRange` children
instead of duck-typed mutable objects and rejects boolean arrays before NumPy
can coerce them into scientific coordinates or PSD budgets.

Kill the candidate if a null direction receives zero cost without a residual,
an empty set projects to a finite interval, a channel-mismatched ratio becomes
numeric, or `x_C` is described as a distance, occupancy or evidence.
