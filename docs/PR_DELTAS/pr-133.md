## Typed-quantity firewall + non-bridge guard

`htt/src/common/source_response_types.py` makes six distinct types:
`observer_proxy` (A_v, kinematic, O(beta), ell=1, NOT physical),
`physical_tilt` (Omega_tilt, O(beta), ell=1), `vorticity` (W2),
`shear` (Sigma), `curvature` (Delta_Omega_k), `background_geometry`.
Cross-type arithmetic (add/sub) and ordering (<, <=, >, >=) raise, and
cross-type equality is always False; the only sanctioned conversion is
`bridge()` across a registered equivalence edge. The registry is EMPTY,
so the A_v -> Omega_tilt bridge is refused. Python cannot forbid direct
reconstruction (`TypedQuantity(PHYSICAL_TILT, x)` asserts a NEW tilt
value, it does not bridge a proxy), so a bridged value carries a
`bridged:<edge>` provenance and `require_declared_provenance` catches
any quantity whose provenance names an unregistered bridge.
