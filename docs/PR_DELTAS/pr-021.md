## Design decisions

### 1. Normalization 전략 (pr-021-design.md §3.3)

**결정**: state-level value 는 MB-95 과 동일 수치로 copy, MB-95 과의 비교는 `PstfObservables::from_state()` 가 제공하는 **physical observable** (δ_γ, v_γ) 수준에서만. PR-020 의 `flrw_norm_ratio_down` 실패 (factor-9 error at ℓ=1) 의 교훈 직접 적용.

```rust
// State-level: 그대로 복사
state[layout.i_photon_i_m0(0)]  = 0.5;                  // I_0 = Θ_0 = 1/2
state[layout.i_photon_i_m0(1)]  = k / (6.0 * adotoa);   // I_1 = Θ_1

// Observable projection: MB-95 관례 적용
impl PstfObservables::from_state:
    delta_gamma = 4 * state[i_photon_i_m0(0)]   // MB-95: δ_γ = 4·Θ_0
    v_gamma     = 3 * state[i_photon_i_m0(1)]   // MB-95: v = 3·Θ_1
```

결과: MB-95 의 `adiabatic_ic` 가 setting 하는 `Θ_0 = 1/2` → `δ_γ = 2.0` 과 PSTF `from_state().delta_gamma` 가 **수치 등가** (bit-identical, 1e-15 tolerance 내).

### 2. 방어용 test 추가 (1 개 초과)

Design §4.4 의 9 개에 더해 `validation_rejects_negative_adotoa` 1 개 추가. 음수 adotoa 입력 시 panic. Hard invariant 방어.

### 3. Fluid/metric 영역 무접촉 증명

`caveat_fluid_sector_untouched_by_ic` test 가 PSTF state vector 의 metric (11 DOF), baryon (4 DOF), cdm (4 DOF) 영역 모두 0 유지 검증. 이것이 성립하는 이유:

1. `pstf_adiabatic_ic` 가 `vec![0.0; n_state]` 로 시작
2. Write 하는 영역은 `i_photon_i_m0(0..1)` 와 `i_neutrino_m0(0..1)` 뿐
3. PR-020 의 `channelwise_index_blocks_disjoint` test 가 이 인덱스 영역들이 fluid/metric 과 disjoint 임을 보장

## Anti-local-minimum observation

Pre-audit §6 에서 3 개 trigger 를 사전 정의 했다:

1. **Normalization mismatch** — 실제로 발생하지 않음. State-level copy 전략이 PR-020 의 경험을 반영해 안전하게 작동.
2. **k-linearity failure** — 발생 안 함. Ratio test 1e-12 tolerance 내 통과.
3. **Scope creep** — 발생 안 함. IC 함수가 photon+neutrino 2 DOF 짝 4개만 건드림.

PR-021 은 `STUCK_LOG.md` entry 추가 없이 종료. Anti-local-min rule 은 예방 효과만 발휘 (trigger 미작동 = rule 정상 작동).
