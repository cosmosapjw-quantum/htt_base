# PR-054 - Pi exceedance curve and threshold discipline

## Goal

- Owner: MIO
- Depends: PR-052, PR-053
- Level: L2
- Scope: pre-solver
- Risk: medium

Add a MIO-owned diagnostic-only Pi exceedance-curve contract. Pi is a curve
over explicit Q or certified-F diagnostic samples under an explicit measure and
threshold policy. It is not a truth probability, posterior, evidence term, or
family/geometry result.

## Chosen plan

- Add `MeasureKind` and `ThresholdPolicy`.
- Add frozen `ExceedanceCurve` with explicit `measure_kind`, target
  `source_score_label`, strict `sample_value > threshold` counting, sorted
  unique threshold grid, `pi_grid`, sample counts, source metadata, transfer
  provenance, sky/covariance/null status, config/input hashes, command, and
  worktree/git provenance.
- Add `build_exceedance_curve()` plus Q/F bridge builders that preserve
  source config, numerator/denominator policy, certified-F sample provenance,
  and PR-014 transfer metadata.
- Require `BudgetUse.EXCEEDANCE_THRESHOLD` for Q/F bridge inputs.
- Keep selected thresholds legal only under pre-registered threshold metadata;
  otherwise payloads remain curve-only.
- Reject hidden selected-threshold fields, post-hoc threshold metadata,
  reserved source-kind or metadata language, non-JSON metadata, missing
  transfer specs, native-transfer labels, and null/mock measures without
  support status metadata.

Rejected alternatives: truth-probability scalar API, HTT posterior route,
COMMON skeleton extension, Q/F helper-only implementation, native solver or
family-ranking surface, and p-value/FPR language without matched null and
look-elsewhere metadata.

    or positive-part Q for PR-054 Pi.

## Claim-tier impact

This PR adds MIO diagnostic-only Pi exceedance-curve bookkeeping. It is
pre-solver and source-provenanced. It does not create HTT posterior/evidence,
MIO certificates, p-values/FPR claims, native solver validation, transfer
validation, morphology compatibility, or geometry/family-identification
evidence.

- owner: MIO
- implementation_scope: mio
- pr_scope: pre-solver
- claim_tier: diagnostic_only
- transfer_source: none by default; transfer-labelled direct or bridged inputs
  must carry PR-014 metadata and remain transfer-conditional
- sky_support_status: source status or `not_directional`
- null_mock_status: source status or `not_statistical`; non-default required
  for null/mock measures
- covariance_status: source status or `not_statistical`; non-default required
  for null/mock measures
- ppc_status: not_applicable
- loocv_status: not_applicable
