implementation on the canonical PR-282 target. A supplied
`SourceResponseGeometryReport` is accepted only after exact replay with an

## Implementation repair

- `source_separation_gate_from_pr256` now requires exact `normalizer` and
  `threshold_contract` arguments. Neither argument has an optional production
  default.
- The gate replays the full source-response geometry through
  `revalidate_source_response_geometry` before it computes a decision or
  serializes the report identity. Copied or mutated report fields therefore
  fail closed.
- The replayed report must use the exact content identity of the threshold
  registered by the PR-283 contract. An alternate factory-derived contract
  cannot relax only the singular-value threshold and regrade the same report.
  The threshold decision is always evaluated; the former
  `threshold_contract=None` bypass is gone.
- The PR-258 oracle, PR-273 blind synthetic integration, anisotropy report
  tests, and open-set response tests now pass the exact normalizer and the
  registered threshold contract.
- Hostile cases cover a missing threshold, an alternate singular threshold,
  a non-`NormalizerSpec` value, and a copied report with mutated
  principal-angle content.
- The PR-272 frozen-source relocation and exact predecessor replay remain
  executable. The PR-273 blind synthetic pack was regenerated because the
  migrated caller now records an adjudicated source-separation decision in
  each type-report content identity; challenge data, truth data, numerical
  case outputs, partitions, and the diagnostic-only ceiling are unchanged.
- The G06 runner and exact-parity regression changed the predecessor receipt's
  declared source bytes. The historical PR-282 receipt was therefore not
  reused: the existing builder regenerated it from this tree and its full
  exact-replay suite now passes.
- The existing PR-280 hermetic runner now includes the repository root in its
  isolated source-root allowlist. This is the minimal portability repair for
  importing the existing `scripts.codex_harness` package in a clean replay.
- The PR-283 receipt contains ten registered mutations and derives its
  terminal state from their executed, activated, and killed outcomes. The
  weak-status and precedence mutants now execute altered gate status through
  the real classifier before the mandatory-abstention oracle kills them; they
  are not positive controls over unchanged production output. The receipt
  does not embed a circular candidate commit identity; the candidate seal
  supplies that external binding.
