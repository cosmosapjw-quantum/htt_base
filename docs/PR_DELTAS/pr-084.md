## Review findings and fixes

- Finding: PR-084 target files were absent.
  - Fix: added the report generator, contract test, and generated public report.
- Finding: a report-only grep over status/claim-ledger files would miss live
  transfer metadata and result-card plumbing.
  - Fix: generator reads the PR-080 BASS adapter registry and separately
    inventories downstream result-card surfaces.
- Finding: the first validator expected a single internal string token and
  rejected legitimate external/proxy transfer-status rows.
  - Fix: validator now accepts the report's semantic vocabulary:
    external/proxy/per-section/current transfer status.
- Finding: future native schema support could be mistaken for a current native
  result if listed beside external rows without status.
  - Fix: native adapter status is listed as blocked/schema-only/non-consumable
    and excluded from current transfer dependency rows.
- Finding: custom `--output` wrote a report whose manifest `artifact_path`
  still named the default checked-in report.
  - Fix: pass the resolved output path into report construction and test both
    dry-run and non-dry-run custom output metadata.
- Finding: missing required source files could be skipped or recorded as
  `:missing` while the report still claimed all gates passed.
  - Fix: required input and downstream source files now fail closed, required
    downstream row IDs are enforced, and downstream `:missing` hashes are
    rejected.
- Finding: native/provisional downstream payload summaries could be labeled
  merely as no external/proxy source.
  - Fix: `BASS_native_provisional` payload summaries fail closed as
    schema-only/non-consumable, and `BASS_native_validated` payload summaries
    require transfer metadata with native validation gates.

## Claim-tier impact

This PR is COMMON diagnostic report and provenance bookkeeping. It reports
transfer-conditional status for current external/proxy result surfaces.

- owner: COMMON
- implementation_scope: common
- claim_tier: diagnostic_only
- transfer_source: none for the report artifact; listed rows include
  `AniCLASS_external`, `empirical_proxy`, `external_transfer`, and future
  schema-only `BASS_native_provisional` status.
- sky_support_status: not_directional for the report artifact; downstream rows
  carry explicit per-section or explicit-field status.
- null_mock_status: not_statistical for the report artifact; downstream rows
  carry explicit per-section or explicit-field status.
- ppc_status: not_applicable
- loocv_status: not_applicable

PR-084 does not evaluate transfer callables, validate transfer calibration,
create HTT posterior/evidence content, create MIO certificate content, treat
future native schema rows as solver values, establish morphology compatibility,
or support geometry/family claims.
