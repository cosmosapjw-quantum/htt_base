# PR-319 — bind the public 2024 2MRS neural velocity field

PR-319 replaces the unavailable/private 2026 2MRS reconstruction in the
JWST-SN readiness lane with the public Lilow–Ganeshaiah Veena–Nusser 2024
neural reconstruction.  This is an explicit scientific substitution, not a
claim that the two reconstructions are byte- or method-equivalent.

The source is [arXiv:2404.02278v2](https://arxiv.org/abs/2404.02278) and the
author repository is
[rlilow/2MRS-NeuralNet](https://github.com/rlilow/2MRS-NeuralNet), pinned for
documentation semantics at commit
`c4c141357f6c99d0d0f30784a1116afa204d91f6`.  The upstream Dropbox share is
mutable and publishes no per-file checksums.  Two independently downloaded
ZIP containers had different container hashes, but every one of their eight
NumPy members had identical SHA-256 bytes.  PR-319 therefore binds the member
hashes, not the packaging hash.

## Scientific operator

The 2024 product is not relabelled as a distance-modulus prediction.  It is a
CMB-frame radial-velocity response template used only in the existing
covariance-whitened, column-scaled response-rank diagnostic.  The registered
evaluation is:

1. convert a source-reported host depth in Mpc to the paper's comoving
   `h^-1 Mpc` coordinates with the fixed `h=0.6711`;
2. form the Galactic Cartesian position from `(l,b,depth)`;
3. trilinearly interpolate the three cell-centred velocity arrays only inside
   the valid `r<200 h^-1 Mpc` sphere and only when all eight corners are finite;
4. project onto the outward Galactic radial unit vector, so positive velocity
   is away from the observer.

No magnitude conversion is invented.  The released `*_error.npy` arrays are
pointwise validation RMSE summaries and are never treated as a spatial or
cross-component covariance.

An independent local replay over the exact released arrays gives the published
`R=50 h^-1 Mpc` convention check:

```yaml
mean_velocity_km_s: [-53.6293, -213.8654, 24.1579]
amplitude_km_s: 221.8064
galactic_l_deg: 255.9227
galactic_b_deg: 6.2527
```

This validates axes, units, frame, and radial sign.  It is not a JWST-SN
result.

## Data and release boundary

All eight arrays are present off-repository and their shapes, dtypes, finite
support counts, and hashes were checked.  The external array license is not
explicitly stated separately from the GPL code repository and CC-BY paper.
The bytes therefore remain private/off-repository and are not redistributed.
Observed execution also remains blocked until the complete five-component
JWST admission, exact host evaluation, and the separate CF4 competitor are
materialized together.
