## Covariance identification result

Reported marginal method variances define a fixed-diagonal PSD uncertainty
set; they do not identify one shared covariance matrix.

- CCHP exact full method-level mean-SE range: `[0, 0.10471429] mag`;
  reduced contrast-diagonal sensitivity range: `[0, 0.07663606] mag`.
- SH0ES exact full method-level mean-SE range: `[0, 0.12538462] mag`;
  reduced contrast-diagonal sensitivity range: `[0, 0.09415092] mag`.
- Registered structured slices are covariance-conditional. Their posterior
  endpoint envelopes are `[-0.09615205, +0.16086370] mag` for CCHP and
  `[-0.15995513, +0.10430522] mag` for SH0ES.

The formal terminal result for both source families is therefore
`TOTAL_UNCERTAINTY_NOT_IDENTIFIED`, not equality of methods and not an H0 or
cosmological inference. Prior sensitivity, leave-host-out, Gaussian versus
Student-t robustness, 3000-realization SBC, and 5000-draw PPC gates pass.
