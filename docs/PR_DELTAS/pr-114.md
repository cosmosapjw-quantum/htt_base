# PR-114 - External audit package generator

## Goal

- Owner: COMMON
- Depends: PR-110, PR-111, PR-112, PR-113
- Level: L4
- Scope: pre-solver external audit disclosure package
- Risk: medium

Build a deterministic COMMON-owned audit package generator that bundles scoped
code snapshots, result packs, manifests, manuscript blocker reports, PR status,
claim/status ledgers, transfer provenance, and adversarial audit prompts. The
package is a disclosure artifact, not an audit-pass or publication-readiness
claim.

## Chosen plan

- Added `scripts/build_external_audit_package.py`.
- Added `tests/contracts/test_audit_package_generator.py`.
- Added static adversarial prompts under `docs/audit_prompts/`.
- Generated `docs/generated/external_audit_package.zip`.
- Generated `docs/generated/external_audit_package_manifest.json`.
- The generator builds a manifest-compatible payload first, then writes a
  deterministic ZIP with fixed timestamps and sorted archive paths.
- The ZIP embeds `MANIFEST.json`, `README.md`, prompt files, scoped code
  snapshots, status/claim ledgers, result packs, transfer provenance report,
  manuscript blocker reports, progress files, and dependency PR deltas.
- The package fails closed when required inputs are missing and `--check` fails
  stale outputs without rewriting them.
- The package preserves PR-113 blocker state instead of hiding it:
  22 missing figure references, 72 quarantined figure references, and 13
  claim-risk findings in the manuscript audit report.

Rejected alternatives: broad whole-repo zipping, prompt text generated only
inside the archive, treating the package as external approval, omitting the
claim ledger, omitting the transfer report, or including figures directly
instead of the figure inventory/quarantine reports.

## Review findings and fixes

- Finding: the first generator used a dataclass with postponed annotations that
  failed under importlib-based test loading.
  - Fix: removed postponed annotations so the module imports cleanly through
    `spec_from_file_location`.
- Finding: check mode initially compared against a manifest whose generating
  command included `--check`.
  - Fix: normalized `generating_command` by dropping the check flag; write and
    check modes now compare the same expected manifest.
- Finding: concurrent status-scoreboard regeneration and package generation
  made the package stale.
  - Fix: regenerated status/progress artifacts first, then regenerated the
    audit package serially and reran `--check`.
- Finding: two archive-entry descriptions used wording that blunt scanners
  could read as MIO-owned evidence.
  - Fix: changed those labels to trace-anatomy wording and regenerated the
    package manifest/ZIP.
- Finding: manuscript materials are not release-clean.
  - Fix: the package includes the blocker reports unchanged; PR-114 does not
    attempt to resolve or hide them.
