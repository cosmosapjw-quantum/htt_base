## Exact-discrete estimator (Phipson-Smyth)

`htt/src/common/finite_null_ranking.py`: the observation and every null
row are scored and maximized the SAME way, and the global p-value is the
exchangeable pooled rank

    p = (1 + b) / (N + 1),   b = #{null_score >= obs_score}

with the conservative (`>=`) tie policy — a Phipson-Smyth exact-discrete
estimator (arXiv:1603.05766) on the finite support `{1/(N+1), ..., 1}`:
never 0, never below the 1/(N+1) resolution. A fully-tied column gives
p = 1. The core formula was independently confirmed against the
published Phipson-Smyth definition in the review lane.

## Super-uniformity, demonstrated genuinely (both P0 fixes)

- **Real exact enumeration** (`exact_rank_distribution`): places the
  observation at each of the N+1 gaps among N nulls, calls the ACTUAL
  `pooled_rank_p` on each placement, and confirms the enumerated
  p-values equal the grid exactly (`enumerated_matches_grid`). This
  exercises the estimator being certified — not an assumed
  1/(N+1)-per-cell distribution.
- **Seeded type-I simulation** with a sub-resolution alpha: the
  alpha grid includes 0.01 < 1/40, where the correct estimator rejects
  with probability EXACTLY 0 (its minimum p is the floor) while a b/N
  NEGATIVE CONTROL rejects at 2.2% and produces exact-zero p-values
  caught by the floor gate — so the check has genuine power to
  distinguish the two estimators, not a loose tail band.

## Resolution/sigma guard

`gaussian_sigma_from_p` refuses any p at or below the 1/(N+1) floor
(the finite null cannot resolve a finer significance); above the floor
the erfinv-based sigma matches `scipy.stats.norm.isf` to ~1e-8
(0.01 → 2.5758, 0.05 → 1.9600). A production gate `validate_reported_p`
that every reported p passes rejects the naive b/N zero.

## Dependence-preserving max scan + load-bearing split

`scan_pooled_rank_p` reduces within each row to ONE score per null (the
dependence-preserving reduction); `require_rowwise_reduction` refuses a
flattened iid pool of all scan points (N*scan_len scores). The module
enforces matched geometry and the row-wise reduction; it does NOT
verify the rows are actually correlated (the caller's matched-null
contract, stated honestly). `split_evaluated_rank_p` computes the
global p over the HELD-OUT evaluation rows only — the
calibration/evaluation split is now load-bearing, not decorative.
