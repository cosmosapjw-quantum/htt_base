## Frozen scope

Capability: `HSC_KIDS_TYPED_SPIN2_TOMOGRAPHY_AND_JOINT_RANK_CLOSURE`.
The current stack consumes only the exact fifteen-component PR-289
`HSC_KIDS` admission. HSC S19A/Y3 and KiDS-1000 DR4.1 remain distinct survey
branches with separate product, mask, random, PSF, n(z), calibration/response,
and covariance identities. A caller cannot substitute `HSC`, `KiDS`, `--all`,
or `CROSS_PROBE` for the single registered `HSC_KIDS` lane.

Raw catalogue `gamma1,gamma2` pairs are typed spin-2 inputs in a right-handed
north/east sky basis. A passive basis rotation uses `exp(-2 i psi)`. The raw
pair is never named E/B: a declared nonlocal, full-rank linear provider runs
before the `E_THEN_B` type exists. Survey-owned n(z), calibration, and response
identities then enter executable tomography; changing a row's bin changes its
feature, while a joint row permutation does not.

The selected forward family is typed pseudo-C_l. Its frozen feature order
contains both EE and BB for every declared auto/cross-bin pair. A nontrivial
mask-coupling matrix and its checked inverse are applied identically to signal
and synthetic controls. Pure-E-to-B and pure-B-to-E leakage are both tested.
The fixed headless axis is compared only after shortest-geodesic spherical
parallel transport; antipodal endpoints abstain.

Joint rank is evaluated only after a supplied full covariance
`[[C_H, C_HK], [C_HK^T, C_K]]` passes shape, order, finiteness, symmetry,
positive-definiteness, conditioning, and nonzero cross-block checks. A missing,
invented-zero, block-diagonal, asymmetric, or indefinite covariance returns
`JOINT_COVARIANCE_REQUIRED_ABSTAIN` before rank. Cholesky-left whitening,
per-column weighted L2 scaling, and nuisance-incremental SVD make the rank
decision invariant to nonzero response normalization. Rank loss returns
`NON_IDENTIFIED_ABSTAIN`, never a coefficient, p-value, or source label.

## Source and data boundary

[S19A/Y3 shape release](https://hsc-release.mtk.nao.ac.jp/doc/index.php/s19a-shape-catalog-pdr3/)
and KiDS-1000 to its [DR4 shear catalogue](https://kids.strw.leidenuniv.nl/DR4/KiDS-1000_shearcatalogue.php).

official release surfaces do not supply an HSC-KiDS cross-survey covariance.
Consequently the code-ready operator remains data-blocked until separately
normalized typed products and a scientifically justified full cross block are
admitted. No zero cross block is manufactured.

The admitted path replays exact PR-289 record order and hashes before parsing
the normalized components, and is reachable only after the attended executor
has written `start.json`. This PR downloaded and opened no observed payload.
