## The nuisance identified set

box (distance-scale calibration ∈ [-0.05, 0.05]; reconstruction observable ∈
{primary = V3k − H0·Dist, Vpec, Vpwf}; nonlinear dispersion σ_nl ∈ [150, 350])
over the flow-plus-monopole estimand — the ℓ=0 monopole is ALWAYS fit so a
radial calibration nuisance cannot alias into the ℓ=1 bulk flow — is swept, and
the depth-resolved CF4 bulk flow is returned as an IDENTIFIED SET per distance
shell: its amplitude interval and apex cone, classified bounded / empty /
unbounded / undetermined (binding the PR-136 `SetStatus` vocabulary).

The honest outcome is that the set is **bounded at every depth shell but its
amplitude interval and apex cone widen with depth** (shell 0 [116, 345], cone
10°; shell 1 [270, 564], cone 17°; shell 2 [286, 826], cone 7° km/s), so no
favourable endpoint is a point estimate and a set containing zero is never read
as isotropy. The identified-set endpoints use a CONTINUOUS optimiser as the
authority with the GRID vertex enumeration enforced as a kill switch; the mesh
sensitivity probes the continuous-optimiser restart stability and reports the
grid-minus-continuous gap; the genuine simultaneous coverage (one shared
injected realisation scored jointly across the shells, Imbens-Manski widened,
binding PR-137) is 0.913, with the per-shell Rice-bias undershoot at
noise-dominated depth disclosed; and the GLS-versus-OLS weighting difference
under a common injected field is predicted (NOT the minimum-variance
ideal-window estimator). A mis-specification diagnostic shows that omitting the
monopole while sweeping the calibration manufactures an artificial
direction-undetermined / effectively-unbounded topology, and a
plausible-unbounded calibration prior yields an unbounded status.

- **P1** — the "bounded → direction-undetermined → effectively-unbounded"
  headline was an artifact of the inadmissible `monopole=False + calibration≠0`
  combination (a distance-scale offset is a radial ℓ=0 mode that aliases into

  fit; the frozen box gives an all-bounded, widening set, and the artificial

  marginals. Fixed: genuine simultaneous coverage scores one shared realisation
