`htt/src/common/frame_typed_algebra.py` makes three audit defects
structural, not prose:

- **H02/H03 (signed carrier + frame mixing).** Every component carries a
  frame tag (`n`/`u`/`obs`, no default); cross-frame arithmetic raises
  unless a registered bridge is used (a bridge carries a declared
  remainder order). The carrier is `S+^3 x R`: the PSD-cone embedding
  applies only to the positive block {Sigma^2, W^2, Omega_tilt}, while
  the signed `DeltaOmega_k` lives on the R factor and is never
  PSD-clipped — both signs pass (negative-branch sign -1 verified; a
  negative positive-block value is rejected).
- **H09 (order mismatch).** Boost order is a type parameter. Omega_tilt =
  (1+w)Omega_m sinh^2(beta) is O(beta^2); the observer-boost kinematic
  quadrupole is O(beta^2); Omega_tilt^2 is O(beta^4). Since 4 != 2, the
  Omega_tilt^2 subtraction cannot cancel the quadrupole and is refused;
  the order-correct deprojection subtracts an O(beta^2) term.
- **H10 (pair density).** Single-stream and antipodal-pair Omega_tilt are
  distinct typed constructors; the fixed-total-density pair equals the
  single-stream value while the fixed-per-stream-density pair doubles —
  the factor-two convention is explicit.
