## Chosen plan

- Added a new depth-null contract in `htt.nulls.local_boost_depth_null`:
  `DepthBinSpec`, `LocalBoostNullConfig`, `DepthNullSample`,
  `DepthNullMockBank`, `LocalBoostDepthNull`,
  `LocalBoostNullFprReport`, and
  `evaluate_global_tilt_local_null_gate`.
- Added `htt.nulls.clustering_dipole_depth.ClusteringDipoleDepthNull` as a
  local-structure depth-null bank using the same HTT diagnostic contract.
- Kept these new banks out of the legacy five-family `NULL_REGISTRY` so old
  scalar null tests and reports remain reproducible.
- Bound the local-null FPR report to a PR-060 `ResponseOverlapAudit` so missing
  or rank-deficient local/global response state blocks downstream eligibility.
- Wired `build_discrimination_matrix()` so `global_tilt|local_boost` cannot
  promote beyond exploratory/diagnostic status unless a PR-061 local-null FPR
  report passes the prerequisite gate.
- Added optional response-overlap config-hash pinning so callers can reject a
  stale or wrong PR-060 rank audit even when it is full rank.
- Added FPR numerator/denominator, Wilson intervals, look-elsewhere adjustment,
  detection-rule metadata, normalized direction distributions, depth-bin
  metadata, sky/mask/scan hashes, covariance/null statuses, config/input hashes,
  random seeds, caveats, generating command, and git/worktree state.
- Corrected stale PR-061 backlog paths from `htt/src/htt/nulls/...` to the live
  `htt/htt/htt/nulls/...` package root in both YAML mirrors and the long-range
  markdown backlog.

Rejected alternatives: fake native solver values, native morphology atlas
claims, HTT posterior/evidence plumbing, MIO certificate reuse, scalar-only
gate wrappers, and extending the old null registry in a way that would change
its five-family contract.

## Review findings and fixes

- Finding: the PR-card path used stale `htt/src/htt/nulls/...` targets.
  - Fix: implemented in the live `htt/htt/htt/nulls` package root and updated
    the YAML/markdown backlog mirrors.
- Finding: the existing scalar null interface cannot carry depth bins,
  directions, G_F values, FPR intervals, or rank binding.
  - Fix: added a separate depth-null contract and kept the old registry
    unchanged.
- Finding: the first sample validator normalized non-unit direction input.
  - Fix: `DepthNullSample` now rejects non-unit vectors instead of silently
    normalizing them.
- Finding: an exported `DepthNullMockBank` could be manually constructed with
  missing or duplicate `(mock_index, depth_label)` rows while FPR still divided
  by `n_mocks`.
  - Fix: `DepthNullMockBank` now requires exact complete mock/depth coverage,
    and tests cover the malformed-bank case.
- Finding: the FPR report accepted any full-rank response-overlap audit unless
  callers pinned the whole report hash.
  - Fix: the global-tilt local-null gate can now pin the expected PR-060
    `response_overlap_config_hash`.
- Finding: morphology/depth support alone still let
  `build_discrimination_matrix()` promote `global_tilt|local_boost` to
  conditional.
  - Fix: `build_discrimination_matrix()` now requires a passing PR-061
    local-null FPR report for that promotion and records local-null gate
    metadata in manifest statistics.
- Finding: JSON backlog mirrors and the root long-range backlog retained stale
  `htt/src/htt/nulls/...` PR-061 paths.
  - Fix: corrected the JSON mirrors and root backlog alongside the YAML mirrors.

## Claim-tier impact

This PR adds HTT diagnostic-only local-null calibration metadata. It supplies a
fail-closed prerequisite gate for downstream global-tilt claim eligibility, but
passing the gate removes only this specific blocker and does not authorize any
model-dependent output.

- owner: HTT
- implementation_scope: htt
- pr_scope: pre-solver
- claim_tier: diagnostic_only
- transfer_source: none
- sky_support_status: `pr040_sky_support_attached` in test fixtures and
  report payloads when supplied by callers
- null_mock_status: `local_boost_null_fpr_available` for the FPR report
- covariance_status: caller-supplied diagnostic covariance status, checked by
  the FPR gate
- ppc_status: not_applicable
- loocv_status: not_applicable

PR-061 does not run or fake a native solver, validate native transfer, create
HTT posterior/evidence content, create MIO certificate content, establish
morphology compatibility, or support geometry/family claims.
