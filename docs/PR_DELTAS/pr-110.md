## Chosen plan

- Added `scripts/result_packs/generate_pack_A_scalar_to_morphology.py`.
- Added `tests/result_packs/test_pack_A.py`.
- Generated `docs/generated/result_pack_A.md`.
- The generator builds a structured payload first, validates through
  `common.artifact_manifest.validate_manifest_payload()`, then renders
  Markdown from that payload.
- The result pack compares:
  - MIO Q, F, and Pi report surfaces;
  - OBSSTAT low-ell scalar and morphology/null-feature surfaces;
  - COMMON MES `I_morph` report status.
- The generator hashes the final generator, the legacy VER2 Pack A JSON source,
  PR-056/076/092 deltas, the MIO/OBSSTAT/MES source files, and the generated
  status snapshot.
- The older VER2 Pack A artifact IDs are preserved as hashed prior context and
  marked as prior context only. PR-110 does not promote their source tier or
  source gate status.
- Added `--check` so the generated report can be tested for drift without
  rewriting it.

Rejected alternatives: publishing the old VER2 pack unchanged, treating the
legacy BASS rows as current native support, creating a scalar-to-morphology
score, storing HTT inference content in the COMMON report, or omitting manifest
metadata because the report is prose.

## Claim-tier impact

This PR adds a COMMON-owned diagnostic-only result pack. It is a manifest-backed
comparison report over existing scalar, morphology/null-feature, and MES report
surfaces. It does not create HTT evidence content, does not turn MIO diagnostics
into COMMON scores, does not promote legacy VER2 gate wording, and does not
support geometry or family claims.
