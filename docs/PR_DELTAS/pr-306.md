## Scientific implementation

The operator freezes a non-amplifying common target beam/pixel transfer and a
full-rank real-linear mask inverse over ell 2–5. Component-specific SMICA and
Commander source beam, pixel, mask, and covariance identities remain distinct;
only the derived target and operator identities are shared.

Multipole vectors are the projective roots of the Majorana polynomial under a
frozen Condon–Shortley and stereographic convention. They are not the existing
power-tensor principal axes. Zero and infinity roots, antipodal pairing,
canonical axis signs, repeated roots, and exact vector cardinality are tested.
The polynomial/root convention follows the projective construction in
[Helling, Schupp, and Tesileanu (2006)](https://arxiv.org/abs/astro-ph/0603594);
the discrete transforms use the documented
[healpy `map2alm`/`alm2map` interface](https://healpy.readthedocs.io/en/stable/healpy_spht.html).

The 24-element feature row is ordered as all 12 SMICA features followed by all
12 Commander features. Each covariance row is one matched same-sky FFP10
realization. The full cross-component block is retained, and incomplete,
duplicated, reordered, rank-deficient, diagonal, or over-conditioned inputs
fail closed.

Only a complete ordered 999-row FFP10 inventory may reach finite calibration.
The 1/8/32/128 profile cells run feature throughput only and report
`NOT_RUN_PARTIAL_INVENTORY` for covariance, calibration, and response-rank
stages. The full cell uses a synthetic profile row and has resolution floor
`1/1000`; no observed statistic enters the benchmark.

Local response rank is computed after covariance whitening. No valid global
response is present, so the terminal boundary is
`ABSTAIN_GLOBAL_RESPONSE_UNAVAILABLE`; missing global response is not encoded
as measured rank zero.
