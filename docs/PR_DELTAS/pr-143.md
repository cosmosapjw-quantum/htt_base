## Blind DGP battery + non-author referee over a seed ensemble

`htt/src/common/synthetic_adjudication.py`: a generator seals a battery of
seven labelled DGPs (known-null, local, global, systematic, weak-ID,
dependent-mock, covariance-misspecified). The sealed truth is a
content-address of the realized labels AND data (seed-dependent), re-verified
at scoring time so any post-hoc tampering is detected. A BLIND analyst (the
PR-141 discrimination method) is handed ONLY the blind items (data + the known
survey geometry) — never the sealed challenge object — and predicts each item.
A NON-AUTHOR referee tallies per-family counts and scores size (the null
false-candidate rate), recovery, abstention, and computational-failure
behaviour over an ENSEMBLE of 10 seeds (150 items/family) against
pre-registered thresholds, producing a method-ready / block matrix.

## Honest outcome — a MEASURED size, not a "zero" claim

The method is READY on six DGP families plus the computational-failure lane and
BLOCKED on covariance-misspecification. The null false-candidate rate is a
MEASURED SIZE — 0.0067 (a small NON-ZERO value) — within the pre-registered
level alpha = 0.1; it is never claimed to be exactly zero. The
covariance-misspecified BLOCK is a genuine DIAGNOSTIC limitation (the
linear-Gaussian PPC attributes the abstention to inadequacy only about half the
time), recorded not hidden, so a data PR requiring covariance-misspecification
diagnosis from this method alone is blocked. Passing the synthetic challenge is
METHOD READINESS, not observed validity; the generator/analyst/referee
separation is content-addressed.
