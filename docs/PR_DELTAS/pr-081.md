# PR-081 - Future native low-ell adapter stubs without fake solver output

## Goal

- Owner: BASS_PY
- Depends: PR-080
- Level: L2
- Scope: pre-solver
- Risk: medium

Add BASS_PY schema-only contracts and a fail-closed adapter stub for a future
low-ell solver artifact. This PR prepares the handoff surface but does not run
a solver, load a solver artifact, synthesize native transfer values, validate
native transfer, create HTT evidence, create MIO output, or support morphology,
geometry, or family-identification claims.

  smoke coverage from repo root and temp cwd.
- Harden `common.transfer_registry.validate_transfer_dependent_result()` so
  explicit schema-only or non-consumable transfer metadata cannot be accepted
  as transfer-dependent result provenance.
- Correct stale BASS backlog file paths from `htt/src/bass/...` to
  `htt/bass/...` across YAML, JSON, and long-range markdown mirrors.

Alternatives rejected: adding value-producing native adapters, registering
fake native values in PR-080's external registry, using `BASS_native_validated`,
or creating the stale `htt/src/bass` package root.

## Review findings and fixes

- Finding: PR-081 and future BASS backlog cards pointed at the stale
  `htt/src/bass` root.
  - Fix: implemented under `htt/bass/transfer` and corrected BASS file paths
    in backlog YAML/JSON/markdown mirrors.
- Finding: direct schema metadata initially lacked claim-tier/scope/status
  downclaims.
  - Fix: `NativeLowEllSchema.to_metadata()` now emits implementation scope,
    claim tier, production status, no-values flags, and non-consumable status.
- Finding: schema-only `TransferFunctionSpec` metadata could pass as generic
  transfer-dependent result metadata.
  - Fix: `NativeSchemaTransferFunctionSpec` carries schema-only/no-values
    flags, and `validate_transfer_dependent_result()` rejects schema-only,
    non-consumable, or no-value metadata.
- Finding: `channels="TT"` was accepted as `("T", "T")`.
  - Fix: bare string/bytes channel inputs are rejected.
- Finding: mask, covariance, and harmonic-ordering metadata accepted blanks.
  - Fix: those fields are normalized and must be non-empty.
- Finding: output splits and future gates were too passive.
  - Fix: metadata now reserves per-observable split schema, tilt/boost status
    schema, gate-status schema, residual-summary schema, and future
    morphology-gate fields for equivalence graph, response rank, mask,
    covariance, and null mock references.
- Finding: wording blurred future solver artifact handoff with native transfer
  output.
  - Fix: user-facing errors and source references now say future solver
    artifact/interface pending native transfer output.
