## 주요 설계 결정

### 1. Linear RHS → state-independent Jacobian (`pr-022c-design.md §1`)

PR-022a (free-streaming) 와 PR-022b (collision) 모두 **state 에 linear**. 배경 변수 (k, τ, κ̇, r_b) 는 parameter 로만 들어감. 따라서 `J = ∂(M·y)/∂y = M` 은 단순 linear operator matrix.

구현 에서 `state: &[f64]` 를 accept 하지만 실제로는 **사용하지 않음** (interface consistency for future nonlinear extension). 테스트가 이것을 암묵적으로 검증 — `pstf_analytical_jacobian` 이 adiabatic IC state 에서도 동일한 triplet list 생성.

### 2. Triplet list + dense dual API

Sparse 로 표현하면 construction 효율적이고 (ℓ_max=16 에서 ~118 entries / 1156² dense matrix), Rodas5P 의 row-major dense format 은 별도 함수 (`pstf_jacobian_dense`) 가 triplet 을 unroll.

`equivalence_dense_vs_sparse` test 가 두 output 이 정확히 일치함을 검증 (non-listed entry 는 정확히 0.0).

### 3. 5-point FD stencil for G3 regression

3-point central difference 의 truncation error 는 O(h²), 5-point 은 O(h⁴). Round-off 를 고려하면 5-point 이 `h ≈ 1e-6·||state||_∞` 에서 훨씬 tight 한 tolerance 가능.

```
f'(x) ≈ [−f(x+2h) + 8·f(x+h) − 8·f(x−h) + f(x−2h)] / (12·h)
```

`jacobian_fd_check` 는 analytical 의 non-zero entries 만 FD 와 비교 (sparse columns only → efficient). Relative error threshold = 1e-6.

### 4. Performance 고려: columnwise FD 만 계산

Dense FD 는 n² RHS 평가 필요하나 (layout ℓ_max=16 → 1156² ≈ 1.3M calls). PSTF analytical J 는 sparse 이므로 실제로 FD 가 필요한 column 은 used_cols (~ℓ_max·2 개) 만. 이것만 `fd_column_5pt` 로 계산하여 **test 실행 시간 < 0.1s**.

## Sparsity analysis (verification)

`caveat_sparsity_count` test 가 ℓ_max_gamma = ℓ_max_nu = 16 에서 기대한 entry count 와 실제 `sparse.nnz()` 가 정확히 일치함을 검증:

| Block | Entry count (ℓ_max=16) | Formula |
|---|---:|---|
| Photon free-streaming | 33 | 2·lg + 1 |
| Neutrino free-streaming | 33 | 2·ln + 1 |
| Photon collision | 17 | 2 (ℓ=1 drag) + 1 (ℓ=2 damp) + (lg−2) |
| Baryon drag reaction | 2 | v_b cross + v_b diag |
| **Total** | **85** | |

Dense matrix: 1156² ≈ 1.34M entries. **Sparsity = 85 / 1.34M ≈ 0.006%**. Rodas5P 의 implicit solve 효율성 확보.
