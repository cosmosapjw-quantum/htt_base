# PR-314 — Planck PR3 SMICA-only existing-data diagnostic

## Scope

PR-314 applies the PR-306 low-ell operator to the locally complete SMICA slice
before waiting for the Commander archive. The primary null is exactly 300
paired rows, each formed as `SMICA CMB_i + SMICA noise_i` for release IDs
`00000` through `00299`. The separate 999-row CMB-only inventory is not pooled
with these rows and does not increase the primary calibration count.

This is deliberately not the full PR-289 PLANCK lane. It identifies a
single-component Planck PR3 research input, produces a SMICA-only diagnostic,
and leaves the thirteen-component joint admission and Commander robustness to
a downstream PR.

## Operator and statistic

The delivered maps are read as `K_CMB`, paired before reduction, and converted
to `microK_CMB`. Observation and nulls share the same SMICA beam, output pixel
window, common temperature mask, mask-coupling inverse, `l=2..5` harmonic
convention, multipole-vector convention, and frozen twelve-feature order.

The 300 null feature rows define a full `12 x 12` covariance. A diagonal,
non-positive-definite, rank-deficient, incomplete, or wrongly ordered path
terminates before finite calibration. Because the feature order mixes
`microK_CMB^2` and dimensionless entries, conditioning is gated on the
diagonal-standardized covariance and is invariant to per-feature unit changes;
the raw dimensional covariance is preserved. The reported feature-family value
is the conservative observation-inclusive rank over one observation plus 300
nulls, so its resolution floor is `1/301`.

No local response rank is invented for this slice. Commander agreement,
same-sky SMICA-Commander cross-covariance, joint response rank, and global
response all remain unevaluated.

## Attended and reproducible boundary

Metadata preflight checks the exact filenames and row inventory without
opening the observed temperature array. A compact plan records the Planck
release identity, observed filename and size, prepared component hashes, and
null row identity. Exact attended acceptance separately binds the current Git
commit/tree, worker, plan, and output directory, then writes `start.json` before
the observed map is read. The observed content hash is computed only after that
start record.

The completed result retains the band-limited observed SMICA map and the exact
300-row compact null input. A fresh replay recomputes the feature vector,
covariance, and finite rank without reopening the raw observed FITS.
