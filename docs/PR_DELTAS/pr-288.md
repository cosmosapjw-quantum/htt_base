# PR-288 — Bayesian semantics, evidence, PPC, and LOOCV repair

Status: `ACTIVE_SELECTIVE_SALVAGE`

## Scope and claim boundary

This increment adds a strict HTT-owned Bayesian-method lane over frozen
analytic and synthetic Gaussian fixtures. It does not execute observed data,
consume PR-151 partial acquisition, validate a native transfer solver, or
identify a Bianchi family. The artifact ceiling remains C2 `diagnostic_only`,
transfer source `none`, synthetic-only, observed-data execution false, public
use false, scientific status `OPEN_UNCHANGED`, and family identification
`BLOCKED_PRE_NATIVE_ATLAS`.

The PR-065 posterior-predictive, LOOCV, and prior-sweep summary builders remain
available for reproduction only. Their caller-authored summaries are not used
as current evidence or as anchors for this lane.

## Delivered capability

- Added normalized, content-addressed analytic fixtures for a scalar normal
  mean, two independent equal-model null copies, a correlated signal/nuisance
  model, and a covariance-misspecified negative control. Units, base measure,
  likelihood, prior, covariance, design rank, and randomization identities are
  frozen before engine execution.
- Added two independent marginal-evidence paths: Dynesty nested sampling with
  registered per-fixture seeds and scrambled Sobol integration with eight
  independent power-of-two randomizations per fixture. The comparison uses a
  preregistered quadrature-combined uncertainty threshold and an independent
  analytic closed-form check.
- Dynesty 3.0.0 is mandatory for the registered terminal pass. Missing,
  unparsable, or below-floor Dynesty versions produce the typed
  `BLOCKED_REQUIRED_ENGINE_UNAVAILABLE` result with no invented evidence; they
  are never silently skipped or replaced by Sobol.
- Replaced plug-in posterior-predictive semantics with 512 registered weighted
  posterior draws and one replicated dataset per draw. The same drawwise
  whitened residual is applied to observed and replicated data, with equality
  explicitly counted in the tail.
- Replaced caller-authored LOOCV fold scores with four exact foldwise Gaussian
  posterior refits. Each fold has its own training, held-out, nuisance-refit,
  posterior-draw, conditional-covariance, and integrated predictive-density
  identity.
- Added a misspecified-covariance negative control, equal-model null control,
  complete ten-result engine inventory, and 15 actually executed registered
  mutations. The aggregate builder independently revalidates the mutation
  executor's returned count, order, activation, kill status, and content
  identities before deriving a terminal.
- Added a frozen receipt with exact source-file bindings, engine versions and
  seeds, fixture/draw/fold/covariance/null identities, assumptions, caveats,
  claim metadata, terminal precedence, and a canonical content address.
- Added build, check, engine, focused, adjacent, and clean-archive portable
  runner modes. The writer preflights parent directories and refuses symlink,
  nonregular, or multi-link destinations before computation, then replaces the
  output atomically.
- Added a fail-closed publication policy whose claim-language command requires
  every named input, explicitly includes generated/provenance trees, and scans
  the frozen receipt as well as the implementation, tests, spec, and delta.
- Re-exported the strict aggregate receipt builder and validator from
  `htt.infer` without changing the legacy summary APIs.
