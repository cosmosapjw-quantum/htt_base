## Identified-set engine over the PR-127 graded basis

`htt/src/common/identified_set.py`: one API computes the identified set
of `(Sigma2, W2, Omega_tilt, DeltaOmega_k)` under equality and
inequality constraints and classifies the topology as BOUNDED, EMPTY,
UNBOUNDED, DISCONNECTED, or UNDETERMINED. The exact engine computes the
TRUE continuous per-axis identified interval by exact-Fraction
constraint intersection (axis-separable scope: each constraint touches
one axis; a multi-axis constraint is REFUSED as out of exact scope
rather than silently undersampled). The scipy HiGHS numeric engine
independently computes per-axis min/max with a big-M envelope for
unboundedness; a solver failure is UNDETERMINED, never unbounded.

## Cross-engine agreement (closes the false-precision hole)

`require_cross_engine_agreement` requires the two engines to agree on
the status, on the set of unbounded axes, AND on every bounded axis
interval to a tolerance — the bounded-axis comparison runs regardless
of the overall status, so a bounded axis inside an overall-unbounded
set is still cross-checked. A disagreement raises and blocks the
downstream claim.

## Rank deficiency bound live to PR-127

The response-rank-deficiency fixture is unbounded along exactly the
PR-127 kernel axes `{W2, DeltaOmega_k}`, DERIVED live from
`graded_nonid.EXPECTED_KERNEL_BASIS` (`_kernel_axes_from_pr127` +
`verify_kernel_binding`) so a PR-127 kernel edit cannot silently
desync. The full-parameter and subvector identified sets are reported
SEPARATELY as set-valued artifacts; the non-kernel subvector is bounded
while the kernel subvector is unbounded. The disconnected sign fixture
(`|Omega_tilt| >= 1` inside `[-3, 3]`) has two components of positive
width (`[1, 3]` and `[-3, -1]`) separated by the excluded open gap
`(-1, 1)`.

## Semantics + admissible pin

`validate_status_semantics` (wired on the production path per fixture)
enforces: empty != detection, broad != central/point estimate,
undetermined != non-identification. `AdmissibleBox.validate_proposed`
is a REAL guard — a proposed box tighter than the pinned box on any
axis (data-driven shrinkage to fit) is refused, while an equal or wider
proposal is allowed.

## Adversarial review lane (pre-commit)

Two P0: the "exact-Fraction polyhedral analysis" was actually a coarse
5-point-per-axis grid enumeration that undersamples any non-grid-aligned
boundary (all fixtures used integer boundaries so agreement was
coincidental), and the cross-engine check skipped bounded-axis
intervals whenever the overall status was unbounded — hitting the
flagship rank-deficient fixture. Both fixed by rewriting the exact
engine to compute TRUE continuous intervals by exact constraint
intersection and comparing every bounded axis regardless of overall
status. Plus four P1/P2: axis-separable scope undisclosed (now in the
spec + fail-closed refusal), semantics guard + admissible guard not
wired to production (now wired + the admissible guard made a real
check), KERNEL_AXES hand-copied (now derived live from PR-127), numeric
nonconvergence folded into unbounded (now undetermined), the
disconnected fixture degenerate to two points (now interior width), and
the topology cross-engine-agreement field hardcoded (now derived). All
fixed before commit.
