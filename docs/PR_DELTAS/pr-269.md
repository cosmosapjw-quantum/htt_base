1. Under the frozen `u^a u_a = -c^2` and

   coefficient.
2. Finite admitted inputs could produce nonfinite outputs: the smallest
   positive float used as explicit `c` returned an infinite coefficient in
   the R2 implementation, and a maximal finite sound-speed input overflowed
   the squared shape.

The second remediation defines `chi_s = dp/dmu` as a dimensionless ratio and
types the gradient itself:

- explicit-`c`: `eps_g = ||c D ln(mu)/Theta||`;
- `c=1`: `eps_g = ||D ln(mu)/Theta||`.

Both branches then have the same dimensionless coefficient
`-chi_s/(1+w)`. The implementation validates the gradient normalization
against the units branch and rejects every nonfinite computed coefficient or
shape. A subnormal but positive `c` now remains finite because it identifies
the gradient units and is not incorrectly divided into the coefficient.

The R2 claim pass cannot override the physics failure. Both lanes must review
the new frozen candidate again.
