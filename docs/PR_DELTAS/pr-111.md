## Chosen plan

- Added `scripts/result_packs/generate_pack_B_local_global.py`.
- Added `tests/result_packs/test_pack_B.py`.
- Generated `docs/generated/result_pack_B.md`.
- The generator builds a structured manifest-compatible payload, then renders
  Markdown from that payload.
- The result pack reports:
  - PR-060 response-overlap/rank audit status by reference;
  - PR-061 local-null FPR and PR-062 survey/systematic FPR prerequisite gates;
  - PR-063 local/global mixture status and full-design rank gate;
  - PR-066 HTT posterior-pushforward prerequisites and scalar-functional
    context without consuming MIO inputs;
  - PR-100 MIO directional coherence metadata as a diagnostic cross-check;
  - PR-101 MIO redshift-depth and G_F bridge metadata as a diagnostic
    cross-check.
- The old VER2 Pack B JSON source is hashed as prior context and marked
  `legacy_context_only_not_promoted`.
- The built-in scenario matrix makes rank-deficient, overlap-degenerate,
  ill-conditioned, missing-FPR, and high-FPR states blocked/no-claim rows.
- Added `--check` so the generated report can be verified for drift without
  rewriting the output file.

Rejected alternatives: reusing legacy VER2 Pack B unchanged, recomputing HTT
inference inside the COMMON report, feeding MIO diagnostic surfaces into HTT
evidence plumbing, storing a combined MIO/HTT score, or promoting blocked rank
or FPR states.
