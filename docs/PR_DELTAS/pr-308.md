# PR-308 — ACT DR6 validated-band operator and 400-simulation closure

## Frozen specification

Capability: `ACT_DR6_VALIDATED_BAND_OPERATOR_AND_400_SIM_CLOSURE`.

PR-308 adds one exact ACT primary-lane profile to the existing attended
single-lane executor and one ACT worker.  It reuses the PR-177 observable
feature primitive, but it does not treat the historical derived feature JSON
or numerical result as data authority.  The worker accepts only an exact
PR-289 `ACT` admission and the seven registered components `product`,
`response`, `mean_field`, `noise`, `mask`, `simulation`, and `covariance`.

The analysis support is the strict integer band `40 < L < 763`, or
`41 <= L <= 762`, in the Equatorial frame.  The released baseline
reconstructed-kappa observation and every one of the exactly 400 ordered
release simulations use the same mask, band synthesis, and five-component
real-`Y_2` feature operator.  The data feature subtracts the all-simulation
mean; every null feature subtracts the mean of the other 400 exchangeable
units, including the observation.  The
result uses the full off-diagonal feature covariance, a covariance-whitened
response-rank check with minimum singular-value ratio `1e-8`, and end-to-end
or pre-QE injection coverage.  Coverage passes only when the frozen nominal
0.95 lies inside the two-sided 95% Wilson interval.  A partial
simulation inventory cannot reach covariance, rank, a rank fraction, or a
scientific disposition.  The successor estimand
`ACT_DR6_INBAND_Y2_MODULATION_V1` is registered at runtime against the exact
PR-134 `ACT_DR6_KAPPA` predecessor, with a new fingerprint and multiplicity 2.

The official release notes identify the baseline reconstruction, Equatorial
coordinates, and 400 reconstructed simulations.  PR-308 freezes a narrower
analysis-specific support than the release filter range.  It neither
reproduces the raw quadratic estimator nor describes a post-reconstruction
injection as pre-QE.  No local/global response or native morphology atlas is
provided, so no global, source-attribution, geometry, or family-identification
claim is allowed.

## Implementation result

- `run_act_dr6.py` verifies the exact ordered 400-simulation nested inventory,
  byte identities, release variant, support, feature order, cross-fit
  mean-field contract, full covariance contract, exact non-collapsed injection
  stage, and successor estimand gate before reading a released reconstruction.
- The observed-open marker is written only after the attended executor has
  atomically written `start.json`.  Planning, acceptance hashing, and all
  profiles in this PR are observation-free.
- The dispatcher still permits one primary lane at a time, forbids caller-
  selected entrypoints, and now binds `ACT` to the exact worker, arguments,
  plan ID, output, timeout, data root, NumPy/healpy runtime, and candidate
  commit/tree.  `--all` and `CROSS_PROBE` remain invalid.
- Rank loss produces `RANK_DEFICIENT_ABSTAIN`; failed coverage produces
  `INJECTION_COVERAGE_FAILED_ABSTAIN`.  Neither route forces a point estimate,
  p-value, source label, or scientific result.
