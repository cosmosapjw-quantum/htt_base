## Outcome

depth path.  It emits a conservative Doob upper bound only when an exact
finite target law, preregistered atom selection, decreasing filtration,
common centered target, common preprocessing/estimator identities, and the
conditional-expectation tower all replay.  An unproved premise emits no bound
and routes to a content-addressed matched-mock plan with status
`MATCHED_MOCKS_REQUIRED`.
