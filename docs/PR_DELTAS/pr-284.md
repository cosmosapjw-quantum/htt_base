# PR-284 — Premise-bound depth-path calibration

## Outcome

PR-284 adds a claim-tiered synthetic diagnostic for one finite registered
depth path.  It emits a conservative Doob upper bound only when an exact
finite target law, preregistered atom selection, decreasing filtration,
common centered target, common preprocessing/estimator identities, and the
conditional-expectation tower all replay.  An unproved premise emits no bound
and routes to a content-addressed matched-mock plan with status
`MATCHED_MOCKS_REQUIRED`.

This is not observed-data calibration, mock execution, optional stopping,
source attribution, a native transfer result, geometry detection, or family
identification.  The claim ceiling remains C2 `diagnostic_only`, transfer
source `none`, observed/public use false, and the family gate remains
`BLOCKED_PRE_NATIVE_ATLAS`.

## Implementation

- `common.depth_path_calibration` defines factory-only, content-addressed
  contracts for the finite target law, selected atom, exact threshold,
  matched-mock plan, reverse-martingale report, and Doob calibration.
- `htt.infer.depth_path_calibration` owns premise evaluation and calibration.
  It reverses the fine-to-coarse path partitions exactly once before calling
  the existing coarse-to-fine PR-271 finite-tower verifier.
- The historically frozen `common.depth_path.py` stays byte-identical; PR-284
  composes its `DepthPath` value from the new module so PR-271 exact replay is
  preserved.
- Centering and the target second moment use exact `Fraction` arithmetic.
  The maximal event is evaluated inclusively as
  `max_abs_path_value_squared >= lambda_squared * E_target_squared`; no
  floating square root or tolerance enters the decision.
- Support nesting remains necessary but insufficient.  It never supplies a
  proof status.
- The fallback plan binds path, threshold, preprocessing, estimator, null law,
  generator, ensemble/seed policy, matching variables, acceptance rule,
  multiplicity rule, and preregistration identity.  Its null status is
  `required_not_executed`.
- The generated receipt replays fourteen mutation kills and recomputes the
  finite-law maximal-event probability and conservative bound from the exact
  registered values.
- The runner rejects symlink, nonregular, or multi-link receipt destinations
  before computation, writes by atomic replacement, and provides a clean Git
  archive replay from a distinct root with scrubbed Python/pytest environment
  keys and before/after source manifests. A hardlink discriminator failed on
