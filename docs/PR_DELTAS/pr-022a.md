## Scope (PR-022a)

PSTF state vector 위에서 **photon + neutrino m=0 free-streaming RHS** 를 구현. Thomson collision 은 PR-022b, metric coupling 은 PR-023 으로 이관.

### 포함된 것
- `src/solver/pstf_primary/rhs_free.rs` (~380 줄)
  - `RhsInputs { k, tau, metric_monopole_source }` — 최소 의존성
  - `RhsInputs::free_streaming(k, tau)` — S_metric=0 편의 생성자
  - `pstf_free_streaming_rhs()` — photon + ν m=0 RHS
  - 내부 helper `free_streaming_m0_block` — photon/ν 동일 구조 공유
- `src/solver/pstf_primary/mod.rs` — `pub(crate) mod rhs_free;` 등록 (1 줄)
- 11 unit tests (design §4.4 에 지정된 11개)

### 포함되지 않은 것
- Thomson collision (−κ̇·I_ℓ, baryon drag, pol feedback): **PR-022b**
- Jacobian (analytical sparse, Rodas5P 호환): **PR-022c**
- Metric coupling (MB-95 hdot/6 대응 gauge-invariant term): **PR-023**
- E-mode, B-mode hierarchies: future PR
- Production 연결: PR-026

## 주요 설계 결정

### 1. Sub-track 분할 (pr-022-design.md §1)

단일 PR-022 (weight 15) 를 3 sub-track 으로 분할:
- **PR-022a** (W=6): free-streaming RHS — 이번 closure
- PR-022b (W=5): electron-frame Thomson collision
- PR-022c (W=4): Jacobian

이유: 4 개 coupled 성분 (free-streaming / collision / metric / Jacobian) 중 하나라도 실패하면 전체 PR 이 멈춤. Sub-track 별로 G2 gate 가 **tighter** — "free-streaming sub-component FLRW" 로 scope 축소.

### 2. Metric coupling placeholder (rhs_free.rs §1 docstring)

MB-95 의 `hdot/6` (synchronous gauge variable) 은 PSTF 에서 gauge-invariant 대응 term 이 필요하며, 이것은 **PR-023 (metric sector)** 에 정의됨. 순환 의존을 피하기 위해:

- `RhsInputs::metric_monopole_source: f64` 를 **placeholder** 로 도입
- Default `0.0` → "MB-95 의 hdot=0 특수화" 와 동치 (pure free-streaming)
- PR-023 이 완료되면 `compute_pstf_metric_monopole_source()` 같은 helper 로 wire up
- `limit_metric_source_zero_pure_freestream` test 가 placeholder 가 **monopole 에만** 영향 주고 dipole/higher ℓ 에는 무영향임을 명시적으로 검증

### 3. Photon-neutrino parallelism 을 내부 helper 로 재사용

FLRW 에서 photon 과 neutrino 의 free-streaming 공식은 완전히 동일. 중복 코드 대신 `free_streaming_m0_block` 내부 helper 함수로 추상화:

```rust
free_streaming_m0_block(state, dy,
    |ell| layout.i_photon_i_m0(ell),     // photon indexing
    layout.ell_max_gamma, k, tau, s_metric);

free_streaming_m0_block(state, dy,
    |ell| layout.i_neutrino_m0(ell),     // neutrino indexing (동일 함수 재호출)
    layout.ell_max_nu, k, tau, s_metric);
```

`channelwise_photon_nu_identical_structure` test 가 이 평행성을 검증.
