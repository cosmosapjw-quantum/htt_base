## Reproduced failure class

PR-254 correctly rejects a rank-deficient ellipsoid, a non-spanning
polytope, and a non-centrally-symmetric runtime polytope at construction.
Without a successor evaluator, however, post-construction mutation of a
frozen anchor could bypass the constructor and a caller could also collapse
the functional value and anchor stress into one untyped scalar.

The PR-262 destructive tests mutate:

- an identity ellipsoid to a rank-deficient quadratic form; and
- a bounded centrally symmetric polytope to a one-sided, non-compact support.

The evaluator reconstructs the existing PR-254 body/family before use. The
mutations return `RANK_DEFICIENT` or `NON_COMPACT_SUPPORT` with no gauge,
margin, or numeric stress. Missing state components similarly return
`MISSING_COMPONENT` without a zero value.

## Implemented change

1. Added factory-only `TensorFunctionalSpec` identities over a closed
   operator registry. Each operator fixes output shape, coordinate labels,
   polynomial degree, O(3) type, sign class, and required state components.
2. Added scalar, polar-vector, axial-vector, and STF-tensor evaluations for
   the canonical joint state, including `tr(sigma^2)`, `tr(sigma^3)`,
   `omega^2`, `beta_RM^2`, `beta_RM dot omega`, and
   `beta_RM sigma beta_RM`.
3. Added factory-only `TensorFunctionalResult` with distinct immutable
   `value`, `domain`, `codomain`, `anchor`, `admissibility`, and `stress`
   reports. A result identity binds the functional specification, source
   joint-state content identity, transfer source, claim ceiling, and all
   typed reports.
4. Reused `AnchorBodySpec`, `AnchorFamily`, `AnchorGaugeInterval`, and
   `AnchorMarginReport` directly. No second anchor registry, body, gauge,
   margin, or support vocabulary was introduced.
5. Reconstructs every supplied PR-254 body/family before evaluation, so
   rank/support/channel mutation fails closed. Continuous conditional
   families retain the existing `OPTIMIZER_REQUIRED` refusal.
6. Added mechanical admissibility: only an available sign-definite
   functional with a matching anchor is occupancy-eligible. Signed,
   pseudoscalar, and equivariant outputs may retain a signed diagnostic score
   or exceedance eligibility but cannot silently acquire occupancy semantics.
7. Added `revalidate_tensor_functional_result`, which replays the exact
   state/spec/anchor path and rejects stale or post-construction result
   mutation.
8. Added a narrow MIO bridge that re-exports the COMMON objects by identity.
   It adds no MIO inference method and preserves explicit `__mio_owned__`
   attribution.
9. Added a portable focused/adjacent/smoke runner, governing specification,
   and candidate-bound publication-review policy.

## Physics and mathematics audit

- `sigma` is an STF rank-2 tensor, `omega` an axial vector, acceleration and
  beta channels polar vectors, `beta_RM dot omega` a pseudoscalar, and the
  registered contractions have their corresponding exact O(3) types.
- Homogeneous degrees are fixed by the operator registry rather than accepted
  from caller metadata.
- Twelve deterministic random O(3) transformations, including improper
  transformations, verify scalar invariance, pseudoscalar sign, and isotropic
  vector-anchor covariance at relative tolerance `1e-12`.
- Scaling `sigma -> 3 sigma` gives
  `tr(sigma^2) -> 9 tr(sigma^2)`; scaling the declared scalar anchor radius by
  the same factor preserves the PR-254 gauge exactly within numerical
  tolerance.
- A gauge is a typed premise-stress diagnostic. It is not a probability,
  evidence term, FLRW converse, geometry test, or source/family classifier.
- This PR implements no theorem-status promotion. VT-T2–T4 and VT-T9/T10
  remain programme obligations for PR-269/270.

## Self-review findings and fixes

- The first exception mapping classified every malformed reconstructed anchor
  as non-compact. It now distinguishes rank loss, one-sided/non-central
  support, and generic anchor unavailability so the typed reason is not
  inflated.
- The first draft had no explicit replay API for a result mutated after
  construction. `revalidate_tensor_functional_result` now recomputes the
  complete result and compares the full payload.
- The O(3) metamorphic test initially checked functional parity but not anchor
  covariance. It now also verifies the unchanged isotropic axial-vector gauge
  under each proper and improper action.
