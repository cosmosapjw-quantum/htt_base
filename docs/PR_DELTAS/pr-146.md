## The CF4 catalogue forward simulator

`htt/src/common/cf4_forward_simulator.py` de-risks and validates the PR-145
covariance with two deliberately independent generators.

**Primary generator (Cholesky-from-Gorski).** A Cholesky factor `L` of the
full `N`×`N` Gorski velocity correlation `C_ab` (imported from PR-145) gives a
correlated radial-velocity draw `v_cv = L z` with `Cov(v_cv) = C_ab` exactly,
so the whole correlated field — including the large-scale modes that dominate
a bulk flow — is present in every draw (no super-sample gap). Its per-galaxy
leg is a draw-mechanics + cross-quadrature consistency check (per-galaxy std
307 vs `sigma_v_1d` 308.09), and its ensemble bulk-flow leg is a
covariance-propagation self-consistency check (the ensemble covariance
reproduces the analytic `A^-1 M A^-1` built from the SAME `C_ab`, diagonal
ratios ~0.94–1.06 within Monte-Carlo tolerance) — a contraction check, not an
independent covariance validation.

**Independent reference (box GRF).** A periodic-box Gaussian random field
built by a separate FFT code path with the physical linear velocity coloring
`i (100 f) k_j / k^2 sqrt(P(k))` and the mode-density normalisation
`|filter|^2 = N^3 P/L^3`. It reproduces the band-limited analytic per-galaxy
dispersion at ratio ~1.02, independently confirming the variance NORMALISATION
(the diagonal scale) is not a shared code artifact. Its off-diagonal
correlation is an order-unity finite-box factor (~1.5 at 32 fields) from the
analytic, so the box is a diagonal-variance reference only, never used for the
covariance or coverage; the off-diagonal covariance structure stays the
fiducial Gorski model, not independently validated. The band captures 0.926 of
the full dispersion (in sigma), with the deficit dominated by above-Nyquist
sub-grid small scales (variance fraction 0.128) and only a percent-level
genuine super-sample piece (0.014).

## Realism stressors + coverage

Four genuine stressors — a lognormal distance-modulus error, a nonlinear
scatter, a magnitude-limited selection with an unmodeled Malmquist bias, and an
unmodeled intra-group dispersion — are layered on and the bulk-flow-plus-
monopole estimator is re-fit on every mock. The idealised Gaussian variant
covers at nominal (68/95 per component) while the noise-only covariance
under-covers; each genuine stressor degrades the radial-monopole coverage (the
lognormal error to ~0.26, the Malmquist selection to ~0.58, the intra-group
dispersion to ~0.46), which is REPORTED not hidden. The per-depth coverage is
measured under the non-Gaussian stressor so the shells genuinely differ (the
Malmquist monopole degradation is depth-dependent), and the genuinely
least-favourable shell is disclosed. An effective-N participation ratio
(~82 independent modes over 800 groups) and the Monte-Carlo covariance
uncertainty are reported so same-box regions are never counted as independent.

## Multi-lane adversarial review (Workflow, 3 refute-lenses × find→verify)

Three refute-prompted lenses (generator/covariance correctness; coverage/
realism/discrimination; overclaim/scope/quarantine), each `effort:high` with a
per-finding adversarial verification pass, run against the real CF4 data. The
review returned **no P0 or P1** (the generator math, box normalisation and
effective-N were reproduced and confirmed correct) and **seven P2, all fixed
pre-commit**:

1. The band deficit was mislabelled "the super-sample gap" — the reviewer
   reproduced that ~90% of the deficit is above-Nyquist sub-grid power and
   only ~1.4% is genuine super-sample; relabelled `band_captured_fraction`
   and split the deficit into its two documented variance components.
2. The off-diagonal ratio (1.816) was noise-dominated at 8 fields; bumped to
   32 fields (converges ~1.5) and reported to one decimal as an approximate
   finite-box factor.
3. The per-galaxy Cholesky leg is near-tautological (the diagonal is forced);
   reworded as a draw-mechanics + cross-quadrature check, with the physical
   normalisation validation assigned to the box leg.
4. The selection and grouping variants were tautological (sample mutated
   before the covariance, so DGP == assessed); made them genuine stressors
   (an unmodeled Malmquist bias and an unmodeled intra-group dispersion) so
   they actually degrade and reveal a bias.
5+7. The P0 remediation receipt overstated "the corrected full covariance is
   validated by an independent construction"; narrowed to the diagonal
   normalisation only (the off-diagonal is the fiducial Gorski model, not
   independently validated), so the receipt PR-157 will read is honest.
6. The per-depth "Bonferroni / least-favourable" framing was oversold under an
   idealised DGP; switched to the non-Gaussian stressor so shells genuinely
   differ, and relabelled the family-wise note honestly.
