2. **Leave-one-simulation cross-fit mean field.** Each sim is debiased by the
   mean of the OTHER sims, so the sims are debiased the SAME way as the data
   (whose mean field is the mean over all sims, none of which is the data). The
   naive self-inclusive all-sim mean field debiases each sim by a mean that
   includes itself — a treatment the data never gets — which biases the pooled
   rank toward false excess. **Honest disclosure**: the naive/cross-fit ratio is
   the exact input-independent `((n-1)/n)² = 0.995` sample-size scaling (not a
   data-dependent bias), and the L=2..10 mean field is numerically negligible
   (~1e-17), so the cross-fit is the PRINCIPLED construction rather than a large
   correction on this data. The cross-fit release-simulation pooled-rank of the
   data band power is **0.364** (vs naive 0.354), consistent with the isotropic
   sim null and matching the historical low-ℓ isotropy value.

3. **Exact finite rank** of the low-multipole band: **117** real harmonic dof
   (=Σ_{ℓ=2..10}(2ℓ+1)), capped by the sample rank n−1.

4. **Injection-law distinction.** A stochastic injection whose band-power
   distribution EQUALS the null's (an incoherent field carrying the null's own
   power) is UNIDENTIFIABLE — a draw from it is a null draw, so its pooled rank
   against the SAME null stays uniform (~0.48); a fixed-template injection is a
   coherent additive offset that shifts the rank (~0.38). Both ranked against the
   same null (identifiability, not a null-set artifact).
