## Why the raw-QE stage was absent

The reconstructed-lensing release bundle contains κ data, 400 κ simulations,
response/normalisation, fiducial N0, N1 derivatives, band powers, and masks. A
realisation-dependent N0 rerun additionally needs the public four CMB splits,
the exact filtering/response/mask configuration, a locked
so-lenspipe/falafel/tempura/pixell environment, the simulation input manifest,
and executed QE/RDN0 outputs. Those public inputs and open software make the
rerun reproducible, but that separate configuration-locked reconstruction has
not been executed locally.

A bare `raw_qe_inputs_on_disk=true` flag or syntactically valid SHA string can
no longer promote readiness. The positive branch requires typed
`path/size_bytes/sha256` records for four distinct splits, filtering, response,
mask, software lock, simulation inputs, QE output, RDN0 output, and an execution
log. The validator reopens and fully hashes every file, constructs a canonical
input-identity hash, parses the log, and cross-checks its command, zero exit
status, input identity, software lock, and output hashes. Placeholder digests,
missing paths, byte drift, or a self-asserted checksum boolean remain deferred.

## Provenance hardening

`scripts/act_raw_qe_card.py` now requires exactly 400 simulations and hashes
every byte of the data alm and every ordered simulation alm. The low-L cache key
also includes L/mode-weight configuration, seed, and producer bytes. A same-
count file replacement, non-head byte change, band change, or producer change
selects a different cache; old caches are retained and never silently reused.

The runner independently checks the embedded input-manifest hash, local cache
hash, producer bytes, 400 saved null scores, finite values, exceedance arithmetic,
support `1/401`, algebraic rank ceiling, injection summary, range boundary, and
inventory/decision consistency before emitting any artifact. Scientific floats retain
full precision. Every output carries the complete owner/scope/tier, input,
sky/mask, covariance/null, caveat, command, runtime, git, and worktree metadata.
