## Plot summary and provenance

The report figure plots the fixed PR-273 synthetic cases only. Panel A shows
dimensionless `max_finite_abs_x` and `max_finite_abs_q`; Panel B shows the
dimensionless `depth_mean_normalized_score` and the preregistered threshold
25. C05 crosses that alert threshold and C03 retains a missing functional
channel. The shaded cases are held out.

Source JSON, generator, PNG, and manifest identities are machine readable in
the plot manifest and replication package. The manifest distinguishes its
canonical content identity from its exact file identity. This plot is a
pipeline-behaviour diagnostic, not an estimator, proof-count graphic,
governance/readiness graphic, observed-data result, or family label.
