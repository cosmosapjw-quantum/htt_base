## Result

Terminal: **DUAL_AXIS_SSOT_EVIDENCE_READY_INDEPENDENCE_OPEN**.

`htt/src/common/dual_axis_claim_state.py` implements two axes that never
collapse into one ordinal: `novelty_tier_external` (K/C/P/S — only the
literature delta) and `readiness_state` (the eight-state lifecycle).
`publication_use` opens only as the conjunctive result of the six gates
(mechanics / identification / calibration / provenance / independence /
claim) plus readiness VALIDATED and a signed independent
(author != adjudicator, not-stale) adjudication receipt.

Gate battery (all conjunctive, sealed in `pr185_result_card.json`):

- **Migration diff 0**: the v10 external-novelty ledger (62 entries)
  migrates losslessly to 62 dual-axis claims; every id, novelty head
  (K/C/P/S, both heads of `K+C`-style tiers recorded in the basis) and
  adjudication basis preserved.
- **No conflation**: all 4 x 8 = 32 (novelty, readiness) combinations are
  legal states, including S + OPEN and P + VALIDATED.
- **Fail-closed publication**: 100/100 `publication_use=true` mutations
  rejected when any gate is not passlike or any independent signed receipt
  is missing.
- **Named kills all caught**: author = adjudicator, fabricated (unsigned)
  receipt, circular promotion parent, stale gate receipt (digest
  mismatch), and the OPEN -> VALIDATED ladder jump are each refused.

Every migrated claim carries `readiness_state = EVIDENCE_READY` with the
**independence gate explicitly OPEN** (adjudication capacity is
spend-limited) and `publication_use = false`. This is the first-class
legal state the engine exists to represent: high external novelty with an
OPEN internal readiness is never downgraded, and an OPEN artifact is never
promoted to public use because its novelty is S.
