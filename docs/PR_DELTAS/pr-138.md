## Conjugate Gaussian model + mandatory lineage

`htt/src/common/sbc_ppc.py`: `theta ~ N(0, tau2)`, `y_i ~ N(theta,
sig2)`, n = 8, exact conjugate posterior. Posterior draws are
content-addressed to the normalized prior, likelihood, data, config,
transfer, and sampler diagnostics. The lineage is MANDATORY and
verified on BOTH paths — the SBC computation lineage binds the model +
config (SBC has no observed data), and the PPC lineage binds the ACTUAL
fitting model — and the verified lineage hash is recorded in both
outputs (`require_ppc_receipt` requires it). The IM/SBC/chi-square
statistics are bit-exact against scipy (review-lane confirmed).

## SBC (Talts et al.) + binned rank uniformity

Rank `r = #{posterior_draw < theta0}` over 20 draws is uniform on
{0..20} under a calibrated model+sampler; the ranks are binned into 7
bins (Talts-style coarser binning; `n_bins` divides `n_draws+1 = 21`,
dof = 6 — the `n_bins` parameter is now load-bearing, not a no-op). The
known-good exact-conjugate model passes the chi-square rank-uniformity
test (p ~ 0.09), and both known-bad models (deflated var_scale = 1/2,
inflated var_scale = 2) FAIL (p ~ 1e-127 / 1e-58) and are reported
inadequate; the SBC-pass claim is refuted for each.

## Replicated-data PPC + demonstrated known-bad

Three frozen content-addressed discrepancies (sample variance, max,
range). The known-good model is `adequate_conditional` (p in
[0.25, 0.36], none extreme). A known-BAD mis-specified under-dispersed
fit (`fit_sig2 = 1/9`) is DEMONSTRATED to produce extreme p-values (all
~ 0) and the `inadequate_ppc_extreme` verdict — the known-bad PPC is now
a shipped artifact, not spec prose. A caller-supplied prediction/p-value
is never a PPC receipt, a discrepancy cannot be swapped after a failure
(frozen hash), a PPC on an invalid posterior is refused, and the plug-in
`residual_check` stays a separate type (never labeled a PPC).
