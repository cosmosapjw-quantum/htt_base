# PR-309 — JWST-SN row provenance and shared-covariance closure

## Frozen specification

Capability: `JWST_SN_ROW_PROVENANCE_AND_SHARED_COVARIANCE_CLOSURE`.

PR-309 extends the existing JWST distance module with one current-stack typed
row operator and registers one `JWST_SN` profile in the attended single-lane
executor.  It consumes only an exact PR-289 admission containing, in registry
order, `source_rows`, `host_rows`, `individual_errors`, `covariance`, and
`competitor_model`.  The historical PR-153/154 numerical builders and
generated result values are neither input nor oracle.

Each ordered row binds source/release/locator provenance, a non-positional host
linkage basis and its uncertainty, individual magnitude uncertainty,
calibration group, CMB-frame redshift, source-reported distance in Mpc, and an
IAU-1958 Galactic direction in degrees.  The full covariance is

```text
diag(individual variance + host-linkage variance)
+ calibration-design * shared-zero-point covariance * calibration-design^T
+ peculiar-velocity covariance.
```

Both shared terms must have genuine off-diagonal support.  The matrix must be
symmetric positive definite and remain below the predeclared condition-number
ceiling; it is never silently diagonalized, jittered, or repaired.

The covariance-whitened response order is fixed to monopole, three Galactic
direction components, centered redshift, and centered depth.  CF4 and 2MRS are
two distinct direction/depth competitors.  They receive separate augmented
response-rank checks and separate diagnostic blocks and are never averaged,
stacked, or treated as independent confirmations of one source.  Base-rank
loss yields `RANK_DEFICIENT_ABSTAIN`; competitor collinearity yields
`NON_IDENTIFIED_ABSTAIN` with null coefficient and standard error.  No route
emits a p-value or forced source label.

## Source and data boundary

- NASA HEASARC 2MRS catalog:
  <https://heasarc.gsfc.nasa.gov/w3browse/all/twomassrsc.html>
- source/release page checked: 2026-08-23

The official catalog description identifies the 2MRS release as a 2MASS-based
nearby-galaxy redshift catalog and labels its tabulated radial velocity as
solar-system-barycenter referenced.  Therefore raw HEASARC rows are not a
drop-in CMB-frame competitor.  A separately admitted forward-model component
must bind the frame transformation, row order, source release, and exact
prediction identity before the worker can consume it.

The clean integration tree has no complete PR-289 JWST-SN admission and no
separately admitted 2MRS competitor model.  The historical
`docs/generated/jwst_cf4_anchors.json` is positional catalogue-linkage evidence
only and is explicitly not execution authority.  No data was downloaded, no
new observed payload was opened, and `H-JWST` remains `NOT_AUTHORIZED`.

  provenance or positional identity promotion, constructs the two shared
  covariance contributions exactly once, and preserves the typed row report.

  separate generalized least-squares diagnostics.  It never pools the
