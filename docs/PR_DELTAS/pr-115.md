## Chosen implementation

- Added `scripts/check_publication_claim_freeze.py`.
  - Builds an importable publication-freeze payload from current generated
    status, claim ledger, result packs, transfer report, manuscript inventory,
    audit prompts, and PR-114 audit package manifest.
  - Renders `docs/generated/publication_claim_freeze.md` and
    `docs/generated/hostile_review_response_matrix.md`.
  - Provides `--dry-run` and `--check`; dry-run writes nothing, while check
    fails on stale generated outputs.
  - Requires every frozen claim to carry owner, artifacts, manifest references,
    tests, and caveats.
  - Fails closed on forbidden claim language, missing required inputs, missing
    claim ledger, missing transfer provenance, missing PR-114 audit manifest,
    and C5/C6 family-ID wording before native morphology atlas support.
- Added `tests/contracts/test_publication_claim_freeze.py`.
  - Tests manifest metadata, claim mapping, dry-run behavior, write/check
    behavior, C5/C6 family-ID failure, C5 transfer-conditional morphology
    compatibility wording, and missing-input fail-closed behavior.
- Generated `docs/generated/publication_claim_freeze.md`.
  - Records `blocked_internal_only`, eight frozen public-claim surfaces, all
    required assertions true, and the preserved manuscript blockers: 22 missing
    refs and 72 quarantined refs.
- Generated `docs/generated/hostile_review_response_matrix.md`.
  - Records hostile reviewer rows for relativistic cosmology, statistical
    inference, numerical methods, software reproducibility, claim hygiene, and
    family-ID skepticism.
- Updated `docs/codex_handoff/pr_status.yaml` and
  `machine_readable/pr_status.yaml`; regenerated status snapshot, claim ledger,
  status matrix, and progress scoreboard.
- Refreshed the PR-114 external audit package and manifest after final status
  changed so `scripts/build_external_audit_package.py --check` remains green.
