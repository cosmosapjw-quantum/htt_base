## Chosen plan

Implemented a small COMMON harness generator:

- `load_pr_card()` reads one card from the active backlog.
- `render_pr_delta()` renders `docs/PR_DELTAS/TEMPLATE.md` with strict
  `string.Template` substitution.
- `target_path()` normalizes output to lowercase `pr-xxx.md`.
- CLI supports `--backlog`, `--template`, `--dir`, `--web-check-status`,
  `--dry-run`, and `--force`.
- Existing output files are refused unless `--force` is supplied.
- Unknown PR IDs and missing/malformed inputs exit nonzero.
- Owner aliases are normalized for generated text:
  `TSC -> TSC_LEGACY`, `BASS_PY -> BASS`, `MANUSCRIPT -> COMMON`.

Rejected alternatives:

- Keeping an inline template in the script duplicates review conventions and
  makes template review harder.
- Inferring changed files from `git diff` is wrong for a scaffold generator;
  the PR card is the intended initial source, and agents record actual changes
  during closeout.
- Creating a separate JSON review artifact was not needed for PR-022; the
  standardized Markdown PR delta is the review artifact.

## Review findings and fixes

- Finding: the first generator design used only a broad downclaim, not
  structured safe defaults.
  - Fix: template now forces owner, implementation scope, claim tier, transfer
    source, sky support, null/mock, covariance, PPC, and LOOCV status fields.
- Finding: generator could emit noncanonical public owner labels from backlog
  cards.
  - Fix: generator normalizes `TSC`, `BASS_PY`, and `MANUSCRIPT` at render time
    and tests the legacy `TSC` case.
- Finding: accidental overwrite would risk losing PR review evidence.
  - Fix: CLI refuses existing files unless `--force` is supplied and tests both
    paths.
- Finding: host Python cannot run pytest on this machine.
  - Fix: recorded exact failure; venv-backed test evidence is the acceptance
    evidence for pytest.
