## Reproduced capability gap

PR-260 preserved two owner-requested cardinality aliases but intentionally did
not yet provide an additive v3 signature loader, typed premise missingness, or
an executable oracle boundary:

- requested “Pillar T 65” denotes the 65-row legacy signature inventory,
  whose actual source partition is `31 T + 34 S`;
- requested “Pillar S 58” denotes the 58-row proposal inventory, whose actual
  source partition is `30 I + 24 II + 4 BRIDGE`.

Treating those aliases as literal scientific pillar membership, or treating
the 123 raw rows as proved theorems, would be false. The source also contains
explicitly untyped assumptions, domains, frames, and branches that must not be
filled from prose by inference.

The supplied oracle has a second reproducible boundary: at the registered seed
`20260730`, its full mode passes all 12 propositions, while its reduced
`fast=True` mode fails `TF-11-MASK-PATH-MARTINGALE` because the reduced
20,000-draw direct martingale separation check is false. The supplied file was
not edited to conceal that result.

## Implemented change

1. Added the additive generated registry
   `docs/research_program/vector_tensor/THEOREM_SIGNATURES_V3.yaml` and a
   fail-closed loader in `common.theorem_signatures_v3`.
2. Registered exactly 65 legacy-source rows and 58 proposal-source rows as
   disjoint `REGISTERED_OBLIGATION` records. Every row binds statement/source
   identities, the true source partition, proof class `U/TC/ST`, registry and
   scientific owners, dependencies, required evidence, evidence path, source
   status, and a diagnostic-only claim ceiling.
3. Preserved typed source missingness. The 12 checked v2 signatures retain
   their declared hypotheses, domain, frame, and perturbative order; branch
   convention remains `SOURCE_NOT_TYPED`. The other 53 v2 rows and every
   proposal premise component stay explicitly untyped where the source does
   not declare them.
4. Kept source status separate from proof adjudication. Every v3 row is
   `NOT_ADJUDICATED`, `counts_toward_theorem_count` is always false, and the
   loader refuses raw-cardinality theorem claims.
5. Copied the supplied tensor-foundation oracle byte-for-byte into the COMMON
   package. Proposal and production SHA-256 are both
   `ddd819323642f5b86e26ee8cad2c9e0bca9175ab842aa66ac4fc81d0c20eb444`.
6. Bound each of the 12 `TF-*` proposition IDs to exactly one proposal row.
   Existing source states are retained: `TF-03` and `TF-04` link to
   `PROVEN_CAS4` primary rows, while `TF-12` remains
   `ACTIVE_CONDITIONAL`. Oracle output has `proof_effect: none`.
7. Registered two full-mode stable vectors and six refusal mutations covering
   oracle identity, seed, missing proposition, failed proposition, unchanged

8. Preserved `TF-02` generic/degree completeness as `UNPROVEN`, the `TF-06`
   principal-stratum and non-identifiability boundary, and the complete

   runner. The PR-260 contract tests now invoke their own interpreter through
