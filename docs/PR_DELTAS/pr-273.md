## Capability

PR-273 connects the registered vector/tensor path

`JointAnisotropyState -> tensor functionals -> orbit catalogue v3 ->
x/Q/F/G_F/Pi successors -> AnisotropyTypeReport`

on five deterministic synthetic cases. The development partition contains
the scalar-limit, tensor-only, and missing-channel cases. The held-out
partition contains the local/global rank-collapse and mask/depth-confounded
cases. The analyst challenge contains opaque IDs only; scenario labels and
expected outcomes remain in the separately committed truth vault until the
post-submission adjudication stage.

The generated diagnostic pack records the config identity, seed, transfer
source, challenge/submission/adjudication content identities, case
partitions, mutation results, caveats, and claim ceiling. It contains no
observed data and supports no native-solver, geometry, or Bianchi-family
claim.
