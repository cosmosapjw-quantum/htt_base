## Reproduced capability gap

The repository had separate typed reports for joint state, orbit stratum,
anchored response geometry, local/global response separation, open-set
response classes, conditional exceedance, and depth coherence. It had no
single immutable consumer that replayed those upstream objects, preserved
their missingness and `UNPROVEN` boundaries, and applied one deterministic
abstention order without manufacturing a nearest geometry or family label.

## Implemented change

1. Added COMMON `GeometryInformationStatus`,
   `LocalGlobalCompatibility`, `AnisotropyCompatibilityStatus`,
   `LocalGlobalCompatibilityInput`, `OpenSetReplayInputs`, and
   `AnisotropyTypeReport`.
2. Replays the exact joint-state payload and PR-263 orbit report. The three
   orbit completeness claims remain `UNPROVEN`.
3. Recomputes PR-255 anchored response rank and principal angles from its
   stored matrices and exact normalizer. A PR-255 `MISSING_INPUT` report whose
   source values were discarded is refused rather than treated as replayed.
4. Adds an HTT-owned adapter that replays the exact PR-256 local/global
   response report and exports only a sealed COMMON snapshot.
5. Rebuilds PR-258 response classes, equivalence graph, and classification
   from the full observation/covariance/nuisance/source-gate inputs. A
   source-specific PR-258 gate must match the exact PR-256 report identity and
   status.
6. Binds sealed PR-265 conditional-exceedance and PR-266 depth/path reports.
   Missing probability laws or unavailable depth covariance yield a no-number
   partial report.
7. Applies the registered precedence:
   `PARTIAL_DIAGNOSTIC` for missing channels, `INDETERMINATE` for weak rank,
   overlap, or equivalence, `UNKNOWN` for an outside-library result, and
   `RESPONSE_COMPATIBILITY_CANDIDATE` only when every declared C2 condition
   passes.
8. The payload contains only safe response-class identifiers. It has no
   family, geometry, or nearest-label field and cannot promote the C2 ceiling.
9. After the first frozen review reproduced a namespace-smuggling defect,
   PR-267 now admits only `response-class-neutral`, `response-class-local`,
   and `response-class-global`, with each identifier fixed to its declared
   PR-258 source semantics. Family-coded or otherwise aliased identifiers are
   refused before they can enter an aggregate report.
