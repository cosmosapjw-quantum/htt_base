## Chosen plan

- Added `htt.statistics.mes_template_bound` with
  `build_mes_template_bound()` and `MesTemplateBoundResult`.
- Reused `obsstat.template_fit.CovarianceAssumption` and
  `fit_template_diagnostic()` for deterministic template-fit metadata rather
  than reimplementing weighting semantics.
- Reused `obsstat.null_ensembles.validate_null_feature_payload()` for typed
  null provenance and look-elsewhere status.
- Emitted a COMMON `ArtifactManifest` plus `FullCovMESReport` with explicit
  passed/failed gates, no-claim reasons, sky/mask/covariance/null metadata,
  and branch-separation payload fields.
- Preserved diagonal MES as the fallback baseline when the synthetic branch is
  blocked, with information gain fixed at 1 in those no-claim states.
- Rejected fake native solver inputs, covariance/BiPoSH anomaly handling,
  HTT likelihood/evidence plumbing, MIO certificate plumbing, and any
  geometry/family wording.

  - Fix: missing covariance, missing/null-local payload, and rank-deficient
    response keep `covariance_bound=None`, preserve the diagonal fallback, and
    record failed gates/no-claim reasons.
- Finding: no-claim states still exposed a numeric `template_bound` and could
  mix in a lower `dynamical_bound`.

    blocked synthetic states preserve the diagonal fallback and information
    gain 1.
- Finding: typed null payload validation was provenance-only and could accept a
  null payload from a different config/input/sky/mask/covariance/scan context.
  - Fix: the synthetic branch now requires matched config hash, input hashes,
    sky support status, mask status, covariance status, scan volume/trial
    count, and observed-feature reference, with focused downgrade tests.
- Finding: generated status consumers still listed PR-090 as pending after the
  status YAML was updated.
  - Fix: regenerated `docs/generated/status_snapshot.json`,
    `docs/generated/claim_ledger.json`, `docs/generated/status_matrix.md`, and
    `docs/generated/progress_checkpoints/progress_scoreboard.md`.
- Accepted residual: the module is exported as `htt.statistics` because the PR
  card targets the HTT package statistics surface, but the emitted manifest
  owner and implementation scope remain COMMON and the module imports no HTT
  inference, MIO certificate, BASS solver, or transfer-runtime code.
- Accepted residual: rank-deficient no-claim reports use claim tier `blocked`
  with failed gates and `covariance_bound=None`; the contract vocabulary has no
  rank-specific production status, matching the existing BASS MES no-claim
  precedent.
