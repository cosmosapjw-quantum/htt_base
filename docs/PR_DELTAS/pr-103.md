## Chosen plan

- Added a PR-card acceptance test at
  `tests/mio/test_mio_evidence_anatomy_no_merge.py`.
- Added immutable HTT evidence-trace dataclasses to
  `mio.decomposition.evidence_anatomy`:
  - `HttEvidenceTraceTerm`
  - `HttEvidenceTrace`
  - `EvidenceAnatomyNarrativeReport`
- Added:
  - `build_htt_evidence_trace_from_payload()`
  - `build_evidence_anatomy_narrative_report()`
- The narrative builder:
  - requires HTT owner/scope;
  - copies finite channel deltas into immutable terms;
  - requires PR-065 prior/PPC/LOOCV and matched-null statuses;
  - blocks failed adequacy statuses;
  - rejects requested single-score output;
  - records MIO read-only narrative metadata and manifest fields.
- Tightened predictive residual slices to reject non-finite or negative
  residual amplitudes.
- Added `predictive_residual_atlas_payload()` to expose residual context as
  MIO diagnostic-only metadata, not HTT evidence.
- Changed the legacy evidence-anatomy default model label from
  `FLRW_vs_BianchiI` to `htt_evidence_trace` to avoid pre-native family-label
  overreading.
- Exported the new helpers through MIO diagnostics/decomposition roots and
  pinned those exports in tests.

Rejected alternatives: creating a single MIO+HTT scalar, treating residual
amplitudes as likelihood/evidence, consuming MIO certificates as HTT evidence,
or using evidence anatomy to claim native solver, morphology, geometry, or
family status.

## Claim-tier impact

PR-103 adds MIO-owned diagnostic narrative and residual-context metadata. It
does not create HTT evidence, does not consume MIO certificates as evidence,
does not modify HTT evidence traces, and does not collapse MIO residuals plus
HTT evidence into one score. Passing adequacy gates yield at most
diagnostic-only MIO narrative status. Failed PR-065 adequacy statuses downgrade
the narrative artifact to blocked. Raw predictive residual amplitudes remain
descriptive and uncalibrated unless caller-supplied covariance/null/mask/rank
metadata says otherwise.

- owner: MIO
- implementation_scope: mio
- claim_tier: diagnostic_only when HTT trace adequacy gates pass; blocked
  otherwise
- production_status: diagnostic_only when gates pass; blocked otherwise
- transfer_source: none
- sky_support_status: not_directional
- null_mock_status: inherited from PR-065 trace readiness
- mio_role: diagnostic_narrative_only or residual_context_only
- htt_evidence_modification_status: read_only_copy
- single_score_status: forbidden_no_owner_merge
