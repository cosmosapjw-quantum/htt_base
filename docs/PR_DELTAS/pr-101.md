# PR-101 - Redshift-binned coherence and G_F certificate bridge

## Goal

- Owner: MIO
- Depends: PR-055, PR-100
- Level: L3
- Scope: pre-solver
- Risk: high

Add a MIO-owned redshift-binned coherence certificate bridge that requires
depth-bin covariance and selection metadata before production-candidate
readiness. The bridge records G_F provenance by reference only; it does not
derive G_F from redshift drift.

## Chosen plan

- Added `RedshiftDepthBinMetadata` with redshift interval, selection rule/hash,
  bin assignment hash, sky/mask status, covariance status/metadata, null/mock
  status/metadata, sample count, G_F payload reference, caveats, JSON
  validation, controlled status vocabularies, and reserved-claim scanning.
- Added redshift certificate readiness augmentation so generic
  `has_covariance` or `has_null_mocks` flags are effective only when
  matched-calibrated depth-bin covariance/null metadata is present.
- Required complete per-bin sky/mask support and checked G_F bridge metadata
  for the all-gates operational readiness path; diagnostic-unmatched metadata
  remains an explicit descriptive fallback.
- Recorded machine-readable status in manifest
  `statistics_definitions["certificate_status_metadata"]`, including depth-bin
  covariance/selection/null status, G_F bridge status, hashes, probe membership,
  excluded probes, gate lists, production status, claim tier, and public-grade
  label.
- Extended `emit_redshift_coherence_artefact()` to preserve covariance/null/sky
  readiness and depth-bin metadata through JSON output.
- Added generated claim-ledger support notes for PR-101 keyed by structured
  PR-card fields, not title text.

Rejected alternatives: copying legacy tests only, treating drift p-values as
calibrated statistical results, computing G_F from redshift drift, using HTT
evidence/posterior surfaces, allowing TSC/Teff ownership, or promoting scalar
coherence/G_F metadata into morphology, geometry, or family claims.

## Review findings and fixes

- Finding: the PR-card command failed because
  `tests/mio/test_redshift_binned_coherence.py` was absent.
  - Fix: added the root-level PR-101 certificate-bridge test suite.
- Finding: a global covariance flag could have bypassed the PR-101 kill switch.
  - Fix: readiness uses effective covariance/null readiness only when complete
    depth-bin metadata exists.
- Finding: complete covariance/null/sky/selection metadata without a G_F bridge
  could read as complete.
  - Fix: missing G_F bridge references force diagnostic-only descriptive
    fallback and a failed `g_f_bridge_metadata_attached` gate.
- Finding: diagnostic-unmatched covariance/null metadata could reach
  `production_candidate` because presence was treated as readiness.
  - Fix: effective covariance/null readiness now requires matched-calibrated
    per-bin statuses and calibration metadata, with a regression test for the
    diagnostic-unmatched path.
- Finding: certificate-level complete sky support could hide incomplete per-bin
  sky/mask support.
  - Fix: per-bin sky/mask status uses controlled vocabularies, feeds effective
    sky support, and has a regression test for partial per-bin support.
- Finding: one delta phrase read too strong for a metadata-only G_F bridge.
  - Fix: downclaimed to checked G_F bridge metadata and reran claim-status
    scanning.
- Finding: generated claim-ledger notes would otherwise collapse PR-101 to
  generic `not_statistical`/`not_directional` placeholders.
  - Fix: added a structured PR-101 status-snapshot predicate and title-only
    lookalike regression.

## Claim-tier impact

This PR adds MIO diagnostic-only redshift-binned coherence certificate metadata.
It is not native solver validation, transfer validation, HTT posterior evidence,
HTT likelihood/evidence, a truth certificate, morphology compatibility, or
geometry/family-identification evidence.

- owner: MIO
- implementation_scope: mio
- pr_scope: pre-solver
- certificate_reduction_status: diagnostic-only
- claim_tier: blocked when covariance/null prerequisites fail, exploratory for
  descriptive fallback, conditional only for the existing all-gates operational
  readiness manifest path
- transfer_source: none
- covariance_status: matched-calibrated per-redshift-bin metadata required for
  readiness
- null_mock_status: matched-calibrated per-redshift-bin metadata required for
  readiness
- sky_support_status: caller-provided readiness plus complete per-bin sky/mask
  metadata required for readiness
- selection_status: per-redshift-bin rule/hash and assignment hash required
- G_F bridge: diagnostic metadata reference only; no G_F is computed from drift
- ppc_status: not_applicable
- loocv_status: not_applicable
