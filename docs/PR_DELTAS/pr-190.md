## Question tested

PR-190 asks whether the lower endpoint, upper endpoint, and intervening values
of the registered PR-215 comparator are realized by one dynamically valid
Einstein–matter solution class.  The tested class is expanding diagonal
comoving Bianchi-I with pressureless dust, signature `(-,+,+,+)`,
`8*pi*G=1`, `N=ln(a/a0)`, and
`Sigma2=sigma_ab sigma^ab/(6 H^2)`.

This is a physically valid and deliberately narrow attempt.  The
`a^-6` shear contribution of Bianchi-I cosmology is also consistent with the
background treatment in [arXiv:1905.06949](https://arxiv.org/abs/1905.06949).
That literature identity is context, not independent validation of this
repository result.

## Result

The class realizes every **scalar** value in
`x_C in [2/25, 1/10]`.  One hundred independent DOP853 developments completed
five e-folds with:

- maximum normalized Gauss residual: `2.666755705149626e-13`;
- maximum exact-solution errors: `6.46e-16` in `Sigma2` and `5.70e-15`
  relative in `H`;
- positive `H` and nonnegative dust density throughout.

That success is only a negative control.  Diagonal comoving Bianchi-I has
`W2=Omega_tilt=DeltaOmega_k=0`, while the registered endpoint vectors do not:

- lower endpoint: scalar gap `0`, exact component `L-infinity` gap `1/50`;
- upper endpoint: scalar gap `0`, exact component `L-infinity` gap `3/100`.

Those gaps are bounded below by the nonzero registered tilt coordinates.
Changing the shear value cannot remove them.  The roadmap explicitly forbids
replacing the withdrawn/nonzero `W2`, tilt, or curvature endpoint components
with a shear-only scalar match, so the conjunctive PR-190 gate fails.
