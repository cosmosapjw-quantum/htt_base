## Implemented changes

1. Added a separate factory-only `VelocityFrameDecomposition`. It leaves
   `DepartureState.beta_a` unchanged and represents
   \[
   \beta_{RO}=\beta_{RM}+\beta_{MO}+O(\beta^2)
   \]
   in one declared basis, epoch/window, dimensionless \(c=1\) convention,
   polar-vector parity, and the fixed `first_order_small_velocity` order. The
   closure threshold includes the registered conservative
   \((\|\beta_{RM}\|+\|\beta_{MO}\|)^2\) truncation envelope, so a residual
   inside the advertised \(O(\beta^2)\) remainder is not mislabeled as an
   exact-closure failure. Every caller must also provide an explicit
   `first_order_beta_ceiling` (at most `0.1`); PR-256 registers `0.01`, and
   inputs outside that domain fail closed rather than exploiting the
   quadratic envelope at relativistic speed.
2. The velocity report distinguishes `CLOSURE_VERIFIED`,
   `CLOSURE_MISMATCH`, `SUM_ONLY`, and `MISSING_COMPONENT`. A missing physical
   component is never derived from the other two. Closure is a first-order
   kinematic consistency check, not source attribution or global-tilt
   detection.
3. Added factory-only `SourceResponseProviderSpec` records for the local
   `beta_MO` and global-candidate `beta_RM` channels. Every provider binds an
   exact response content identity, observable and parameter labels, basis,
   epoch/window, perturbative order, response role, and transfer provenance.
4. Available providers require an explicit finite response. Missing providers
   require an explicit reason and forbid any response, including a zero
   placeholder. Only analytic/synthetic `transfer_source=none` and a complete
   matching `empirical_proxy` specification are accepted. Local and global
   blocks must share the exact transfer identity under either source type, and
   that identity is bound into the joint response receipt. Transfer provenance
   and distinct provider identities are checked before the missing-provider
   early return, so absence cannot hide a mixed or aliased contract.
5. Added `SourceResponseGeometryReport`, evaluated on the PR-255
   covariance-supported quotient after one common nuisance projection. The
   report returns local, global, and joint rank; singular spectra; principal
   angles; the registered minimum-angle threshold; covariance-null response;
   exact provider identities; and allowed/forbidden uses.
6. The normalizer must declare `RESPONSE_CONDITIONING`, match concatenated
   local/global parameter labels, remain invertible within both blocks, and
   contain exactly zero cross-block entries. Coordinate scaling cannot create
   response rank or mix the two physical channels.
7. Geometry outcomes are exactly `NON_IDENTIFIED`, `SUM_ONLY`,
   `SEPARABLE_CANDIDATE`, and `MISSING_RESPONSE_PROVIDER`. Rank loss,
   including rank loss inside either multi-parameter source block,
   covariance-null response, direct-sum failure, or a principal angle at or
   below the preregistered threshold abstains. `SEPARABLE_CANDIDATE` is not a
   detection or source label.
8. Added a deterministic synthetic benchmark comparing dipole amplitude,
   diagonal \(C_\ell\), morphology-only, anchor-stress-only, anchored response
   geometry, and full held-out source competition on the same response bank.
9. The benchmark uses seed `20260728`, a 60/20/20 partition, 40,000 held-out
   draws per cell, fixed prediction and scoring identities, and four
   preregistered cells: pure local, pure global, mixed source, and confusable
   sum-only. Train and validation partitions are sealed but unused because the
   rule and threshold are preregistered; only the held-out partition is
   scored.
10. The PR-222 window matrix enters only through a content-bound synthetic
    depth-contrast design. An unavailable real aberration, remote-dipole, or
    depth provider would return `MISSING_RESPONSE_PROVIDER`, never the
    synthetic response and never a zero column.
11. Added a second executable oracle using a Cholesky whitener and direct
    nuisance projector, independent of the public eigen-whitener
    implementation. It compares rank, singular spectra, principal angles,
    status, and exact velocity closure across 300 randomized
    positive-definite cases.
12. Added source-layout package exports, packaging import probes, a portable
    integration runner, a one-change-set/one-PR publication policy, focused
    unit/property tests, destructive ablations, and artifact replay checks.

## Mathematical and statistical boundary

The velocity composition is the first-order small-velocity relation in a
single registered basis and window. Higher-order velocity composition,
frame-transfer uncertainty, and observational estimation are outside this
change-set. Passing closure does not determine whether either physical source
exists, and failing closure does not select one.

The response geometry is a finite-dimensional Gaussian tangent-space
diagnostic. Local and global response blocks must share one covariance,
nuisance tangent space, basis, epoch/window, perturbative order, and transfer
provenance. The normalizer is an invertible block-preserving coordinate map.
Its singular values can change, but its rank cannot.

`SEPARABLE_CANDIDATE` means only that the registered supported tangent spaces
form a direct sum and clear the preregistered principal-angle threshold. It is
not an observed global tilt, posterior result, Bayes factor, e-value, FLRW
departure, geometry detection, native-solver validation, or Bianchi family
identification.
