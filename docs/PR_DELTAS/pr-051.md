## Chosen plan

- Add `mio.formalism.budget_spec` with explicit `BudgetPolicy`,
  `BudgetUse`, and pre-solver-safe `NativeMorphologyAtlasStatus` enums.
- Implement frozen `BudgetSpec` with strictly positive finite denominator
  values, non-empty comparator/frame/units/config/input/assumption metadata,
  diagnostic-only ownership, and policy-specific gates:
  - `MES_linear` is the only legacy admissible ceiling policy.
  - `external_transfer` requires PR-014 transfer metadata and cannot claim
    native validation or certified filling.
  - `atlas_quantile` requires quantile/source/status metadata and only accepts
    controlled pre-solver atlas statuses.
  - `observational` requires source, sky-support, covariance, and null/mock
    status metadata and cannot certify filling.
- Implement provenance-preserving `BudgetSensitivityPoint` and
  `compare_denominator_policies`.
- Export the new MIO contract and add MIO boot-smoke coverage.
- Tighten legacy BASS descriptive report plumbing so COMMON legacy budgets can
  only use explicit `MES_linear`/`linear_MES`, reject non-positive denominators,
  and cannot be relabeled as `external_transfer`, `atlas_quantile`, or
  `observational` without the MIO contract.
- Update the current VER2 artifact export caller to pass
  `denominator_policy="MES_linear"` explicitly.

## Claim-tier impact

This PR adds a MIO L2 diagnostic-only denominator-policy contract and a
fail-closed compatibility guard for the legacy COMMON/BASS descriptive report
path. It provides metadata, policy separation, transfer provenance, and
sensitivity hooks only. It does not implement Q, certified F, Pi, G_F, HTT
evidence/posteriors, MIO certificates, transfer validation, native solver
validation, morphology compatibility, or geometry/family-classification
surface.

- owner: MIO for `BudgetSpec`; COMMON/BASS compatibility guard only for legacy
  descriptive departure plumbing
- implementation_scope: mio for `BudgetSpec`; common/bass_py compatibility for
  legacy report plumbing
- pr_scope: pre-solver
- claim_tier: diagnostic_only
- transfer_source: none by default; `external_transfer` budgets and sensitivity
  points require PR-014 metadata
- sky_support_status: not_directional by default; observational budgets require
  explicit support status
- null_mock_status: not_statistical by default; observational budgets require
  explicit null/mock status
- covariance_status: not_statistical by default; observational budgets require
  explicit covariance status
- ppc_status: not_applicable
- loocv_status: not_applicable
