### Non-blocking notes
1. **χ² identification is numerical only.** `chiSq ν` is not formally identified with `gammaMeasure (ν/2) (1/2)` or a closed-form density. That `threshold` equals scipy `chi2.ppf` is supported by the standard fact plus my Monte Carlo/scipy check, not by Lean. Correctly declared not claimed. Uniqueness of the quantile (strict monotonicity of the cdf) is also unproved; coverage does not need it.
2. **ν=0 in floating point (downstream code, not the Lean proof).** In exact arithmetic P = 0 and Q = 0 (proved). Numerically, Q ≈ 1e-27 to 1e-28 > 0, so applying `Q ≤ q = 0` gives coverage 0.0000 instead of 1 in my run. A numerical implementation must special-case ν=0 (Cα = Ω) rather than evaluate Q ≤ 0, and must use an explicit rank tolerance for ν. My run also hit a pinv-rcond rank misjudgement until I set the tolerances explicitly.
