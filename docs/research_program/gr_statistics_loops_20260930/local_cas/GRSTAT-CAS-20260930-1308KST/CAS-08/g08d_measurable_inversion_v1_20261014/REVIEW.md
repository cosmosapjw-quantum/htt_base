### Non-blocking notes
1. **Two reused-import oleans differ.** My G08AWhitening (`473f79e8…`) and G08BGaussianLaw (`b8c15594…`) oleans differ from the author's (`54406d4c…`, `2fd932bb…`). Both modules emit linter warnings that contain the absolute source path, which plausibly explains it. Both G08D oleans that depend on them are bit-identical, so the effect is cosmetic. It is worth recording that only these two are path-dependent.
2. **`CoverCert` is not a finite interval certificate.** It has an arbitrary index type `ι : Type` and Prop-level bounds, so it is sound but logically as strong as a pointwise emptiness proof. It is not a finite, executable box/interval certificate. Disclosed by the author ("Prop-level objects", no executable interval arithmetic over ℝ).
3. **Exact checkers have narrow applicability.** `checkWitness_sound` and `checkExclFinite_sound` require `∀θ, Q θ = (Qq θ : ℝ)` globally. A witness only needs the pointwise equality at θ, and the real Qstat with W = C^{-1/2} is generally not rational-valued. A data-run application will need a pointwise or interval-enclosure bridge. This is a methodology limitation, not a code defect, and is consistent with "application pending".
4. **Hypotheses not discharged for the concrete source domain.** M6–M8 and M10 take σ-compactness of Ω, continuity of m and xmap on Ω, and closed G as hypotheses. They are not proved for the source domain (5) or for `FirstJet`, which has no topology. Domain (5) is defined by finitely many strict and non-strict inequalities in finite dimensions, so it is plausibly F_σ and hence σ-compact, but this is unproved. Disclosed by the author.
5. **Scope of M9.** The counterexample uses a non-Borel (countable–cocountable) σ-algebra on Y. It is genuine for the theorem as stated (arbitrary measurable space). It does not show non-measurability for Borel Y with a Borel graph, where projections are analytic and universally measurable.
6. **accelNorm non-negativity.** Non-negativity of the quadratic form inside `accelNorm` is not formally proved; I checked it numerically (0 violations in 20,000 samples). The converse "a = 0 ⇒ x ∈ G" is not proved and not needed for the exclusion direction.
7. **Event measurability in P3/P6.** These bound the outer measure of possibly non-measurable report events, which is a valid upper bound. P7 supplies a measurable envelope of measure exactly α.
