# CAS-03-C01: independent SymPy axis derivation

Let `g=diag(-1,1,1,1)`, let `S=S.T` be an arbitrary real covariant matrix, and let `u` be any future unit vector. The global future unit shell itself has the coordinates `u=(sqrt(1+x²+y²+z²),x,y,z)` for arbitrary real `x,y,z`: the mass shell gives the two square roots, and `u0>0` selects exactly the positive one. The square root is always strictly positive.

Set `s_t=-u.T*S*u` and `B=S-s_t*g`. Since `g` is invertible, `Bu=0` is equivalent to `g^-1*Bu=0`, whose left side is `(g^-1*S)u-s_t*u`. This is an identity for arbitrary `S,u`, verified entrywise by SymPy. For any real coefficient `c`, if `(S-c*g)u=0`, then contraction with `u.T` gives `u.T*S*u-c*(u.T*g*u)=0`, hence `-s_t+c=0` on the unit shell. Thus the metric coefficient is unique. Neither implication assumes an eigenvector exists.

In the rest frame `u=e0`, `s_t=-S00`, so `(S-s_t*g)e0=(0,S10,S20,S30)`. If `Bu=0`, its entire first column vanishes. Symmetry of `S` and `g` makes `B` symmetric, so its first row vanishes too. Only then does `B=diag(0,D)` follow, with real symmetric spatial `D`. Zero expansion adds exactly `tr(D)=0`. The code constructs a generic such `D` with five independent real entries and third diagonal entry `-D11-D22`, avoiding an invertibility assumption.

For **every** `w` in `ker(D)`, define `Phi(w)=(sqrt(1+w·w),w)`. The block identity gives `B*Phi(w)=(0,Dw)=0`; the positive root makes the vector future; and its Lorentz norm is `-(1+w·w)+w·w=-1`. Conversely, any future unit `v=(q,w)` with `Bv=0` has `Dw=0`. Its norm equation gives `q²=1+w·w>0`; `q>0` forces the same positive root. Thus `v=Phi(w)`, with inverse given by taking the spatial coordinates. This inverse also proves injectivity. The proof works for every symmetric tracefree `D`, including zero and singular matrices; there is no denominator or implicit-function step. An orthonormal basis of the finite-dimensional Euclidean subspace `ker(D)` identifies this fibre with the standard future hyperboloid chart on `R^r`, `r=dim ker(D)`.

Exact controls in the executable source use `D=0` (`r=3`, full future sheet), `diag(0,1,-1)` (`r=1`), and `diag(1,1,-2)` (`r=0`, singleton `e0`). A nonzero real symmetric rank-one `D` cannot have trace zero: by the real spectral theorem it has one nonzero eigenvalue, equal to its trace. Thus `r=2` is impossible under this target's trace condition; it was not silently excluded. Repeated nonzero eigenvalues and all attainable ranks remain admitted.

Finally, `A=[[0,1],[-1,0]]⊕0₂` is Lorentz self-adjoint because `S=gA` is symmetric. Its characteristic polynomial is `lambda²(lambda²+1)`. The only real eigenvalue is zero, and its eigenspace has temporal component zero, so it contains no timelike vector. This exact counterexample rules out any universal timelike eigenline claim. The rest-frame chart is conditional on an actual future unit eigenvector.

The SymPy run checks exact symbolic equalities and matrix ranks. Branch uniqueness and the finite-dimensional quantifiers above are analytic arguments over the declared real domain.
