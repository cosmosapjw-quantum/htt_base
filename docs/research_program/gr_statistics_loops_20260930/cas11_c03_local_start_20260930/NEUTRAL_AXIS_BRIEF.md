# CAS11-C03 중립 축별 명세

실행 대상은 원 version 3 계약 `GRSTAT-20260930-CAS11-C03-WEIGHTED-PROJECTION`이다.
SHA-256: `a97dc88082095ba636d326ea390cf629b86ca333577a27638c83c2b7f9a55794`.
이 문서는 원 계약을 변경하거나 새 성공 판정을 부여하지 않는다.

## 입력과 목표

유한 차원 실수 양의 정부호 내적 W, 부분공간 V, V로의 W-직교투영 P, 유한 벡터족 K_i를 사용한다.
r_i=(I-P)K_i, R_ij=<r_i,r_j>_W다.

원 계약의 모든 정량자를 유지하여 다음을 증명·검사한다.

1. P²=P, 모든 v∈V와 x에 대해 <v,(I-P)x>_W=0.
2. 모든 실수 계수 벡터 a에 대해 aᵀRa=||Σ_i a_i r_i||²_W≥0.
3. 모든 x,y에 대해 |<x,y>_W|²≤<x,x>_W<y,y>_W를 투영 또는 제곱합 인증으로 증명한다.

## 범위와 검사

- 임의 유한 차원·부분공간과 유한 벡터족에 대한 범위를 고정 작은 차원 예제로 대체하지 않는다.
- V={0}, V=전체공간, 영벡터·영잔차, 선형 종속 잔차와 특이 R, Cauchy–Schwarz 등호·영노름 가지를 포함한다. 계약이 허용하는 영차원·빈 벡터족을 임의로 제외하지 않는다.
- W의 양의 정부호와 잔차 Gram R의 양의 준정부호를 구별한다. R의 가역성, 잔차의 독립성, 특정 Bianchi 유형을 추가 가정하지 않는다.
- 좌표 표현을 택하면 W-내적과 일반 유클리드 내적을 섞지 않는다. 투영을 계산할 때 선택한 기저의 정당성과 정의역을 명시한다.
- 수치 예제·음성 control은 보조 검사다. 계산기가 인증한 유한 대수 성분과 임의 차원 해석적 의무를 분리한다. Lean에서는 전체 진술·의존성·axiom을 확인한다.
- 원 계약의 부수적인 Lorentz/다른 CAS 성분 메타데이터가 이 유한 양의 정부호 내적을 바꾸지는 않는다. 실제 해석의 차이가 있으면 기록하고 원 계약을 임의 수정하지 않는다.
- 결론을 가정에 넣거나 표본을 보편 증명으로 취급하지 않는다. 실제 미증명·범위 불일치는 그대로 반환한다.

## 독립성과 반환

작성자는 원 계약 및 그 계약이 허용한 중립 입력을 읽는다. 다른 축의 소스·증명·결과, Host 유도문과 선행 판정은 adjudication 이전에 읽지 않는다. 불가피한 선행 노출은 공개한다.

각 축은 실제 소스, SHA-256, argv/cwd/exit, 전체 stdout/stderr, statement_alignment와 proof_coverage를 반환한다. 성공 payload는 실제 계산과 닫힌 증명 의무에 근거해야 한다. 엔진 오류나 출력 marker 부재를 수학적 반례로 바꾸지 않는다.

이 성분은 유한 deterministic residual Gram에 한정된다. 측도공간의 영함수 동치류·적분가능성·연속체 극한, 물리적 잔차의 구성과 오차 bound, 관측 covariance·catalogue fit은 범위 밖이다.
