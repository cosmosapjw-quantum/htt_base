# Host-only coverage and execution checks

Do not give this note to fresh blind axis authors. It is a scope checklist for orchestration and post-author adjudication. It contains no new CAS result. Candidate control outcomes below are exact diagnostic specifications, not executed evidence or counterexamples to the theorem.

## Full scope

For every n≥1 and rank 0,…,n, the complete forward implication must establish both range membership and the pseudoinverse bound under the declared universal premise. Preserve all zero branches. A scalar lemma, matrix identity, finite-size diagonal calculation or sampled vector suite is only partial evidence unless its general reduction and branch coverage are established explicitly.

Wolfram simplification or quantifier elimination at a fixed dimension does not establish all n. SymPy exact identities need an explicit justified dimension-independent reduction. Singular ideal reduction alone does not prove real order, PSD, arbitrary quantification or pseudoinverse semantics. A Lean result must state the aligned theorem for arbitrary finite dimension and audit its dependencies; compiling an unrelated or weaker theorem is insufficient. Imported general lemmas must have identified statements and correct assumptions. An axis that cannot close its complete contribution stays incomplete or misaligned.

The existing runner can check payload structure and actual execution; it cannot replace this mathematical scope check. Preserve its raw aggregate even if a subsequent scope review finds a narrower proof. Report component acceptance separately rather than rewriting raw evidence.

## Suggested exact diagnostic controls

Apply controls after candidate author sources are sealed. These test proposed auxiliary diagnostics or certificate verification; they are not additional theorem obligations or valid counterexamples to the contracted implication.

| Case | Inputs | Required interpretation |

| Zero branch | R=0, e=0, ε=0 | Range condition and quadratic are zero; no division failure. |

Where scripts consume certificates, include a genuine certificate/assumption mutation that the checker must reject. Do not add a fake `--self-test` wrapper returning stored expectations. Positive examples do not establish arbitrary n. Any exact control execution in the local run must retain actual source, command and output.

## Execution hazards already exposed by prior work

- Preserve the old Wolfram recursion failure. Use distinct symbols for array heads and assigned containers; an engine error or absent marker must not become `checks=false` for a mathematical theorem.
- The contract includes a historical environment record with a failed non-pinned Lean probe. Use the actual pinned project context and retain a separate current runtime observation. Preflight is readiness, not proof.
- `cas_gate.py run-adjudicate` keeps output tails. Axis wrappers must save complete engine logs. Adjudicator stdout must remain a single JSON document.
- The child `checks` object has exactly one key, `CAS11-C02-FINITE-GRAM`. Put granular coverage and diagnostics in separate evidence files, not extra obligation keys.
- A true boolean cannot be assigned merely because a program exited zero. It must be connected to the complete specified checks/proof artifacts. Do not parse a previous PASS marker instead of executing the current source.
- If proof scope is incomplete, record it without manufacturing a counterexample. If execution crashes, record an implementation/runtime failure. Retain any raw runner label without enlarging its mathematical meaning.

## Units and physical boundary

Finite algebra is evaluated in normalized real coordinates. No indefinite spacetime norm enters this target. Physical use requires separately established residuals, positive weighted inner product, error representation, moment cancellation and a norm budget; these are not supplied by the C02 premise. R is a deterministic residual Gram, not observational noise covariance.
