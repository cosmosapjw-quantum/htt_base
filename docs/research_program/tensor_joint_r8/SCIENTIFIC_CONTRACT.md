## Outcome semantics

`process_status` and `scientific_outcome` are separate. Each scope ends with measured/calibrated inference, conditional bound, partial/nonidentification, scenario, input unavailable, numerical unresolved, or validation failed. Hypothesis rejection is a scientific result under an admitted experiment; code failure is not. A branch-local failure excludes only dependent capabilities. The final synthesis waits for terminal receipts, not universal success. No global percentage of terminal nodes is a measure of scientific completion.
