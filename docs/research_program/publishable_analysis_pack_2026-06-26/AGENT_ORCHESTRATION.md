## CoVe / CCoT Protocol

For each candidate result:

1. Draft the claim in one sentence.
2. List the exact assumptions required.
3. Derive or cite the theorem step.
4. Run the smallest numerical witness.
5. Ask four verification questions:
   - Is the input real or synthetic?
   - Is the rank sufficient for the stated sector?
   - Is transfer provenance native, external, proxy, or none?
   - Does the claim require a native atlas?
6. Collapse to one of:
   - theorem/proof claim;
   - calibrated measurement claim;
   - diagnostic-only claim;
   - blocked claim;
   - rejected claim.

## Web CRAG Protocol

Before K1/K5/K6 discharge:

- verify current data source location;
- verify product naming and access constraints;
- verify whether simulations include the required systematics;
- verify method citations and caveats;
- record URLs and access date;
- do not let web snippets replace local manifests.

## Closeout

Every PR must close with:

- files changed;
- commands run;
- pass/fail/skipped status;
- claim-tier changes;
- blocker status changes;
- residual risks;
- subagents closed.
