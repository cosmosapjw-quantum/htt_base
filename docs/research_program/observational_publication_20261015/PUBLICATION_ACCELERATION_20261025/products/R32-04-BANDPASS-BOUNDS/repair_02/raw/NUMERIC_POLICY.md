# BP-03 numerical implementation delta for independent review

The exact pure-target branch uses equality of all seven supplied binary64 rows when the frozen CMB response is exactly `a = ones(7)`. This structural case has `J0 = 0`; positive finite `rho` gives a full 24-dimensional ball of radius `rho / ell`, and zero `rho` gives the exact supplied-row singleton. Unequal supplied rows at zero `rho` are empty.

For general supplied rows, the binary64 path forms `Z = L^{-1}Y`, `b = L^{-1}a`, `q = b / ||b||`, and `Jhat = ||Z - q(q^T Z)||_F^2`. Its scale-homogeneous uncertainty uses Cholesky factor and triangular-solve residuals, `cond(K)`, `gamma_7`, and `gamma_24` to form `delta_E`, then `2||Ehat|| delta_E + delta_E^2`. Budget roundoff is `2 epsilon rho^2`. The comparison tolerance is the existing relative `1e-9 * max(rho^2, Jhat, ||Z||_F^2)`. If this binary64 policy cannot resolve a boundary, it returns typed `NUMERIC_BOUNDARY_HOLD` or `BOUNDARY_UNCERTAIN` unless the bounded fallback below resolves it.

The newly added fallback uses `mpmath` at **80 and 120 decimal digits** on the same retained 7-by-9 response, nine metric scales, seven-vector response, and 7-by-24 target. Every input is lifted with `mp.mpf(float(x))`, preserving the exact value of its already supplied binary64 entry; it does not acquire new sky data or change the response, metric, budget, or rank. It computes `K^{-1}` and `J0` from the residual `Y - a s0^T`, with `s0 = Y^T K^{-1}a/(a^T K^{-1}a)`. Its retained-matrix numerical error allowance is `|J120-J80| + 16 cond(K) 10^{-76} ||Z||_F^2 + 2 epsilon |J120|`; budget roundoff remains `2 epsilon rho^2`. The fallback comparison tolerance is `1e-9 * max(rho^2, J120)`. It returns `EMPTY` or `BALL` only when the corresponding strict inequality clears both the error and tolerance; overlap stays `BOUNDARY_UNCERTAIN` with no radius. Missing `mpmath`, arithmetic failure, negative/nonfinite `J120`, binary64 underflow on conversion, or inadequate coverage retain a typed hold/uncertainty.

This error allowance is a numerical implementation policy for the retained matrices, **not** a rigorous interval proof for all possible input reals. The 120-digit regression oracle computes the Schur-complement expression, separate from the consumer's residual expression, but shares the retained binary64 inputs and `mpmath` inversion; it is not fully independent numerical certification. The first test run failed 24 cases because the binary64 error envelope was too broad. The second failed 36 near-boundary cases because the initial binary64 SVD-derived regression oracle lost accuracy there. Both failing stdout streams and their exact source/test snapshots are retained. The final 173 passing tests establish code behavior under these comparisons only. Whether this fallback and error criterion satisfy the frozen scientific contract is pending fresh independent Astra review; no scientific admission or original-42 acceptance is asserted.
