# R32-03-H03-STRUCTURED candidate

This is a complete **conditional finite-window structured-response** calculation for the retained H03 12D dipoles. Run `python consumer.py` in this directory from an environment with NumPy, SciPy and Matplotlib; build `main.pdf` with `latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex`. The consumer checks both exact retained input hashes, reads no raw catalogue, writes the full carrier and analysis JSON, the numerical table and three vector figures, and executes focused synthetic controls. `main.tex` is the five-page English RevTeX methods/results note; `main.pdf` is its built review PDF.

The source carrier stores the complete 36D covariance and all saved nine-coefficient and physical rate-tensor records, plus the extracted 12D marginal, signed dipoles and bulk response. `generated/analysis.json` stores each full D and whitened B, resolved singular vectors and spectrum, signed irreducible residual, crossing correction and refitted signal. `generated/matrix_min_budget.csv` is the compact cross-design table. These together let a reviewer check whether a scalar statement follows from the tensor and covariance carrier.

The three designs use a declared unit rate and one joint Euclidean coefficient metric. They are sensitivity spaces rather than signed physical calibration/PV/selection Jacobians. The original six-degree reference is unchanged. The physical $(x,F,\Pi,Q,G_F)$ object is undefined here. Original 42-node acceptance is unaffected. A stronger physical response interpretation requires signed source-bound derivatives of the actual estimator and an externally justified joint coefficient law or bound.

`CLAIM_TO_SOURCE.json` maps the numerical and interpretation claims. `ARTIFACT_MANIFEST.json` lists exact candidate artifact hashes and source identities. `RAW_RECEIPT.json` records actual commands and timing, including the final build.
