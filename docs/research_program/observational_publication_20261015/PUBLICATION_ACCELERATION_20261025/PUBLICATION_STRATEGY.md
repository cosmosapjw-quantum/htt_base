## Marginal scientific value and concrete execution order

The unit of progress is a derived relation, measured result, useful identified set, or a manuscript organized around one such result. Repackaging a prior result, expanding a ledger, or repeating source searches is not counted as new science.

1. **QO-METHODS: deterministic geometry + local optical realization.** Highest immediate value per new input: substantial existing proof, attained endpoint, explicit physical mechanism and independent finite checks. The first next action is to make the claim-specific source/proof/comparator bundle, then assemble the short manuscript. Its finish condition is a coherent reviewed methods result, not closure of P2's cosmological anomaly claim.
2. **P1 selected-cohort partial-identification manuscript.** Reuse the existing dedicated P1 sections and saved normalized row-likelihood statistics. Resolve the score's training-uncertainty omission only if a new predictive comparison is actually advertised. Do not demand a fully known cosmic signed-x law to publish a transparently selected statistical result; likewise do not mark that law as known.
3. **P3 structured finite-window discrepancy.** Small matrices, actual saved observations, and a material scientific discriminator: whether a named physical-error response can span the residual. Outputs are a structured budget curve, active residual directions and comparison to the unrestricted radius. This is more informative than recalculating the same conditional tail or another directional map.
4. **P2 finite-bandpass nuisance experiment.** Reuse released R31 bandpasses and all signed channels. Bound actual foreground moment/remainder freedom or propose explicitly defined added bands, compute quotient singular values/information cost, and exhibit the corresponding compensator. Chluba et al.'s moment expansion [S5] supplies the established framework; a free second-order relaxation is not automatically the nonlinear physically allowed foreground set. The existing SMICA held-out-B norm 0.37923421 microK is an observation about the fixed rule, not a physical foreground rejection.
5. **P6 then P4 physical inverse/design results.** Reuse the common optical and nuisance maps from preceding tasks. Prioritize a finite useful interval or independently measured response direction over adding nominal rank to a nearly powerless experiment. More theory can proceed conditionally without misreporting input qualification.
6. **P5 conditional external intake.** Continue only for a genuinely new obtainable atlas hypothesis. Absence of the atlas blocks this inference branch, not the independent first five scientific products.

Tasks 1–4 can begin with existing retained finite inputs; dependency gating for an original claim remains separate from readiness to investigate a narrower explicitly conditional result.
