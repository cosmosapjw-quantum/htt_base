## C3 numerical design, precision and counterexamples
1. Weighted Gaia normal equations use per-source covariance \(C_i=(\sigma_{1i}^2,\sigma_{2i}^2,\rho_i)\), \(W_i=C_i^{-1}\) with denominator \(1-\rho_i^2>0\). Explicitly preserve off-diagonal \(\rho\) terms. Process contiguous float64 B in blocks, compile C++ loop with thread-local compensated or long-double accumulator, reduce deterministically. Nonfinite, zero-error, \(|\rho|\ge1\), mismatched shape: fail closed; no silently discarded observations. BLAS NumPy reference always available. No unnecessary inverse of full N×N covariance.
2. C++ uses ordinary IEEE double inputs and long double intermediates or compensated accumulators; no -ffast-math, no GPU promotion. Native may yield mathematically equivalent but not bitwise identical sums. Only select when matched rel error <2e-11 for F/score/chi2 and actual speed. Real fitted small eigenmodes can be sensitive to roundoff; validate eigenvalues, condition number, postfit coefficients and chi2 separate from accumulator.
3. Fortran masks: actual weighted selected source group directions \(n_i\) and axis p, accumulated 20 double outputs = two hemisphere total weights, weighted 3D means and symmetric 3×3 second moments, using Neumaier/Kahan over rows; explicit positive weights, finite values and unit vectors. Angular source reference frame must be preserved (e.g., Galactic table4 cannot be mixed with ICRS signed STF). Parallel Fortran loop is not required; no false speed claim if NumPy is already faster on 35k.
4. Radio ring: sort ring integer ID exactly; subtract maximum log rate per ring and normalize \(\exp(\ell-\mathrm{max})\) with all finite \(\ell\). If all source ring totals N_r are zero, return an exactly zero contribution; no division by zero. Scores derivative \(\partial_\beta F_A\) uses \(\sum_r N_r/N \operatorname{Cov}_r(1_A,n)\) only with explicit k_b, not an observed beta. Stable under log offsets ±1000.
5. Rotation preserve STF trace/SO3 signed chi, reject det<0 for orientation-sensitive Lie; no arbitrary sign flips of N. Photon PSD use symmetric eigval with declared relative residual, never silently clamp physically negative distribution. Cholesky Schur on SPD, reject singular source covariance, do not imply lack of physics. Flat Sachs J=lambda I analytic; constant isotropic tidal J=sin(sqrt(k)lambda)/sqrt(k) I, and only fixed-affine optics not observed D_L(z). Online mean/cov uses Welford–Chan and finite normalization N−1 (if N>1).
6. Performance acceptance: run repeated median after warmup on same Gaia sample and blocks, and on real CF4 angular groups for Fortran; report min/median and ratio with actual hardware. Native fastest conditional on accuracy and measured ratio; otherwise NumPy is retained as production path and native stays tested optional. CPU memory target <~400 MiB incremental on Gaia quality chunk, no N² allocation; benchmark counters do not include source FITS I/O for computational kernel speedup. OpenBLAS/OMP controlled with max 1 BLAS thread and explicit N native worker threads.
