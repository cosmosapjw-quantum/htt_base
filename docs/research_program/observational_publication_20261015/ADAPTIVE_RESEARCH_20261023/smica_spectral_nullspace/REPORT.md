# R25 SMICA spectral nullspace: source-bound linear information audit

**Scope and status.** This is a fixed-operator, claim-tier C0 diagnostic of the released Planck PR3 R3.00 SMICA polarization propagation weights. It asks which processed-frequency E/B harmonic contrasts can be recovered from the released compression rows at ℓ=2,3. It does not measure a foreground amplitude, supply a matched physical CMB null, identify a Bianchi family, or advance an original publication acceptance. Independent review is pending.

## Source and interpretation

The local archive `COM_Code_SMICA-weights-propagation_R3.00.tar.gz` (74,625,775 bytes; SHA-256 `044ec9bed746ae745ad35a8b6ccf6e603f546083fec328e9c64d866ac9221f93`) supplies `weights_EB_smica_R3.00.txt`, `smica_coadd.py`, and `README`; their exact member hashes are recorded in `RESULT.json` and `MANIFEST.json`. The archive was read in memory. Its Python 2 producer was inspected, never executed. It loads the weight text as `(2,7,4001)`, processes 30, 44, 70, 100, 143, 217, and 353 GHz polarization maps into E and B alms, applies the corresponding E or B harmonic row, and then applies a common pixel window. The README says the weights include beam correction and LFI beam renormalization. The producer converts its frequency-map inputs into µK_CMB before combining them. Thus the seven `s` coordinates below are **processed frequency harmonics in the producer's units**, rather than arbitrary native map amplitudes. We neither set the row sum to one nor use a naive foreground spectral law; the observed row sums differ from one at source precision.

The [Planck diffuse component separation paper](https://arxiv.org/abs/1807.06208) describes seven polarization frequency maps and SMICA as a component separation route. [Constrained ILC](https://arxiv.org/abs/1006.5599) and [constrained moment ILC](https://arxiv.org/abs/2006.08628) motivate keeping spectral contrast constraints distinct from a compressed CMB map. These papers are context; the local release members above define the numerical operator audited here. The A&A HTML link in the frozen input returned HTTP 403 during this run, so its arXiv counterpart was used for source context.

## Mathematical discrimination

For each polarization `p ∈ {E,B}`, multipole `ℓ ∈ {2,3}`, and real harmonic coordinate `m=-ℓ,…,ℓ`, write `y_{pℓm}=w_{pℓ}ᵀs_{pℓm}`. The common output pixel window, if nonzero at these ℓ, multiplies `y` without changing this row kernel. The supplied producer applies no second frequency observation to the same unknown E/B coordinate. E and B are distinct fields. The full input carrier contains `7×(5+7)×2=168` real coordinates; its compressed carrier contains `(5+7)×2=24`. `RESULT.json` retains all 168 nonzero sparse entries of the explicit 24×168 block operator, the four `wᵀ⊗I_(2ℓ+1)` blocks, and a per-harmonic kernel basis. Since all four rows are nonzero, its rank is 24 and its kernel dimension is 144. This is a statement about the fixed linear response, not an observed sky realization or physical feasibility set.

For any target frequency functional `x_a(s)=aᵀs`, the finite-dimensional theorem is `x_a` identified from `y=Ms` iff `ker M ⊆ ker x_a`, equivalently `x_a=KM` for some `K`. For a nonzero row, `P_ker=I−wwᵀ/(wᵀw)`. Set `h=P_ker a`. Then `wᵀh=0` and `aᵀh=hᵀh`; `s₀=0` and `s₁=h` have identical compressed output but different target contrast when `h≠0`. The four exact witnesses in `RESULT.json` use original decimal strings, parsed as rationals, for the 30−44 GHz contrast. They give the seven rational components of `h`, exact `wᵀh=0`, exact `aᵀh−hᵀh=0`, and independent 80-digit decimal residuals. Their full-tensor versions place this seven-vector at any one harmonic coordinate and zero elsewhere.

Every four-row analysis includes all seven unit-frequency and all 21 pair-difference targets: 112 targets total. For each, the result stores the target, Euclidean retained and lost projection norms and fractions, squared fractions, a seven-coordinate `(s₀,s₁)` witness, and an independent least-squares residual. The fractions use a declared Euclidean metric on the seven processed coordinates; they are **computational coordinate measures**, sensitive to coordinate scaling, not a foreground amplitude or statistical confidence. Among pair contrasts, the smallest lost norm fraction is about 0.7479 for E2/E3 (30−143 GHz) and 0.8169 for B2/B3 (30−143 GHz). The largest is about 0.999913 for E2/E3 (217−353 GHz) and 0.999969 for B2/B3 (44−217 GHz). Every listed unit or pair contrast has a nonzero lost component, so none is exactly recoverable from its single released row under this carrier definition. The accompanying figure displays all 21 pair losses for all four rows.

## Formalism boundary

`x` here is the declared frequency functional `aᵀs` on the full tensor carrier; it is not the cosmological signed departure `x_C`. For an observed compressed value `y`, the response fiber is `F_response(y)={s:Ms=y}=s_*+ker M`; it has explicit kernel directions and is not a bounded physical feasible set or an occupancy fraction. Physical `F` is **UNKNOWN** because no sky/support measure or admissible physical ceiling is supplied. `Q_comp=||P_ker a||/||a||` is a coordinate-norm diagnostic, with denominator and metric stated above; physical policy-normalized `Q` is **UNKNOWN**. `Pi` is **UNKNOWN**, because no joint physical law or null ensemble is supplied. The four `(p,ℓ)` response entries can be organized as `G_F` bookkeeping, but there is no redshift/depth support and therefore no cosmological depth-gap `G_F` here. The released weights are external component-separation provenance; they are not native BASS transfer functions or an atlas.
