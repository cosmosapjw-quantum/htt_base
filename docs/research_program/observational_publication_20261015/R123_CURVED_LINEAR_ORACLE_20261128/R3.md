# R3: background and conventions
Signature (-,+,+,+), eta=ln(a_bar/a_emit), propagation direction n with polar axis z. Balanced VII background N=k diag(1,1,0), A=a e_z, Fermi frame. Hubble normalization: structure constants c/H times inverse length, Sigma=physical shear/H. Use initial k0=.01, a0=0 (VII0) or .005 (VIIh, h=.25), initial Omega_K=a0²; Omega_m+r=1-Omega_Lambda-a0² and dust fraction split as prior native. H²/H_emit²=m0 exp(-3eta)+r0 exp(-4eta)+L0+a0² exp(-2eta). Thus k=k0 exp(-eta)/Hratio, a=a0 exp(-eta)/Hratio, q=.5 Omega_m+Omega_r-Omega_Lambda. Pure transverse STF seed epsilon diag(1,-1,0) fixes initial Codazzi flux to zero, no linear dipole, scalar or vector sector. Positive m=2 complex carrier S(w)=[[Re w,-Im w,0],[-Im w,-Re w,0],[0,0,0]]. Sigma=S(s), delta N=k S(d), d'=2s by N evolution. Initial s=1,d=0 for derivative w.r.t. epsilon, radiation anisotropies zero. Table-only opacity c sigma_T n_H_emit exp(-3eta) xe/H; no matched REC correction. Host normal at first order, outward sky opposite propagation. Q,Pi,F,G_F not defined without respective physical body/null/measure/transport.
