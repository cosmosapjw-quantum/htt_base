# K03 외부 관측 입력 사전준비: nonradial transverse response

실제 CF4 35,970 grouped source의 angular n_J2000만 사용한다. 물리적으로 관측된 proper motion, 1+3 global source transfer, source correlated covariance는 없다. 국소 Euclidean first-jet에서 radial nWn=0, tangential (I-nn)Wn=Wn이며, tangent shear5+omega3 설계의 rank8와omega-after-shear rank3를 관측창별 검증. 전체 CF4 방향의 omega-profiled relative eigen=[0.7480828469914959, 0.8349358091887091, 0.9849938452618903], 자세한 shell별 결과는 JSON 참고. 이 결과는 K03 외부입력 준비증거이며 완료/검출이 아니다.
