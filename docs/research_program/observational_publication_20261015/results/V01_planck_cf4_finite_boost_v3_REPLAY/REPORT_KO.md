# P4 V01: 정확한 국소 Lorentz frame bridge와 실제 Planck/CF4 소스 주입

Frame beta_AB는 '관측자 B에서 본 프레임 A'의 3-velocity fraction이다. 복사 R, 물질 M, 관측자 O 세 congruence/orthonormal tetrad의 event-local Lorentz map이 수학적으로 유효함을 확인했다. Planck dipole first-order reference beta=0.001233573536, v=369.816 km/s, source axis Galactic (264.021°,48.253°).

Monopole blackbody T0 boost의 l1 dipole norm=3362.081 microK; l2 STF analytic residual=1.11363e-06 microK.

실제 source SMICA_FULL l2/l3 곱하고 angular aberration한 뒤 l2 finite-source coefficient 변화 norm=0.037747192 microK, l3=0.056615899 microK.

이것은 실제 Planck 소스 관측의 'boost correction'이 아니다: 원래 processing에는 solar dipole가 제거되어 있고 여기서는 임의 l2+l3 관측 계수를 가정된 radiation-rest 소스로 다시 주입한 counterfactual이다. CF4 z_CMB도 기초 관측자의 속도 보정이 이미 적용되었으므로 위 observer velocity의 angular source projection은 중복 적용 불가능한 조건부 survey-window response check로만 보존했다. global tilted Bianchi emission/opacity history 및 source covariance 부재, physical beta_RM posterior나 rho와 beta 혼동 허용 불가.
