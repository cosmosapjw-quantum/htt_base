# CF4 35,970 실제 그룹의 redshift-dependent Hubble 관측창

표본은 published Cosmicflows-4 group에서 고른 동일 35,970개이며 새로운 독립 표본은 아니다. zcmb/c 및 DMzp로 만든 log(cz/D) estimator는 H_eff apparent/source-conditional이고 물리적 Θ/3, Bianchi shear 또는 cosmological H0 posterior가 아니다.

Window source counts: [8581, 7833, 8818, 10738, 16414, 25232, 35970]. Shell H_eff [km/s/Mpc]: [74.08727281722821, 73.68044194436894, 71.3115578274404, 68.88624490075597]. Shell bulk response |kB*300km/s|: [0.006861798913764005, 0.008237114546477428, 0.010094394341431188, 0.008680937631186748].

Covariance는 겹치는 각 window에 같은 group ID를 통한 working diagonal C만 전파한다. 실제 shared calibration/peculiar cosmic velocity/selection의 비대각 covariance는 미제공, 따라서 신뢰구간, 비등방성 검출 유의도, physical tensor shear posterior로 승격하지 않는다.
