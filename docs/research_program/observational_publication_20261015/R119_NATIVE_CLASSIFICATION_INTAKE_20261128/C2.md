# Source-to-consumer map
* R114 C1 receipt binds per-case h32_s2000 signed LOS mode bytes; EXECUTED_COMMANDS binds the producer revision. These are historical native outputs, not C4F outputs.
* Layout: runs/<case>/<tag>/los_modes.tsv; row i=l(l+1)+m, l=0..128, all signed m; T,E,B complex columns and deterministic pair products. Dimensionless native units, host observer, common HyRec x_e history.
* Independent reader takes a case, not k. TransferValidRange requires a strictly positive k-domain and cannot represent a finite homogeneous sky. Preserve the existing transfer entry point's non-fabrication behavior.
* Derive exact manifest from the pinned receipt and ledger; reject disagreement, missing data, malformed modes, nonfinite values, invalid reality, nonzero spin-2 l<2, inconsistent pair products or selected C_l.
* The legacy marker is only file presence. Even a verified deterministic atlas is insufficient for C6; mask, covariance, null and continuous family likelihood are not present.
