# Numerical contract
C_l(X,Y)=sum_m a_X conjugate(a_Y)/(2l+1); it is not a stochastic covariance. Signed m reality: a(l,-m)=(-1)^m conjugate(a(l,m)). Use rtol=2e-12, atol=1e-18 for reality and 1e-24 for mode products, matching R7; selected C_l rtol=2e-11, atol=1e-24. Reject nonfinite data before tolerances. Source identity takes precedence over numerical equivalence.
For geometry-only comparisons, normalize nonzero vectors on l=2..8. Optimize positive amplitude analytically; d=sqrt(1-max(0,Re inner)^2). Norm of each l/channel is rotation invariant; its normalized block-dot bounds maximal correlation above and therefore distance below. A sampled common proper SO(3) rotation yields an upper bound, not an exact minimum. Exclude FLRW from shape normalization.
