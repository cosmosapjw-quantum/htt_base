# R9: calculation contract
Input: producer-bound manifest with exact BASS revision, history/opacity hash, binary hash, run record, observer frame, phase and unit convention; per finite point source LOS TSV and its recorded SHA256, expected signed degree, parameter coordinates, constraints, source-native spectra. Output deterministic all-m complex sky ordered by ell*(ell+1)+m; raw full l<=128 retained, explicit l=2..8 slice for diagnostics, no covariance or k input. Check hash, exact header/index coverage, finite values, real-field conjugacy, spin-2 low degrees and computed products. Export qualified source-specific conditional metadata, not native-validated TransferFunctionSpec. C5 exposes a new typed deterministic entry point; old k-dependent entry remains unimplemented for physical reason. Ensure a bare manifest does not promote C6. C7 compare full source and FLRW control; C8 measure truncation, geometry-only profile brackets and finite rotation resolution, and record actual errors. For (x,Q,Pi,F,G_F), x is dimensionless signed physical prediction; Q requires a declared meaningful body, Pi matched null, F finite measure, G_F transport. Leave these physical quantities undefined until supplied; norm and block profile are explicitly auxiliary.
