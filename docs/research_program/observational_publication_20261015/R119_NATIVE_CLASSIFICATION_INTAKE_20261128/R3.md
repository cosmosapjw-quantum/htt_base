# R3: exact objects and conventions
With signature (-,+,+,+), use right-handed orthonormal normal tetrad, Hubble-normalized symmetric N, vector A, STF Sigma. Source _rustcore/src/geom/lie.rs defines C^k_ij=eps_ijl N^lk+A_i delta^k_j-A_j delta^k_i, Jacobi N A=0, and sky generator potentials; spatial unit length is Hubble length c/H. Normal, host, radiation-energy and observer frames differ. The R114 driver selects host observer and reports these velocities. Source sky_spectrum.rs uses arrival direction opposite photon propagation, Q+iU on (e_theta,e_phi), Condon–Shortley and HEALPix/COSMO E=-(a_++a_-)/2, B=i(a_+-a_-)/2. Preserve native dimensionless units, not unverified microkelvin conversion.
Deterministic mean x(theta) is a complete signed T/E/B coefficient list. A homogeneous template is not a transfer function Delta_l(k). The existing TransferValidRange forces a positive k interval; BianchiTransferAdapter.evaluate_lowell_transfer(ell,k,family) is therefore semantically wrong for this source. Add a separate deterministic reader rather than filling k with an invented value.
