# R6: adversarial review
For m=0, homogeneous monopole perturbation is not to be mistaken for an independent k-mode source; derivative of constant vanishes, collision conserves monopole. We omit perturbed mean H and individual density histories only from linear anisotropic/dipole equations, not claim full scalar background solution. Source pressureless dust number divergence is linear (2 A.beta), but density times tilt/shear perturbation is second order. Initial velocities constrained by total flux, not separately by baryon flux; coflow is explicitly BASS's native choice. For m=1, complex carrier sign fixed by Y11/Y21 Condon-Shortley and axial(NS); independent direct screen integrals required for spin ±2 phase before using results. Thomson monopole conservation, opposite momentum transfer, exact constraint propagation and frame dipole sign are separate checks. Numerical small-seed errors include truncation/time and floating error, not a universal proof. Compare signed dipole and ell>=2 separately; a very small scalar VII0 dipole is absolute-only. No regular-mode bridge or external solver parity, no native subagent.
