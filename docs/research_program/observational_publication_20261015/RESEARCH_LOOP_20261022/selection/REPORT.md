For strictly positive, normalized reference masses `p`, a compact nonempty weight polytope `a≤r≤b`, `Br≤d`, `Er=f`, and certified **per-atom binary** envelope `eL≤I_E≤eU`, the endpoint problem is `min/max (p*e)·r/(p·r)`. The `r_i` are **unnormalized positive joint importance/selection weights**; the normalized target/reference joint-law Radon–Nikodym ratio is `r_i/Z`, with common `Z=p·r`. State-dependent catalogue selection normalization must already be part of the target kernel. Unknown `Z` does not give measured `r_i` bounds, and inverse detection probabilities on retained working-Gaussian draws do not supply them. The mathematical Charnes–Cooper variables are `t=1/(p·r)` and `y=tr`, with `p·y=1`, `a t≤y≤b t`, `By≤d t`, `Ey=f t`, `t≥0`. The numerical implementation uses conditioned masses `q_i=p_i y_i`, so `sum(q)=1` and the event objective is `e·q`; this avoids tiny objective coefficients when reference atoms have small mass. Coupled-polytope LP witnesses are recovered as `r_i=q_i/(p_i t)`, checked in original constraints and objective at absolute residual `1e-10`, and given a primal-dual optimality check. Infeasible or numerically invalid polytopes fail explicitly. For a pure box, monotonicity gives the exact endpoint vertex and avoids LP tolerance entirely.

The sharpness statement holds for the relaxed class in which event completions and weight choices are independent. A source law coupling them can narrow the identified set; these endpoints then remain outer bounds. Event construction from physical data is unresolved. The box formula for **unnormalized weights** `r_i∈[1/Γ,Γ]` uses only lower/upper reference event mass `L,U`: `L/(L+Γ²(1−L))` and `Γ²U/(Γ²U+1−U)`. Fractional aggregate masses `L,U` are valid in this helper; fractional per-atom event flags are rejected. A target mass of at most `ε` outside reference support widens an interval to `[(1−ε)L,(1−ε)U+ε]`. A common weight cancels exactly. A bound on the normalized RN ratio itself would require the additional condition `p·r=1` and is a different feasible set.
