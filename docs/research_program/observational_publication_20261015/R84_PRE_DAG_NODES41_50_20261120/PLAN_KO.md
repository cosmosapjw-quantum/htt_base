## C3 exact source-conditional ring score, tensor/frame and rank error budgets

For original R65 three flux bins b, 185 fixed ring groups g, each pixel-centre source direction \(n_i\in S^2\) in ICRS, original fitted two-component signed dipole \(v_b=(v_x,v_y)\) and fixed k_b, and frozen selected ring totals \(N_{bg}=\sum_{i:g_i=g}c_{bi}\), define normalized conditional pixel density
\[
p_{bi}=\exp(\ell_{bi}-m_{bg})/\sum_{j:g_j=g}\exp(\ell_{bj}-m_{bg}),\quad
\ell_{bi}=v_{bx}n_{ix}+v_{by}n_{iy},\quad m_{bg}=\max_{i:g_i=g}\ell_{bi}.
\]
Define \(r_{bg}=N_{bg}/\sum_g N_{bg}\), \(a_{bi}=r_{bg_i}p_{bi}\), and within-ring \(\mu_{bg}=\sum_{i:g_i=g}p_{bi}n_i\), score **\(s_{bi}=k_ba_{bi}(n_i-\mu_{bg_i})\)**. Then for any fixed selected hemisphere axis \(u\),
\[
F_b(u)=\sum_i a_{bi}\mathbf1(n_i\cdot u>0),\quad
\nabla_{\beta}F_b(u)\big|_{\beta=0}=\sum_i s_{bi}\mathbf1(n_i\cdot u>0).
\]
The source score identity \(\sum_i s_{bi}=0\) is enforced before native calls, not posthoc correction. Positive ring totals must have data and each ring probability sums to 1. The latter removes normal-component (constant-within-ring) nuisance and is different from the unprofiled global beta gradient. Numerical underflow-safe logsumexp by ring, stable double reductions; dynamic \(n\) belongs to one physically specified source frame. \(\nabla_\beta F\) is a **conditional model derivative**, not an actually observed observer velocity, nor actual physical \(G_F\). Source prior R74 CMB axis gradient z=0 is caused by exact ring geometry, not a generic physical prior.
