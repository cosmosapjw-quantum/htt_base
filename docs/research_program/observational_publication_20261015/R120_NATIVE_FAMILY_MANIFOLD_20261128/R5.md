# R5: exact curvature and local nuisance quotient
From C, Koszul Gamma^k_ij=(C^k_ij-C^i_jk+C^j_ki)/2. Constant spatial coefficients give R^l_kij=Gamma^m_jk Gamma^l_im-Gamma^m_ik Gamma^l_jm-C^m_ij Gamma^l_mk. Contracting Ric_jk=R^i_kij and expressing in units H²/c² gives Ric_11=-(b-d)^2/2-2 A0²; Ric_22=(b²-d²)/2-2 A0²; Ric_33=(-b²+d²)/2-2 A0²; Ric_23=Ric_32=(b-d)A0; other off-diagonals zero. Therefore K=(b-d)^2/12+A0². Wolfram Language symbolic Koszul contraction verified all components. For balanced VI, K=k²/3+A0² and Ric23=2k A0, so curvature itself generates tracefree stress evolution; balanced VII has Ric=-2 A0² I but its spatial-frame twist still depends on k. At h=-1/9 the Codazzi operator determinant 3(9 A0²+b d) vanishes (BASS group.rs), so do not invert that matrix there.
For nonzero real-sky vector x in signed harmonic space use real inner product Re(x†y). Let J=∂x/∂p; U=[x, L_x x, L_y x, L_z x] with L_i=-i angular-momentum representation in each T/E/B block. Minimize ||J dp-U dz||², with positive amplitude near 1. Least-squares solution dz=U^+ J dp yields G=(P J)^T(P J)/||x||² where P=I-UU^+ in real coordinates. This is the first nonzero quadratic metric on local morphology modulo amplitude and orientation, not a Fisher matrix absent observational C. Rank drops in stabilizers and FLRW; use SVD and report sensitivity, never invert U^T U blindly. If C is known and positive definite, replace all columns by C^-1/2 times response-transformed columns and optionally omit amplitude as nuisance when amplitude is physically constrained. A nonzero projected direction establishes local sensitivity on that chart only; rank loss at a point is not global nonidentifiability.
