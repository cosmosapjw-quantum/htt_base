# 원본 REC·REI 이력을 이용한 Rust BASS 유한구간 계산

후기 구간에는 원본 REI의 AXBI 조건부 다섯 물질 이력을 적용한다. 평균 적색편이 20에서 방출해 4에서 받으며, 각 이력은 1,001개 고유시간 절점이다. 초기 구간은 원본 REC가 q=0 HyRec 2012 모형으로 계산한 8,001개 정수 적색편이 출력에서 1200부터 1000까지 201개를 선택한다. 초기와 후기 수신자는 서로 다르다. 두 구간 사이와 오늘까지의 전달에는 별도 물질 이력이 필요하다.

## 원본 코드와 데이터 흐름

1. 후기에는 원본 REI Rust `thomson_history`가 소스의 고유 수소 핵 밀도와 전자수율, 고유시간, 축대칭 계량의 변형 변수 b를 복원한다. 다섯 원본에는 전자 틸트가 0이다. 초기에는 원본 REC의 전자수율과 원본 배경의 수소 핵 밀도 및 H(z)를 사용한다. 두 공급자의 헬륨 핵수비와 적색편이 기준을 각각 따른다.
2. 원본 REC Rust `rec_ray_thomson`이 고유시간에 대한 ln(nH)와 전자수율의 선형 보간을 사용해 각 Δτ와 수신자까지의 생존율, 산란 질량을 적분한다. 독립 8점 Gauss 구적으로 각 셀을 확인한다. 원본 Rust의 σT = 6.6524587051 × 10⁻²⁹ m²과 c = 299792458 m/s를 사용한다.
3. BASS 입력 q = cσT ne/H는 정상계 시간 η = ln(a/a_emit)당 산란율이다. REC 노출을 보존하려고 양 끝의 원래 기울기를 유지하고 내부 중점값을 qₘ = 2Δτ/Δη − (qL + qR)/2로 정한다. 두 선형 구간을 적분하면 Δη(qL + 2qₘ + qR)/4 = Δτ이다. 음의 중점값은 거부한다. 원본 BASS가 실제로 누적한 `proper_depth`도 다시 대조한다.
4. Rust BASS의 I형 배경에서 원본 물질을 처방한 편광 tracer를 실행한다. 배경과 그 물질 이력이 하나의 중력·물질 초기값 문제를 풀었다는 주장은 별도 검증이 필요하다. T = I^(1/4)/⟨I^(1/4)⟩ − 1과 Q,U의 4⟨I⟩ 정규화, 바깥을 향한 관측자 하늘과 HEALPix 스핀 관례를 따른다. 전 m = −ℓ,…,+ℓ의 복소 구면조화계수에 대해 aX·aY*, 결정론적 Cℓ 및 실수장 켤레대칭을 재계산한다.

## 역사적 수치 대조

후기에는 공통 물질 방출면까지의 τ를 R106의 312,238절점 독립 결과와 대조한다. R105의 방향별 관측 적색편이에는 수직·평행 축의 척도인자가 각각 a exp(−b), a exp(2b)인 축대칭 I형 기하를 사용한다. 공변 광자운동량이 보존되므로 ln(1+z) = Nₒ − N + (1/2)ln[(1−μ²)exp(2Δb) + μ² exp(−4Δb)]이며 Δb = b − bₒ이다. 주어진 z, μ에서 해당 방출 사건과 REC로 구한 유한 τ를 찾고 48점 Gauss 구적으로 τ₀, τ₂를 적분한다. 6개 관측 적색편이와 5개 원본 이력을 대조한다. 보간법과 간격에 따른 차이는 결과에 함께 기록한다.

## 실제 실행 결과

다섯 REI 이력과 한 REC 이력 각각에서 16, 32, 64, 128 시간 스텝을 사용해 총 24개 하늘을 계산했다. 공통 설정은 I형, 전단 초기 매개변수 0.008, 전자 및 수신자 틸트 0, 최대 ℓ = 4, 각도 격자 10 × 24다. 아래는 128스텝의 무차원 온도 사중극 전력이다.

| 물질 소재 및 구간 | 원본 REC의 τ | BASS C₂(TT) |
|---|---:|---:|
| REC, z = 1200 → 1000 | 2.85738726816 | 2.34934578985 × 10⁻⁷ |
| REI ZERO, 평균 z = 20 → 4 | 0.031968205575 | 5.29567677202 × 10⁻⁶ |
| REI SHEAR_PLUS, 평균 z = 20 → 4 | 0.031967946280 | 5.29567907809 × 10⁻⁶ |
| REI SHEAR_MINUS, 평균 z = 20 → 4 | 0.031967946280 | 5.29567907809 × 10⁻⁶ |

5,200개 물질 셀에서 BASS 보간표가 보존한 REC 노출의 최대 절대 오차는 6.94 × 10⁻¹⁸이었다. 실제 BASS 누적 수신자 깊이와 보간표 적분의 최대 차이는 1.34 × 10⁻¹⁵ 이하였다. 후기의 고유시간 REC 보간은 R106 전체 절점의 Richardson 추정치보다 약 2.27 × 10⁻⁸ 컸다. N64와 N128 사이 C₂(TT)의 최대 상대 차이는 2.282 × 10⁻⁴였다. 광학 깊이 셀에서 얻은 높은 수치 일치도를 하늘의 연속체 수렴 오차로 해석할 수 없다.

## 재현

아래 명령은 세 저장소를 각각 `NATIVE_MATERIAL_PINS.json`의 커밋으로 체크아웃한 뒤 htt_base 루트에서 실행한다. REC와 REI의 원자료 커밋이 별도 객체 저장소에 있다면 `--rec-source`, `--rei-source`에 그 경로를 지정한다. BASS 원본 빌드 캐시가 있다면 `--bass-target`에 Cargo target 경로를 지정할 수 있다.

```sh
d=docs/research_program/observational_publication_20261015/R109_NATIVE_RUST_BIANCHI_20261124
python -m scripts.r109.native_material_sky \
  --rec-repo "$REC_REPO" --rei-repo "$REI_REPO" --bass-repo "$BASS_REPO" \
  --pins "$d/NATIVE_MATERIAL_PINS.json" \
  --steps 16 32 64 128 --sky-cases REC_1200_1000 ZERO SHEAR_HALF_PLUS SHEAR_HALF_MINUS SHEAR_PLUS SHEAR_MINUS \
  --products-dir "$PWD/r109-material-products" --output "$d/NATIVE_MATERIAL_SKY.json"
python -m pytest -q tests/obsstat/test_r109_material_sky.py
```

`--products-dir`는 새 디렉터리로 지정한다. 각 경우의 `rest.tsv`, `rec_cells.tsv`, `rate.tsv`와 분해능별 `modes.tsv`, `cl.tsv`, `diagnostics.tsv`가 저장된다. JSON에는 각 원본 실행 파일과 물질의 SHA-256, 표본 수, 모든 부호 있는 T·E·B 구면조화계수, 시간 분해능 간 차이가 있다. R78의 원래 과학 수용 상태와 보정된 물리적 Π, 관측된 계열 귀속은 이 증거 범위 밖에 있다.
