# 비영 정상 플럭스에서 Hamiltonian–Codazzi 동시 초기조건

**구현·수치 검증.** `build_tilted_initial_conditions`의 두 고정-H 정책은 사용자가 준 정상 플럭스, 물질 밀도, 우주상수를 보존하며 최종 전단과 Lie 대수에 대해 양쪽 제약을 재평가한다. 이 결과는 `CODAZZI_FIX_KO.md`에 남겨 둔 선택적 재조정 단계의 문제를 해결한다.

## 구성

공간 직교정규 틀과 `(−,+,+,+)`에서 물리적 정상 플럭스는 `qⁱ=T⁰ⁱ`이다. `A`는 정규직교 STF-5 기저에서 전단을 발산으로 보내는 연산자다. `b=−κq`, `x_p=A⁺b`, `x_0=P_ker(A)x`라 쓰면 초기 전단은 `x=x_p+x_0`이다. 같은 SVD 상대 문턱 `10⁻⁶`으로 행공간과 유효 영공간을 구분하며, 실제 최종 발산은 원래 연결로 다시 계산한다. `U=‖x_p‖²`, `V=‖x_0‖²`, `E=3H²−κρ−Λ`로 놓는다. 직교 기저이므로 `‖x‖²=σ_ab σ^ab`이다.

- **전단 진폭 조정.** 고정 곡률 `R₀`에서 Gauss가 요구하는 전체 제곱노름은 `F=2E+R₀`이다. 최소 가능값은 `U`이다. `F>U`이면 입력의 영공간 방향을 따라 `x′=x_p+√(F−U) x_0/‖x_0‖`를 반환한다. `F=U`이면 `x′=x_p`다. 물리적으로 불가능한 `F<U`와 영공간 방향이 주어지지 않은 양의 잔여 노름은 서로 다른 오류로 처리한다. 경계의 반올림 불확도는 Gauss 각 항의 크기로 평가한다.
- **곡률 조정.** Lie 대수의 균일 배율이 `u>0`이면 `A′=uA`, `R′=u²R₀`이다. `x′=x_p/u+x_0`로 두면 Codazzi가 성립한다. `y=u²`에 대한 Gauss 방정식은 `R₀ y²+(2E−V)y−U=0`이다. 양의 해가 둘이면 `|ln u|`가 작은 가지를 택하며 동률에서는 큰 해를 택한다. 두 가지가 합쳐지는 지점은 `u_*=(U/|R₀|)^(1/4)`이다. 변별식은 계수를 정규화한 후 계산하고, 큰 쪽 근과 근의 곱을 이용해 취소를 피한다. 최종 `u`는 제곱근 비율로 직접 계산하므로 일부 표현 가능한 `u`에서 `u²`가 부동소수점 범위를 넘는 경우에도 근을 구할 수 있다.

`algebra_scale_factor`는 실제 `u`, `shear_amplitude_scale`은 최종 전단 노름과 첫 Codazzi 투영 직후 전단 노름의 비다. 비영 플럭스에서는 전체 전단을 한 상수로 곱하면 Codazzi의 소스가 달라지므로 어느 성분이 바뀌었는지 `metadata.notes`에 표시한다. 정확히 영 플럭스인 기존 직교·상쇄 유체는 종전 정책을 그대로 사용한다.
