# CF4 원표 실행 결과

같은 7,190개 6dFGSv 거리 mark로 계산한 5개 공통 radial field 시나리오와 영장(zero-field) 사이의 조건부 log density 차이가, 어느 매칭 정보를 조건으로 삼느냐에 따라 **−11.94216에서 +27.34102**로 바뀌었다. 두 계산은 동일한 fitted probit과 release를 사용한다. 후자는 CF4 table 2와 고유 매칭되지 않은 1,695개 행의 관측된 상태도 사용하며, 그 행들의 거리 mark는 적분 소거한다.

log density는 7,190개 magnitude 좌표의 동일한 기준측도로 환산했다. 고정된 단일 장에서는 미매칭 확률이 조건부 분자와 분모에서 정확히 상쇄된다. 두 fitted 행의 영장 log density가 같고 혼합장 값만 39.283180 변하는 이유다. 여러 장이 공존하면 장마다 미매칭 패턴의 확률이 달라 혼합 가중치가 변한다.

양의 상태만 주고 mark도 관측한 경우에는 mark별 선택확률이 주어진 mark에서 모든 장에 동일하게 곱해진다. 실제로 고정 컷과 fitted probit 모두 +100 km/s 장에 0.999999981의 가중치를 주었다. 전체 패턴에서 고정 mean template 배율의 score는 −24.827022이고 중앙차분 절대오차는 1.12×10⁻⁶이다. 기존 컷의 log density·log inclusion 재현 최대 절대오차는 2.01×10⁻¹¹ 이하였다.

이 결과는 동일 릴리스와 같은 적합계수를 사용한 조건부 민감도다. 매칭 실패에는 후보가 여러 개인 4개와 매칭되지 않은 1,691개가 포함된다. R100 Gaussian 폭과 공통 bolometric radial-shift scenario를 유지했다. CF4 전체 모집단의 선택·교정법칙, 독립 검증 표본과 물리적 속도장은 미확정이다.

**실행 근거**는 같은 R101 결과 디렉터리의 `CF4_PREDICTIVE_RESPONSE.json`과 `OWNER_RUN_RECEIPT.json`이다. 소유자 환경에서 `scripts.r101.program analysis --all`은 8.98초에 종료 코드 0을 냈고, 범위 내 pytest와 R100 회귀 validator도 종료 코드 0이었다. 실제 입력 SHA-256은 6dFGSv table 1의 `08f3d4b264e28efcb574bea4efa370d66e4f299f8254e21bd04979fb8301a14d`와 CF4 table 2의 `8e908928e68352b59292cf67020a4d70aaa6d30f278dfa6aa3e41a9df808332f`이다.
