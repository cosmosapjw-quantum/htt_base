# Evidence and citation policy

1. 핵심 claim에는 근거 상태를 붙인다: `established / literature-supported / derived / numerically checked / implementation-verified / conjectural / unresolved / blocked`. `established`도 요청에 관련된 조건과 근거를 가진다.
2. 문헌 지지 관계는 별도 축이다: `supports / contradicts / limits / contextual / missing`. 감사 판정 `SUPPORTED / PARTIALLY_SUPPORTED / CONTESTED / UNSUPPORTED / MISATTRIBUTED / INFERENCE_ONLY`는 이 관계의 검토 결과이며 근거 유형을 대체하지 않는다.
3. 실제 열람 범위, 저자·제목·날짜·버전, 페이지/식/표, 성립 조건과 한계를 기록한다. 검색 결과·초록·원문을 구분한다. 접근하지 못한 문헌은 읽었다고 하지 않는다.
4. 직접 유도는 정의→가정→변형→결론을 재현 가능하게 남긴다. 수치 검산은 입력·오차·정밀도·극한을, 구현 검증은 source·command·environment·actual exit·raw log를 남긴다.
5. hash·commit·tree·파일 크기는 byte identity 증거다. 문서의 과학적 권위, 도구 실행의 진정성, 권한 있는 출처 여부는 별도 근거로 확인한다. 내용상 동등함은 해시 일치와 구분하여 근거를 기록한다.
6. 상충 결과, 부정·null 결과, 유효범위 차이를 보존한다. evidence 부재를 부재의 증거로 바꾸지 않는다. 같은 주장을 반복 지지하는 자료는 정보가치가 없으면 추가하지 않는다.
7. 외부 문헌 금지 요청이면 제공된 자료·직접 유도·가능한 계산만 사용한다. 기존 citation 목록은 검증된 원문 근거로 자동 승격하지 않는다.
8. ledger의 evidence ID를 state와 최종 claim에 연결한다. citation 존재만으로 과학적 결론을 승인하지 않는다.
