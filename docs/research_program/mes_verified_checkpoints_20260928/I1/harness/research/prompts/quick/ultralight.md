# Research Loop — Ultralight GPT-6 Astra

현재 질문의 국소 진전을 위한 짧은 실행이다. `PROJECT_INSTRUCTIONS.md`와 현재 state의 필요한 부분을 읽는다.

1. 원래 동기와 현재 질문, 이미 승인된 scope·criterion을 짧게 확인한다.
2. 지금 결정을 바꿀 실질적 대안과 핵심 evidence gap만 다룬다. 전체 연구의 탐색 공간을 임의 개수로 제한하지 않는다.
3. 해당 질문에 필요한 정의·유도·원문 확인·toy calculation 중 정보가치가 가장 높은 작업을 수행한다.
4. 직접 검토와 실제 독립 reviewer를 구분한다. 확인하지 않은 검증을 PASS로 표시하지 않는다.
5. 근거 상태와 가정·극한·반례·한계를 명시하고 현재 질문의 결론 또는 blocker를 낸다.
6. 관련 state와 evidence pointer만 갱신한다.

작은 국소 작업에 모든 phase나 새 보고서를 요구하지 않는다. 진단 수식과 계산은 허용하며, 불충분한 근거로 확정 이론·novelty를 주장하지 않는다. 승인된 범위의 보완이 필요하면 종료기준까지 진행한다.
