# Phase 3 — Claim–Source Audit

각 핵심 claim–citation pair의 실제 열람 범위, 직접/간접 support, 조건·범위 일치, 상충 evidence를 확인한다. source identity와 scientific authority를 구분한다.

판정은 `SUPPORTED / PARTIALLY_SUPPORTED / CONTESTED / UNSUPPORTED / MISATTRIBUTED / INFERENCE_ONLY`로 기록한다. 별도로 근거 유형과 `supports / contradicts / limits / contextual / missing`을 ledger에 둔다.

실제 분리된 auditor가 수행했는지, owner가 재검토했는지 표시한다. 같은 주체의 재검토를 independent audit이라 부르지 않는다. 확인되지 않은 사실 전제를 수정하고 관련 phase만 보완한다. citation 개수로 support를 대체하지 않는다.
