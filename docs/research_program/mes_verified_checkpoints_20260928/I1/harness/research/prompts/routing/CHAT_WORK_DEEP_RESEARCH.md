# Host and tool routing

현재 호스트에서 실제 제공되는 기능만 사용한다. UI 이름이나 설치 표시만으로 source 접근·실행·게시 가능성을 추정하지 않는다.

- 국소 토론·설명: 현재 대화와 필요한 source로 처리한다.
- 명시된 심층 문헌조사: 가용한 Deep Research/SciSpace/search 기능으로 원문과 claim support를 확인한다. 검색 범위 제한은 사용자 요청을 따른다.
- 다단계 연구·파일 산출: 단일 실행자가 상태와 증거 포인터를 유지하며 완료까지 수행한다.
- 계산·수치 검증: 현재 실행 가능한 runtime을 먼저 활용한다. 새 환경이나 Local Codex 인계는 실제 blocker가 있을 때 고려한다.
- 지속 상태: 현재 사용 가능한 저장 수단의 저장 성공을 확인한다. 파일 작성과 영속 저장은 구분한다.

도구가 없으면 가용한 동등 경로와 정확한 한계를 기록한다. 이미 승인된 범위의 작업을 도구 이름 때문에 재승인받지 않는다. 제품별 실제 capability와 모델별 선택은 `docs/MODEL_ROUTING.md`로 연결한다.
