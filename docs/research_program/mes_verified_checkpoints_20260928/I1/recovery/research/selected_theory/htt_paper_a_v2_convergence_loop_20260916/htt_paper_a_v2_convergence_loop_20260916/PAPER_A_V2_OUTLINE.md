# PAPER-A V2 manuscript architecture

## Recommended working title

**From CMB Multipoles to Spacetime Kinematics:
Identifiability, Cosmographic Consistency, and Redshift Lifting**

Alternative:
**What Low-Multipole Radiation Can Identify About Spacetime Kinematics**

## Central paper claim

The paper should not claim that low-ell CMB morphology measures shear, vorticity,
acceleration or Bianchi geometry.

It should claim:

> Physical attribution from low-multipole radiation is an inverse problem with typed
> observable, transport and kinematical state spaces. Exact response nulls can be proved,
> a near-isotropic radiation–cosmography consistency residual can be derived, and
> redshift dependence lifts only those degeneracies whose physical kernels are independent.

This preserves the original tensor/morphology motivation but converts the paper from a
large framework report into a theorem-driven methods paper.
