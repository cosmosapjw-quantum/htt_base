## Necessary assumptions and what constitutes progress

### 1. Fibres: a nullspace is an answer only for the declared domain

Historical T-A1 proves an algebraic cancellation ray in a sector coordinate cone. It does not prove the ray is attained by a globally regular GR solution. A useful R9 extension starts from a specified domain D and observation law P_x. Define `[x]={x' in D:P_x'=P_x}` and the target image `{h(x'):x' in [x]}`. For a linear mean model and fixed covariance, equality reduces to A delta-theta + N delta-eta=0. For an actual stochastic sky, equality of the mean is not enough: the covariance or higher distribution can distinguish states. Conversely, a nonzero Jacobian rank can be merely local, and zero derivative at a boundary need not imply global nonidentifiability.

A project-facing deliverable is a target table: local observer beta, coherent source parameter K, radial bulk B, STF S, signed x_C, matter-congruence rapidity. For each: physical domain, law equivalence relation, maximum allowed claim, identified/unbounded directions, and exactly which additional assumption reduces the image. This directly advances the original program without converting an abstract rank fixture into a survey result.

### 2. Full stochastic information: preserve the distinction between target and summary

For a regular Gaussian law N(mu(theta),C(theta)), positive-definite C on the retained space, the information is `F_ab=mu_a^T C^-1 mu_b + (1/2) tr(C^-1 C_a C^-1 C_b)`. Eliminate nuisance scores in the same law, not by projecting only the mean response. A generalized Schur complement is meaningful with its estimability/domain conditions stated.

R9 C3's equal-spectrum example is the decisive fixture: a full-rank deterministic B_Q does not prevent vanishing covariance derivative. Additional processing L changes both signal and noise law; a fixed C_l `f_sky` scalar correction is not exact cut-sky Fisher information. If a summary T is used, score conditioning provides `F_full-F_T=E Var(score|T)` in the regular experiment. This supplies an exact definition of lost information. It does not establish global sufficiency from one local Fisher calculation.

The useful outcome is a per-target information budget and compression ablation. The original promise of tensorized low-ell morphology is thereby tested against scalar and pole-only summaries, not merely asserted.

### 3. Shared calibration: strict improvement must be witnessed

R9 already proves projection(intersection) is contained in intersection(projections). Improvement is not always strict. Strictness depends on whether the target-extremizing latent/calibration choices from individual products can coexist. The shared parameter must be tied by actual anchor and method identity; same-host differences can identify a nuisance difference without measuring the common distance scale.

For ratio targets N/D, compute extrema on the same feasible tuple. If D has both signs or approaches zero, partition by sign and examine unboundedness. If D>0 but N can be negative, `Nmax/Dmin` need not be an upper endpoint. Characterize the product-space extremizers first, then ask whether any has a diagonal/common-state representative. Avoid the historical unconditional face rule.

### 4. Orientation: orbit invariants and common sky orientation are different targets

Joint rotation of (Q,O) preserves their relative shape. Independent rotation of Q and O removes relative orientation and answers a different question. Rotating only the CMB while holding a CF4 sky pattern fixed removes a scientifically relevant relation. Therefore morphology invariance should use a simultaneous action on the objects whose common orientation is nuisance; direction-dependent cross-probe inference should retain an orientation parameter or an equivariant set.

T-P2's eigengap warning is valuable, but gap→0 only makes a generic perturbation bound uninformative; it does not make every particular axis realization maximally erroneous. At exact degeneracy, return the eigenspace or axis set. Future acceptance should contain rotated inputs, nearly repeated eigenvalues, zero tensor, and two distinct full morphologies with the same pole summary. None requires a new scalar primary statistic.

### 5. Design: information depends on covariance, nuisance, units and target

T-P12's E-optimal objective is meaningful only after target units and a reference metric are fixed. A smallest eigenvalue is coordinate-dependent; mixing km/s and dimensionless amplitudes silently changes the objective. If an irreducible blind sector is present, maximizing the smallest eigenvalue of the full matrix gives zero for all designs. Optimize the declared identifiable target or quotient instead.

For fixed known covariance and linear responses, independent new observations add PSD information. Duplicate correlated draws do not. Nuisance projection must be recomputed on the common tuple because new calibration observations may constrain an existing nuisance rather than add a new physical-response direction. A finite candidate design can have an SDP form via a Schur-complement matrix inequality, but free changes in covariance or selection can destroy the simple affine information model.

The radial identity `n^T Omega n=0` applies to antisymmetric affine rotation about the observer. It is a valid blind-sector example, not a theorem that every vortical cosmological configuration has no radial consequence after dynamics and selection. Proposed transverse/spin-2 channels reopen inference only through an explicit nonzero independent response, not the channel name alone.

### 6. Estimated covariance: retain one honest exact special case

For fixed B independent of the data and covariance simulations, `x_r=B^T x ~ N(0,Sigma_r)` and `(Nsim-1) S_r ~ Wishart_k(Sigma_r,Nsim-1)` independent, the usual scaled F pivot for `x_r^T S_r^-1 x_r` is valid. This is a concrete theorem with a narrow consumer. If B is computed from S, the ordinary fixed-B derivation does not apply. Orthogonal projected Gaussian blocks are independent only when their cross covariance vanishes; Euclidean orthogonality alone is insufficient for a general Sigma. R9's known-whitened-covariance construction avoids that problem.

The historical coverage candidates can seed this case, but should not automatically qualify active-set optimization, covariance estimated from overlapping sky simulations, data-dependent rank, fitted selection, or an estimated design. Those require their own joint experiment. Bonferroni remains available without independent probes; exactness and conservatism must remain separate labels.

### 7. MES and realization: maintain a ladder of mathematical claims

A radiation multipole amplitude at one event does not control its time/spatial derivatives merely because an octupole amplitude is small. NT2-B1's replacement of derivative control by a3/a2 is not an admissible closure until the actual covariant hierarchy, norms and source terms establish it. R9 already states this correctly at the relation level.

A constrained component vector is weaker than constraint-satisfying initial data; local development is weaker than a specified global cosmological branch. Moreover sigma², omega² and boost energy excess are O(epsilon²) when their underlying first-order fields are O(epsilon). Linearized constraints do not alone establish the quadratic budget or independent second-order realization. A hypersurface normal has zero vorticity; any nonzero omega must refer to another congruence, with its frame relation and constraints included. These facts do not invalidate all local constructions, but they prevent automatic endpoint promotion.

A productive near-term target is one explicit admissible branch with controlled remainders, alongside a rigorous nonidentifiability example when derivatives are absent. It need not wait for all BASS types or a full production solver.

### 8. Error: consumer-bound uncertainty, not a free-standing gate

The historical transfer-evidence inequality is correct when both likelihoods use the same normalized prior and the log-likelihood difference is uniformly bounded across its support. A bound checked at sampled parameter values is not such a uniform bound. In an unbounded Gaussian mean problem, a small response coefficient perturbation can create an unbounded log-likelihood difference. Therefore either restrict/justify the domain or use a target-error/set bound whose premises are actually available.

R9's directed support propagation is already the right starting point. Improve it by retaining correlations between approximation, calibration and physical state. Alternative plausible processing laws generally give a union of admissible states; mutually compatible measurements constrain by intersection. A nuisance minimizer or discrepancy choice must stay shared where the physics says it is the same variable.

Novelty of the combined result remains unresolved until a dedicated comparison is done.
