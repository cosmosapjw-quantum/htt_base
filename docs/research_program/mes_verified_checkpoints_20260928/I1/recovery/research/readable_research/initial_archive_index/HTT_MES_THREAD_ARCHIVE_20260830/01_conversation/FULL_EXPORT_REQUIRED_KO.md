# 완전한 대화 원문을 채우려면

현재 도구가 반환한 자료에는 이 스레드 전체의 원문 export가 없다. 이전 메시지 일부는 `Skipped … messages`로만 표시되고, 파일 검색은 첨부 파일의 내용 검색이지 전체 채팅 원문을 내보내는 API가 아니다. File Library에서 나온 2026-03-16의 다른 대화록은 이 스레드와 다르므로 포함하지 않았다.

이 스레드의 사용자·assistant 원문이 담긴 HTML/JSON/Markdown export를 추가로 제공해야 생략 구간까지 채울 수 있다. 이를 제공받으면 기존 02_original_files와 비교하여 덮어쓰지 않고 별도 원본 export로 보존할 수 있다. 지금의 요약·발췌를 누락 원문의 대체물로 승격하면 안 된다.

이 archive에는 숨겨진 system/developer 지시나 비공개 추론이 들어 있지 않다. 연구 파일 내 사용자가 제공한 공개 프롬프트/하네스는 원본 파일의 일부로 보존했다.
