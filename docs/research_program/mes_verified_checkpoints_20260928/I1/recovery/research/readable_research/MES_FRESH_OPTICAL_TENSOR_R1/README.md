The independent exact sphere-polynomial check is `python3 evidence/reviewer_tensor_checks.py` and uses Python standard-library rational arithmetic. Read the script output convention before comparing full-sphere integrals with normalized sphere averages.

`evidence/wl_checks_1.json` through `wl_checks_3.json` contain actual Wolfram inputs and raw tool responses. The first call's warning and hardcoded auxiliary field are explicitly excluded where appropriate in the review; later calculations actually evaluate those quantities.
