# Null-bundle optical kinematics -> observables

For a light-cone congruence k_a=grad_a psi,

k.k=0,
k^b∇_b k^a=0,
twist=0.

The screen deformation tensor is

B_AB=varsigma_AB+(1/2)vartheta delta_AB.

The null expansion controls beam area, and the null shear controls differential image
distortion.

Sachs equations:

d vartheta/dv =
-(1/2)vartheta^2 - varsigma_AB varsigma^AB - R_ab k^a k^b,

D varsigma_AB/dv =
-vartheta varsigma_AB - (C_AkBk)^TF,

with sign conventions tied to the declared Riemann convention.

For the Jacobi map D_AB, away from caustics,

B = D' D^{-1}.

The determinant gives area/angular-distance information and the trace-free part gives image
distortion.

In observational coordinates (w,z,theta,phi):

D=D_A,
L_IJ = image/lensing-distortion variables,
V^I = transverse proper motion,

and

vartheta = 2/(B D) partial_z D,
varsigma_IJ = D^2/(2B) partial_z L_IJ.

Therefore use the redshift-parametrized products B*vartheta and B*varsigma_IJ in future
statistical analysis whenever possible.
