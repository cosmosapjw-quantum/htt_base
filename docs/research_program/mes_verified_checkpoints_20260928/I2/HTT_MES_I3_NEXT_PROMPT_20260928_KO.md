state를 읽고 그 claim ceiling을 보존하라. 필요한 선행식만 I1과 R2/R5에서
참조한다. 원본 backup/portable catalog는 읽기 원장의 locator를 따라 선택적으로
열고 이미 완료된 전체 목록화·fixture·R9 D2 compilation을 반복하지 않는다.

이번 질문은 하나다. 기존 target Z를 물리·관측 질문으로 연결하기 위해
같은 congruence의 독립 geometry 또는 radiation-jet 입력 하나를 실제로
선택할 수 있는가? 사용자 원래 목적은 FLRW departure 및 tensor morphology다.
I2의 radiation-only Bianchi I는 그 전체 목적의 최종 우주모형이 아니다.

먼저 현재 연구의 관측 질문이 norm 상한인지 tensor morphology인지 명시한다.
전자는 독립 joint (H,rho) 입력과 Einstein model compatibility를 검토하고,
후자는 기존 R3/R4 optical directional response 중 실제 source/observer congruence,
거리 scale, peculiar velocity, frame spin, mask 및 Taylor remainder를 함께
제공할 수 있는 하나의 관측 입력을 검토한다. 이론상 가능성만 나열하지 말고
대표 input file 또는 primary data/method 하나를 실제 열어 field/units/frame/
모형 의존성/공분산/selection의 존재 여부를 판정하라.

선택된 입력에 관해 기존 target response로 가는 최소 수학 계약을 작성하고,
독립 정보인지 확인하라. FLRW/ΛCDM 고정 H0 posterior를 model-free expansion
자료라고 부르지 않는다. 같은 복사식을 풀어 얻은 jet를 independent prior로
재투입하지 않는다. 순간의 isotropic sky가 dot-pi=0이라는 가정도 금지한다.

I2 branch에서 kappa=8piG/c^2, rho는 energy density, Z=sigma다. Constraint
||sigma||_F^2=6H^2-2kappa*rho는 magnitude만 정하며 negative radicand는 empty다.
General finite tilt로 되돌아갈 때는 Z와 physical shear를 구분하고 I1의
operator 및 R5 geometry와 같은 상태의 제약을 유지한다. I2의 제한 모형
결론을 Lambda/matter/curvature/tilt가 있는 경우에 그대로 확장하지 않는다.

자료가 충분하면 작은 analytic conditional target set 또는 식별 부분공간을
구성하고 필요한 가벼운 계산만 실행하라. 부족하면 실제 확인된 missing field와
그것이 왜 필요한지, 최소 추가 자료가 무엇인지 산출하라. 입력 부재를 임의의
수치 bound로 메우지 않는다. 대규모 full suite, solver reimplementation,
posterior sampling은 이번 단계의 자동 후속 작업이 아니다.

새 결과는 원문/source identity, assumptions, derivation, current execution,
실제로 분리된 독립 decision 및 남은 gap과 함께 보존한다. Repository 입장을
변경하려면 기존 registered assignment/CAS4 절차를 적용하고 외부 analytic
review를 그것의 대체물로 사용하지 않는다. Local Codex는 반환 handoff와
새 결과 ZIP을 작성하되 원본 대용량 백업을 불필요하게 중복 복제하지 않는다.
