# 읽기 안내

1. REPORT_KO.md: 이번 이론 연구의 결론·증명·관측 한계.
2. CLAIMS.json: 9개 후보의 가정·근거·독립 판정. 7개 조건부 이론 명제만 후속 단계 승인.
3. INDEPENDENT_DECISION.json / INDEPENDENT_REVIEW.md: 실제 분리된 reviewer의 판정과 읽기 범위.
4. evidence/: 실행한 Wolfram 입력 4개와 원 출력, SciSpace 탐색 결과.
5. NEXT_TASKS.json / LOCAL_CODEX_PROMPT_KO.md: 아직 실행하지 않은 local 후속 연구 DAG와 프롬프트.
6. prior_audit.md / geometry_findings.md / optics_findings.md: 독립 분담 조사와 정확한 source 범위.
7. SOURCE_REGISTER.json / PRESERVED_SOURCE_HASHES.json: 출처와 보존 문서 byte identity.
8. CLOSEOUT.md / RESEARCH_STATE.md: 완료 및 미완료 상태.

CANDIDATES_FOR_REVIEW.md는 판정 전 초안 보존용이다. 현재 해석은 필수 조건을 반영한 REPORT_KO.md와 CLAIMS.json 및 INDEPENDENT_DECISION.json을 따른다.

이 묶음에는 대용량 DB, 전체 repo, 원 논문 PDF, 원래 연구 하네스 ZIP을 포함하지 않았다. 이전 결과의 읽기 감사와 필요한 source 포인터를 제공한다. MANIFEST.sha256은 이 묶음의 파일 바이트를 확인하며 과학적 증명이나 최신 원격 repo identity를 대신하지 않는다.
