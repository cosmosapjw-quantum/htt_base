# Bianchi 식별 재탐색 — 연구 상태

날짜: 2026-09-29. 범위: 외부 Boltzmann solver 없이 가능한 Bianchi 기하/군작용의 조건부 식별, 배제, 부분식별.

사용자 지정 GPT-6 Astra 연구 프로파일 v4.0.0을 적용한다. 현재 호스트의 일반 GPT-6 표기만으로 Astra 하위모델이나 ultra 설정을 검증하지 않는다. 하네스는 모델을 변경하지 않는다.

원래 동기: 유형을 선험적으로 고정하지 않고 모든 운동학량, tilt/boost, 적색편이와 형태 정보를 활용하여 이론적으로 허용되는 집합과 관측을 비교한다.

불변조건: signature (-,+,+,+); c 명시; 광학 screen shear와 유체 shear 구별; 관측자/물질 congruence와 homogeneous slice normal 구별; full data law의 동일성과 평균의 동일성 구별; 기존 HOLD를 자동 승격하지 않음; 실제 자료 적합이나 전체 저장소 최신 감사는 이번 실행 범위가 아님.

가용 근거: 보존된 이전 이론 문서, SciSpace 문헌 탐색, 원 논문 웹 열람, Wolfram 기호 계산, 실제 분리된 연구 및 판정 검토자. 대용량 데이터베이스 다운로드와 저장소 변경은 하지 않음.

완료기준: (1) 식별대상 정의, (2) 정확한 반례와 구성적 조건부 명제, (3) 가능한 기호 검산 실행과 원 출력 보존, (4) 독립 판정, (5) 보고서와 재현 입력·후속 국소 작업 계약 저장.

진행 상태: 연구루프 완료. 직접 유도와 Wolfram 기호 계산 4건 완료. 별도 reviewer가 조건부 이론 명제 7개를 후속 형식화 범위에서 승인했고, 관측 재구성 및 실자료 분류는 HOLD. 최종 상태는 CLOSEOUT.md 및 INDEPENDENT_DECISION.json 참조.
