## What this PR does

Lifts the species background coverage from z ≤ 8000 (HYREC fixture
default) to z ≤ 10¹⁰, comfortably covering the audit's stated δ deep
anchor target z = 10⁹ with one decade of floating-point headroom on
each side.

### Recombination fixture extension

The original `recombination_ref_planck2018.csv` (8001 rows, z ∈ [0, 8000])
is preserved. A new file `recombination_ref_planck2018_z1e10.csv`
(8133 rows, z ∈ [0, 10¹⁰]) is generated by appending 132 log-spaced
radiation-era extension rows to the original. The extension uses
closed-form physics:

| Quantity | Extension formula |
|---|---|
| `x_e(z)` | constant `≈ 1.1634` (asymptotic full He++ ionization at z ≥ 8000) |
| `T_m(z)` | `T_CMB · (1 + z)`, T_CMB = 2.72548 K (tight Compton coupling at z ≫ 100) |
| `τ_dot(z)` | `τ_dot(8000) · ((1+z)/8001)²` (∝ a · n_e ∝ a⁻²) |
| `κ(z)` | numerically integrated from z=8000 anchor using closed-form `\|dη/dz\| = 1/H(z)` (Friedmann radiation+matter) |

The κ formula uses a calibration factor (numerically `0.9952` ≈ 1 in the
generator output) computed from the existing fixture's observed
`dκ/dz(8000)` to absorb tiny Ω_γ / N_eff convention mismatches between
this script's analytic Friedmann and the HYREC fixture's underlying code.

### FLRW bg_table extension

`SpeciesBackgroundRegistry.from_planck2018()` now calls
`build_flrw_background_table(a_start=1e-10)` (was default 1e-8). This
extends the FLRW η-grid by two log-decades down to a ≈ 10⁻¹⁰ (z ≈ 10¹⁰).

Rationale for one decade past the recombination fixture:
`1.0 / (1.0 + 1e9) = 9.999...e-10 < 1e-9` due to floating-point
rounding, so a fixture / bg_table anchored at exactly `a_start = 1e-9`
would reject the literal `z_injection = 10⁹` at the strict-`<` boundary
check. Setting both tables at `a_start = 1e-10` gives one decade of
headroom; `z = 10⁹` queries map to `a ≈ 10⁻⁹` which is well inside
`[1e-10, 1]`.

The cost in η-grid resolution is `Δlog a ≈ 2.5e-3` instead of `2.0e-3`
at the default `n_eta = 4000` — still much finer than the recombination
visibility FWHM (~19 Mpc) and below the highest-k Bessel period the
LoS projector resolves.

## Caveats

This PR addresses **defect-1** of V0d's three-defect explanation
(species table edge). It does NOT address:

- **Defect-2: IMEX pre-recombination tuning.** The 8 algebraic
  patches in `bass/hierarchy/ver3_layout_protocol.py` (Round-15
  Blocker 2 closure) were validated for `η ∈ [261, 14147] Mpc`. They
  may behave correctly at deeper anchors, but per-decade conservation
  audit is δ scope (audit Report 2 R-3, R-4).
- **DAE-relaxation switch-smoothness across `Γ_T/H ~ 10⁹ → 10⁻¹`.**
  Current smoothness audit covers only the recombination transition.
  Deep-TCA-only smoothness is δ scope.

Therefore V0d post-pre1+pre2+pre3 is expected to **partially** improve
over V0d post-pre1 (the species-table-edge contribution is closed) but
**not** fully resolve to the monotone-collapse signature the audit
predicted. The remaining gap is δ work.
