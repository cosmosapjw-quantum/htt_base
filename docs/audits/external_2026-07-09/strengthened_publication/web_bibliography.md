These are external context sources used to design the strengthened publication plan. They are not repo-local evidence for HTT claims.

- Planck Collaboration, “Planck 2018 results. VII. Isotropy and Statistics of the CMB,” arXiv:1906.02552. Used to position low-ell anomaly diagnostics without overclaiming unambiguous cosmological detection.
- Saadeh et al., “How isotropic is the Universe?”, arXiv:1605.07178. Used as the high bar for all-degree-of-freedom Bianchi/anisotropy testing with Planck temperature and polarization.
- Saadeh et al., “A framework for testing isotropy with the cosmic microwave background,” arXiv:1604.01024. Used for template/anisotropy-testing context.
- Jaffe et al., Bianchi VII_h WMAP papers. Used as the template-tradition counterpoint.
- Hajian and Souradeep BiPoSH/statistical-isotropy literature. Used for scalar-vs-covariance channel positioning.

## Statistical methodology

- Sellentin and Heavens (2015/2016), covariance-marginalized multivariate-t likelihood. Used for estimated-covariance K1/K5 inference.
