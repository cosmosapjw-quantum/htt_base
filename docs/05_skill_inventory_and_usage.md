# Skill Inventory and Usage — v3 augmented

This inventory includes the original repo skills and the upgraded template skills.

| Skill | Trigger description |
|---|---|
| `htt-adversarial-review-loop` | Use for every substantial PR before commit, especially after implementation and tests. |
| `htt-claim-firewall` | Use when a PR touches claim tiers, manifests, MIO/HTT ownership, transfer provenance, TSC/Teff legacy language, or manuscript/report text. |
| `htt-claim-provenance-ledger` | Use when writing or changing scientific claims, result captions, reports, claim ledgers, artifact manifests, status snapshots, or publication-facing text. |
| `htt-dag-orchestrator` | Use when selecting the next PR, validating dependencies, updating PR status, computing progress percentages, or replanning the long-range DAG for htt_base. |
| `htt-family-identification-gate` | Use whenever a PR, report, figure, likelihood, or manuscript text mentions Bianchi family identification, geometry candidate, equivalence classes, native transfer atlas, BiPoSH morphology, or family ranking. |
| `htt-harness-engineering` | Use when adding or modifying test runners, optional dependency handling, PR delta scaffolds, status snapshots, artifact linters, or CI-like local commands for htt_base. |
| `htt-latex-paper-build` | Use when editing or auditing TeX files, references, figures, manuscript snapshots, appendix material, figure provenance, or external-audit manuscript bundles. |
| `htt-local-global-discrimination` | Use when implementing local boost, global tilt candidate, depth-gap, response-overlap, null competition, PPC/LOOCV, or HTT mixture models. |
| `htt-manuscript-figure-audit` | Use when auditing tex files, includegraphics paths, generated figures, result packs, claim ledgers, or external audit packages. |
| `htt-observable-statistics` | Use when implementing obsstat, alm conventions, low-ell scalar features, morphology axes, template fits, BiPoSH/covariance features, null ensembles, or look-elsewhere bookkeeping. |
| `htt-physics-math-audit` | Use for GR/cosmology/statistical mechanics/kinetic-theory derivations, MES bounds, transfer functions, Bianchi/tilt variables, local/global anisotropy claims, units, signs, limits, and convention-sensitive equations in this repo. |
| `htt-research-plot-summary` | Use when PRs produce plots, result packs, convergence diagnostics, residual plots, local/global discrimination heatmaps, G_F depth-gap plots, BiPoSH/template summaries, or manuscript figures. |
| `htt-reviewer-mode-pre-submission` | Use before public release, external audit handoff, manuscript freeze, major PR merge, family-identification claims, or result-pack publication. |
| `htt-scientific-code-validation` | Use after edits to Python/Rust/scientific scripts, tests, numerical artifacts, generated figures, transfer adapters, local/global discrimination code, MIO reports, obsstat features, or validation harnesses. |
| `htt-solver-handoff-readiness-audit` | Use when reviewing external/native low-ell Bianchi solver design docs, solver handoff prompts, 1+3 PSTF/tetrad architecture, Bianchi family coverage, implementation skeletons, or solver-to-observer interface readiness. |
| `htt-ssot-handoff-maintainer` | Use after every five PRs, after architecture or claim-tier decisions, before external audit packages, when context is large, or whenever project state/validation/claim status changes. |
| `htt-transfer-provenance` | Use when wrapping current AniCLASS/external transfer functions, defining future native solver adapter stubs, AtlasEntryLite, budget ceilings, or transfer sensitivity reports. |
| `htt-xqpi-fg-formalism` | Use when implementing or reviewing DepartureBundle, Q, Pi, certified F, G_F depth-gap, report cards, or posterior pushforward. |
