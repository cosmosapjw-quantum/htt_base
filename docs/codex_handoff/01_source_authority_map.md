1. Current root `AGENTS.md` in this package.
2. `docs/codex_handoff/pr_backlog.yaml` as the canonical active DAG authoring
   root and `docs/codex_handoff/pr_status.yaml` as its canonical orchestration
   state. `machine_readable/*.yaml` are byte mirrors; the two backlog JSON
   files are semantic mirrors generated from the canonical YAML.
3. `docs/codex_handoff/research_remediation_state.yaml` as the active finding
   root and `docs/codex_handoff/authorized_principals.yaml` as its default-deny
   authority registry. Their `machine_readable/` copies are generated byte
   mirrors.
4. Generated PR delta files and immutable checkpoint artifacts created by the
   harness. A checkpoint at completed count N is never rewritten after later
   DAG intake changes the denominator.
5. Current repo code and tests.
6. Uploaded research plans and manuscript/audit packages. Historical audit
   prose is immutable evidence, but generated counts and the active finding
   root control current status when prose and structured authority disagree.

`docs/02_long_range_PR_backlog.md` is a historical human-readable plan, not an
active DAG root. Proposal IDs (`AUD-R*` and `PR-R*`) are superseded through the
PR-119 crosswalk and must not be executed alongside their active `PR-119..166`
cards.

## Scientific authority constraints used by this handoff

- The v4-critical research plan says the next center of work is not more figures but claim-tier, artifact manifest, ownership firewall, direction-inclusive gates, HTT/MIO separation, TSC scope restriction, and status snapshot discipline.
- The observables/statistics document separates solver core from observer-side outputs: `a_lm`, deterministic templates, anisotropic covariance, low-ell statistics, null ensembles, and look-elsewhere bookkeeping.
- The low-ell solver core document is out of scope for this pre-solver repo work except for adapter schemas and future `AtlasEntryLite` interfaces.
- The `(x,Q,Pi,F,G)` document requires `Q` as normalized score, `F` as certified filling fraction, `G_F` as depth-gap diagnostic, and no scalar-only family claim.
- Teff/TSC is legacy for new work; any retained utility must become generic semantic guard code, not active science ownership.
- PR-DAG orchestration state, terminal execution resolution, and scientific
  finding status are orthogonal. Completion or a negative terminal receipt can
  close only its typed process dependency and never promotes scientific status.
- Adjudication and external-delivery status envelopes are not authority.
  Receipt-gated edges require hash-bound typed receipt bytes, exact scope,
  registry resolution, attestation verification, and the required independence
  class; no injected trust verifier means fail-closed.
