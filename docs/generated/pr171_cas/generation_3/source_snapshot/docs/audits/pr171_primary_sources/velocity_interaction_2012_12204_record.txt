NORMALIZED SOURCE STATEMENT:
The velocity-dependent coupling is model-specific, modifies Euler perturbation equations without modifying the homogeneous background, and has stability conditions derived for its restricted parameter regime.
SUPPORTED USE: demonstrate that an interaction damping coefficient requires an explicit model and closure.
NOT SUPPORTED: a universal Gamma term, generic shear closure, or a universal no-go.
