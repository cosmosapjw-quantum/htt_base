# Approval boundaries

현재 요청과 세션에 이미 존재하는 승인을 먼저 확인한다. 이 정책은 새 권한을 만들지 않는다.

## 승인 범위 안에서 계속

- 제공 자료·연결 source 읽기, 허용된 검색, 유도·계산·검증
- 요청된 산출물·초안·ledger·상태 문서 생성·수정
- 같은 objective/scope/invariants 안의 증거 기반 수정과 필요한 재검증
- 이미 승인된 branch/push/게시 등 외부 행동은 그 대상·범위·조건을 유지할 때 실행

phase 전환, 리뷰 지적의 통상적 보완, 기존 권한 재사용만으로 재승인을 요구하지 않는다. 미승인 대상에 대한 원본 덮어쓰기·외부 게시 권한을 다른 승인으로 확대하지 않는다.

## 실제 추가 승인이 필요한 경우

- 현재 승인 밖의 외부 공유·게시·파괴적 변경 또는 비용 발생
- 명시된 scope 확장이나 별도로 예약된 work unit 진입
- 보호된 convention, baseline, tolerance, claim ceiling 또는 과학적 의미의 변경

먼저 승인된 부분과 검토 가능한 구체 결과를 완성한다. 추가 입력이 꼭 필요하면 대상 행동과 적용되는 경계·출처를 짧게 밝힌다. 도구/정책 거절을 다른 경로로 우회하지 않는다.
