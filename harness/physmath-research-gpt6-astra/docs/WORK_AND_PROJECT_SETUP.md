# Host setup

이 패키지는 파일 기반 연구 계약이며 특정 호스트의 자동 설치를 가정하지 않는다.

1. 현재 호스트의 모델을 `docs/MODEL_ROUTING.md`로 확인한다.
2. `PROJECT_INSTRUCTIONS.md`를 실행 core로 제공한다.
3. `state/RESEARCH_STATE.md`와 현재 source·raw evidence 포인터를 연결한다.
4. 긴 실행에는 integrated prompt를, 국소 작업에는 quick prompt를 사용한다.
5. 실제 저장 성공이 확인된 위치에 결과·상태를 보존한다.

호스트가 Projects instructions/sources를 제공하면 활용할 수 있다. 현재 기능의 가용성은 호스트에서 확인한다. 포함된 과거 제품 링크는 지원 여부의 현재 증거가 아니다. 메모리의 routing 지시가 파일 읽기 도구나 실행 기능을 새로 생성하지 않는다.
