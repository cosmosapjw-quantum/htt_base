# Customization

분야별 convention·baseline·tolerance·보호된 의미는 하나의 source 또는 `state/RESEARCH_STATE.md` 포인터에 둔다. 모든 phase에 반복 복제하지 않는다. default signature `(-,+,+,+)`와 c, ħ, k_B 보존은 사용자가 다른 convention을 정하지 않았을 때 적용한다.

탐색 breadth·검색·검증 예산은 질문과 실제 정보가치, 사용자가 정한 한도에 따른다. 후보 수나 수리 횟수의 고정 cap을 default로 추가하지 않는다. 실증 로그 없이 모델 설정의 우열을 단정하지 않는다.

기존 연구의 novelty·motivation·claim ceiling을 바꾸는 수정은 이유·영향을 먼저 설명하고 기존 승인에 포함되는지 판단한다. 패키지에 포함된 legacy `.agents/skills/`를 개인 환경에 자동 설치하거나 수정하지 않는다.
