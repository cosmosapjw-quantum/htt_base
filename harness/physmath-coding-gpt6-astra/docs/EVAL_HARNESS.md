# Executable evaluation contract

The v4 release is a proposed GPT-6 Astra instruction adaptation. No model-quality, cost, speed or token-efficiency improvement has been measured. Package tooling tests are implementation checks of those tools only.

Compare original GPT-5.6 v3.1.0 and GPT-6 Astra v4.0.0 on fixed tasks and artifacts. Preserve task difficulty, supplied context, tools, acceptance, scientific definitions, tolerances and execution budget. Separate model change from harness change with a supported cross-over/ablation when possible; record unsupported combinations rather than fabricating runs.

Use recent executable private cases covering a targeted bug, a multi-file dependency, numerical conditioning/convergence, physical invariant violation, derivative/JVP, malformed evidence authority and interrupted runtime recovery. Avoid implementing a test suite whose sole oracle is the patched implementation. Record actual independent reference provenance.

For each case report actual host/model identifier, reasoning setting, harness/source identities, tool versions, first outcome, repair evidence, final acceptance, scientific/numerical gates, false success/false stop, human intervention, regression, actual wall time and provider usage if available. Cost is NOT_EVALUATED without independently sourced usage and applicable rates. A self-hashed usage packet cannot confer usage authority.

Stop evaluation when the predeclared comparison is answered; do not grow review recursion. See `MODEL_REGRESSION.md` for release-specific unevaluated conditions.
