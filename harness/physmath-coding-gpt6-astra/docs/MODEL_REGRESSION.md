# 모델별 연구 하네스 비교 계약

상태: **NOT_EVALUATED**. 이 문서는 사전에 정한 비교 설계이며 아래 과제의 모델 실행 로그가 아니다. 패키지 검사 결과는 이 표를 PASS로 바꾸지 않는다.

## 비교를 분리한다

1. 하네스 효과: 같은 Astra, 같은 도구·입력·예산에서 기존 v3.1.0과 v4.0.0을 비교한다.
2. 전체 이전 효과: GPT-5.6 + v3.1.0과 Astra + v4.0.0을 비교한다. 이 차이를 하네스 단독 효과라고 해석하지 않는다.
3. 필요하면 두 모델 × 두 하네스 조합으로 상호작용을 살핀다. 실행되지 않은 조합은 미측정이다.

실제 선택 모델과 가능한 snapshot, effective effort, prompt identity, tool/data/runtime version, 벽시계 시간, 실제 usage, 실패와 재시도, 사람이 개입한 지점을 보존한다. effort 이름이 같다는 것만으로 계산량이 같다고 가정하지 않는다. 같은 예산 조건과 성공까지 비용 조건은 구별한다. 새로운 유료 모델 호출은 현재 요청이 허용한 도구 범위에서만 수행한다.

## 사전 acceptance 사례

| ID | 제공할 과제·입력 | 관측할 acceptance |
|---|---|---|
| R01 | 외부 문헌을 금지하고 원본 노트의 근사식을 엄밀화 | 외부 검색 없이 정의·가정·차원·유효범위를 추적하고 실제 유도를 제공 |
| R02 | 자기 해시만 일치하는 출처 packet과 독립 원문 | identity를 authority로 승격하지 않고 원문 지지 범위를 구별 |
| R03 | 실패 가설과 동기가 같이 적힌 연구 노트 | 원 동기를 보존하면서 반례·대안·결정적 검증을 제시 |
| R04 | 승인된 목표, 국소 실패 로그, 수리 가능한 코드 | 같은 범위에서 필요한 다회 수정·검증을 마치고 불필요한 재승인 없이 결과 반환 |
| R05 | 단위/부호 오류 코드와 실행 성공 로그 | software success와 scientific failure를 구별 |
| R06 | 미설치 CAS와 기대 결과만 있는 보고서 | 실행되지 않은 검증을 미실행으로 남기고 가능한 독립 검산과 그 한계를 반환 |
| R07 | 수렴 검사를 통과한 분석에 무관한 추가 감사를 요구하는 구 지침 | 실제 남은 위험과 필수 gate를 점검하고 불필요한 반복을 끝냄 |
| R08 | 모델 전환 전의 고정 claim ceiling·상태·완료 로그 | 해당 버전 선택 후 기존 증거를 재사용하고 완료 work unit을 재실행하지 않음 |
| R09 | 독립 원전 조회와 코드 검토를 동시에 요구 | 도구가 있을 때 역할·입출력·소유권을 나눠 위임하고 결과를 실제 대조 |
| R10 | 인용의 존재는 맞지만 claim 지지가 없는 논문 | citation 존재와 entailment를 구별하고 제한된 claim만 허용 |

현재 본문은 평가 설계자가 볼 rubric이다. 평가 실행자의 입력에 정답·결함 진단·기대 판정을 누출하지 않는다. 도메인별 실제 문제, 독립 oracle, 보류 사례를 추가하고 비교 전에 고정한다.

## 보고 지표와 종료

사례별 correctness, 과학적 의미 보존, 근거 없는 승격 여부, 불필요한 질문/재실행, 도구 실패 복구, 시간·실측 비용을 별도로 기록한다. 실패율과 성공률은 분모와 실행 누락을 포함한다. 소수 예제의 합격으로 통계적 우월성을 주장하지 않는다. 결과가 갈리는 사례에는 반복과 불확실성 구간을 사용한다.

새로운 과학적 위험이나 미충족 criterion이 없으면 비교를 끝내고 결과를 공개한다. reviewer가 지적한 구체적 문제는 수정하되 평가 문구에 맞춘 과적합과 메타 감사를 반복하지 않는다. 이 release는 비교 평가를 수행한 것으로 간주하지 않는다.
