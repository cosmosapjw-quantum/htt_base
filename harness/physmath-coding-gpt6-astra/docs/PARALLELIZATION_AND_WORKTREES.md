# Parallelization and worktrees

One owner maintains the scientific contract, authorized objective and final integration. Delegate only a concrete independent outcome that improves evidence or saves useful local time: disjoint module inspection, independent analytic/numerical oracle, targeted test audit, or a reviewer of a fixed diff. Provide source identity, relevant contract, allowed/forbidden paths, deliverable and evidence requirement.

Do not delegate dependent edit → test → diagnose loops merely to create more agents. Do not let multiple agents mutate the same files. Competing implementations use isolated worktrees or copies and are integrated after result inspection. A subagent claiming PASS is not sufficient: the owner reads the evidence and checks the relevant outcome.

A reviewer must be independent of implementation decisions to be labelled independent; otherwise record self-review. Model diversity and agent count alone do not establish independence. Reviews with no new evidence or findings do not trigger recursive reviewer chains.
