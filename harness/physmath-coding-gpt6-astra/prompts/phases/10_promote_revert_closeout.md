# Phase 10 — Promote / Hold / Rework / Revert

PROMOTE requires scoped acceptance, relevant implementation/scientific/numerical gates, required review, clear validity range and respected protected semantics. It does not authorize push/publish/merge or imply untested global physics. REWORK means continue needed in-scope evidence-driven corrections while access and explicit budget permit. HOLD names missing required evidence; REVERT applies only to authorized reversible changes without losing user work.

Update current state, validation matrix and first-failure/decision history with actual source, commands, exit and artifacts. Separate evidence status and claim ceiling; never convert template checks or hashes into science/authority. Finish the requested concrete deliverable and report only material limits and next actions.
