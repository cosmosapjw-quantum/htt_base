# Phase 4 — Execution Plan

For a complex task, write milestones with outcome, files, dependency, required test/scientific evidence, completion condition and rollback boundary. The owner retains dependent edit/test/diagnose and integration; independent delegated tasks receive explicit deliverables. Simple fixes need no ceremonial plan. Milestones are state, not approval gates. Plan completion as Done/Blocked/Cancelled with explicit evidence, and continue through in-scope repairs to acceptance.
