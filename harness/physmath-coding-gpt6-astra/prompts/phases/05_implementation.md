# Phase 5 — Isolated Implementation

Protect existing work with an isolated worktree or clearly bounded copy when needed. Implement the selected coherent change without unrelated cleanup, broad exception, silent fallback or unauthorized semantic changes. Add only checks that discriminate the requested behavior or remaining risk. Continue multiple evidence-driven edits and tests within the same approved objective; one repair cycle is not one edit. Existing authorization persists. Escalate only the concrete new scope, protected meaning or consequential-action boundary that it does not cover.
