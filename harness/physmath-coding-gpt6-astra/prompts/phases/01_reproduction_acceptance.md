# Phase 1 — Reproduction / Acceptance Baseline

For a bug, preserve minimal reproduction and the first observed failure. For a feature, define observable acceptance; for a refactor, lock preserved behavior; for a numerical algorithm, choose analytic/independent reference, error norm, tolerance and regime before observing candidate results. Capture actual source, environment, seed, command, exit and stdout/stderr. If execution is blocked, classify the actual blocker; do not infer a scientific or implementation result. Continue when sufficient baseline evidence exists.
