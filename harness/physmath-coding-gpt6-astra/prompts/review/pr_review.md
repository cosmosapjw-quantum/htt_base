# Scientific PR Review — GPT-6 Astra

Read the fixed source/base/candidate diff, bounded task, original scientific motivation, protected contract and actual relevant test evidence. Prioritize correctness, scientific consistency, numerical reliability, regression, missing discriminating checks, error swallowing, hidden scope and reproducibility/authority defects.

For each finding provide severity, exact location, impact, evidence/reproduction and minimal in-scope correction. Check oracle independence, approximation/closure/tolerance integrity and whether hashes are incorrectly treated as approval or truth. If no blocking finding remains, state residual untested regimes and stop. Label self-review honestly. The implementer may perform several evidence-driven repairs within the approved objective; repeat only affected validation, not a recursive full review without new findings.
