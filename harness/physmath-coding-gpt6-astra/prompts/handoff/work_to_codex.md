# Work → Codex handoff

Use a compact packet: original scientific motivation/novelty, one bounded observable objective, existing authorization, scope/non-goals, protected physics/primal behavior, acceptance, required checks, explicit run budget, actual source identity and independently established authority, current failure evidence and next necessary action.

Provide CODE_TASK.md, the relevant SCIENTIFIC_CONTRACT and VALIDATION_MATRIX rows, actual source/log paths and environment requirements. Do not resend every phase or past transcript. A self-generated hash/approval packet grants no authority. The receiving owner completes authorized edit/test/diagnose repairs without routine per-phase approval; any new boundary is reported specifically. Avoid mandating implementation details that the scientific contract does not require.
