# 다음 독립 이론 연구 루프

사용자의 원래 동기를 유지하라: CMB 관측에서 운동학적 양을 조건부로 제한하고, 물리적으로 선언한 부등식 상한 대비 비율을 계산하되 morphology와 dynamics를 보존한다. 모든 비등방 우주를 다루는 수치 ODE/PDE/Boltzmann solver 구축은 목표가 아니다.

이 묶음의 `MES_FRESH_RESEARCH_R1_KO.md`, 두 증명 노트, `decision.json`을 읽어 현재 결과와 미해결 사항을 구분하라. 원래 기호 x,Q,Π,F,G_F를 보존하고 전단 pilot을 전체 x로 바꾸어 부르지 마라. 기존 프로젝트의 부정적 판정이나 별도 native checkout 차단을 이 연구의 전제로 삼지 마라. 사용자 지시에 따라 GPT-6 Astra 연구 하네스를 적용하되 실제 호출한 모델·도구와 확인하지 못한 상태를 구분하라.

이번의 우선 목표는 **유용한 크기의 물리 잔차 집합 R를 구성하는 것**이다. 정확한 국소 식 L_B(σ)=r, 양성 및 역상 S=L_B^-1 R는 확보했다. 정적인 CMB가 r까지 측정한다고 가정하지 마라.

1. 모든 미분의 개별 smallness 대신 필요한 결합 잔차만 유한한 클래스가 MES 조건보다 어떻게 넓은지 정확한 포함관계와 구성적 예제로 분석하라. 단순 대수 입력과 Einstein–matter 실현을 구별하라.
2. 한 가지 통제된 dynamics/source 클래스를 선택해 새 유한 잔차 부등식을 실제로 유도하라. 후보로 고정 주축 Bianchi I의 팽창 이력 범위와 전체 비등방 응력 범위를 사용하되, 자가중력 복사의 응력을 자동으로 0으로 두지 마라. 새 numerical evolution 없이 할 수 있는 명제부터 완성하라.
3. 관측 가능한 brightness 모멘트의 오차와 residual budget이 전단 타원체, A_sigma, Q_sigma/F_sigma에 어떻게 전달되는지 증명하라. MES 1차 상한을 쓸 경우 finite remainder 또는 reference-score 표기를 유지하라. 확률 ν를 정의하지 않은 Π 수치를 만들지 마라.
4. 증명·한계·기호 검산을 고정한 뒤, 후보 생성과 초기 검증 설계에 참여하지 않은 별도 reviewer의 범위 한정 검토를 한 번 받으라. 문헌 계수와 직접 유도가 충돌하면 해당 식을 검증 전 전용하지 마라. 신규성은 별도 확인 사항이다.

산출물은 새 명제와 증명, 물리 가정의 역할 표, 한 가지 구체적인 반례/경계 예제, 실제 검산 기록, tensorized 통계량으로의 연결, 다음 질문이다. 계획이나 승인 기록만 만들고 끝내지 마라. 관측 fit을 하지 않았다면 관측 제약이나 percentage를 얻었다고 쓰지 마라. 저장소·기존 pending 등록의 변경은 이 이론 작업에 포함하지 않는다.
