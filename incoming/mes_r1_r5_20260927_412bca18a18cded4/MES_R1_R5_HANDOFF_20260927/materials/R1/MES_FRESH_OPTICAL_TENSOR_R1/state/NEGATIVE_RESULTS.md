# Fresh boundaries, established in this loop

These are not inherited project verdicts.

1. Endpoint optics do not alone identify current shear. A change Delta sigma=C[2(t−t*)/L−1] integrates to zero but changes final shear by C. This is a kinematic construction, not a solution in a fixed matter theory. The stress integral restricts that freedom when justified.
2. An unrestricted primordial/source anisotropy can compensate a geometric temperature quadrupole. A source covariance or finite physical source class is needed for conditional inference.
3. Positive invertible L_B does not measure its residual. If R is all STF space, L_B^-1 R is all STF space. A static CMB map alone does not bound unobserved time/spatial derivatives.
4. P=0 is not generally exact for self-gravitating anisotropic collisionless radiation. Finite total stress budgets are the constructive branch.
5. The MES compact coefficient is a first-order result. A strict finite F in [0,1] needs remainder control, and the theorem's observer/domain premises cannot be replaced silently by one measured sky.
6. Scalar norms lose morphology; PSD squaring also loses tensor sign. The signed STF tensor must remain available.
