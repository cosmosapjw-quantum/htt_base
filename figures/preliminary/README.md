# Preliminary figure tiers

Early-stage preliminary figures organised by review tier. Generated by
[`scripts/make_preliminary_figures.py`](../../scripts/make_preliminary_figures.py).

## Tiers

| Tier | Scope | Population |
| --- | --- | --- |
| `TIER_A/` | Core Route-B closure + MES bound atlas; reviewed first | 5 figures |
| `TIER_B/` | Reserved for follow-on analysis figures | empty |
| `TIER_C/` | Reserved for extended-diagnostic figures | empty |
| `TIER_D/` | Reserved for appendix-level supplementary figures | empty |

## Tier A contents

| File | Topic |
| --- | --- |
| `fig_MES_three_bounds` | Bσ > Bω > Bu̇ hierarchy with S1/S2a/S2c markers |
| `fig_sigma_omega_contour` | σ and ω bounds in the ε₁ plane |
| `fig_sigma_accel_contour` | σ and u̇ bounds in the ε₁ plane |
| `fig_colin_beta` | Colin+2025 β_SNe(z) against CF4 band |
| `fig_route_b_sentinel` | D₂(Σ²) Michaelis–Menten curve with sentinel anchor |

Each file ships as PNG + PDF at 300 dpi with a matching `.caption.txt`.

## Regeneration

```bash
venv/bin/python scripts/make_preliminary_figures.py --tier A
```

The Tier-A figures are also mirrored into `paper/ch04_bounds/`,
`paper/ch05_teff/`, and `paper/ch07_results/` with richer captions for
manuscript use.
