# Review checklists

## Every PR

- Dependencies complete.
- Web/doc check recorded or skipped with reason.
- At least four distinct subagent viewpoints used.
- Code changes are meaningful for the PR goal.
- Tests run and recorded.
- PR_DELTA updated.
- Status updated.
- Claim tier and transfer provenance not weakened.
- Completed subagent threads closed.

## Claim-sensitive PRs

- No MIO/HTT merge.
- No external-as-native transfer claim.
- No scalar-only geometry/family claim.
- No TSC/Teff active science ownership.
- No figure without manifest.

## Five-PR checkpoint

- Progress percent computed.
- Stagnation checked.
- Blockers listed.
- Replan if needed.
- Subagents cleaned up.
